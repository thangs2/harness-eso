   0/6 đạt ngưỡng 15%; 60% còn lại là compaction do host. Xem `21.session-whatif-batch.md`.
2. **Quality gate (detection) chưa có bằng chứng.** 2/2 tín hiệu ban đầu là false positive; 0 defect

3. **Pilot 3 vòng chỉ là tín hiệu, không phải kết luận.** Cùng output; B ít LLM step hơn 2/3 vòng
   (TB 24,0 vs 39,3) nhưng n=3, task quá dễ. Xem `25.pilot-rounds-1-3.md`.

Hướng đi đã chốt: **không đốt thêm vào score gate**, mà xây **capability fabric** (RFC 18) để chọn
native/custom theo từng host, và **check hợp đồng/project/migration** — nơi lỗi thật sự xảy ra.

### Plugin DSH (M7) — trạng thái và cách dùng

- Package: `packages/harness-eso-dsh` (bundle `dist/eso-plugin.mjs`, 36,5 KB, **0 external import**).
- Cài: `plugin_manager { action:"install_bundle", target:"<absolute package dir>" }` — UI Plugins chỉ
  nhận spec registry, không có chọn local. Sau khi sửa code: `remove_bundle` → bump version →
  `install_bundle` (HMR không reload bundle).
- Kiểm: `harnessctl doctor dsh --profile desktop` phải `healthy` (chặn ATF-OPS-001).
- Chứng nhận live: `node scripts/make-dsh-demo-consumer.mjs --out /tmp/eso-dsh-demo` rồi mở thư mục đó
  làm workspace, gửi 1 prompt; trail ở `~/.harness/eso-blockers.jsonl`.
- Luật: không cài package nào kéo theo package app-đã-ship (`dsh-tools`, `dsh-llm`, …) — hai instance
  làm `Symbol()` khác identity, mọi tool call chết ở `.prepare()`.

## 5. Việc tiếp theo (thứ tự đề xuất)

1. **P3 — bơm evidence vào context** (`tools/post-execute` + message `agent-instructions`). Cần tự dựng
   message có `id` đúng shape; chưa làm vì chưa kiểm được session store chấp nhận shape tự dựng.
2. **Engine tự chạy check** khi policy khai `eso.checks` (hiện host shim mới chạy) — đo chi phí IO
   mỗi turn trước khi đổi.
3. **Nối `verifyClaim` vào `decide()`**: thêm option `verifyFn`, mặc định `off`, giữ `jev.mode` legacy.
4. **Chạy live DSH**: `dsh bridge --out` → cài bundle → 1 turn → `verify host --require-native`.
5. **Khi quay lại đo**: dùng `23.experiment-protocol.md`; snapshot bằng `scripts/pilot-snapshot.mjs`.
