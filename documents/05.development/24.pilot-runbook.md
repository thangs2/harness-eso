## 3. Smoke pilot (hôm nay, ~2 giờ)

Mục tiêu: kiểm tra **instrument**, không kết luận về ESO. Dùng ticket **chưa làm** (ví dụ BAP-160) để
không cần chặn đáp án.

### 3.1 Tạo 2 snapshot từ HEAD hiện tại

```bash
node scripts/pilot-snapshot.mjs --repo ~/Workspaces/baplatform --commit HEAD --out /tmp/pilot-A
node scripts/pilot-snapshot.mjs --repo ~/Workspaces/baplatform --commit HEAD --out /tmp/pilot-B
```

### 3.2 Chuẩn bị arm

| Arm | Chuẩn bị | Kiểm tra |
|---|---|---|
| **A. Cursor native** | không làm gì | `ls /tmp/pilot-A/.harness /tmp/pilot-A/.cursor/hooks.json` phải **không tồn tại** |
| **B. Cursor + ESO** | `./harness init profile /tmp/pilot-B --id pilot-b` | `.harness/host-pack/harness-hook.mjs` tồn tại; hooks.json có entry `harness-eso-*` |

Nếu muốn đo arm B bằng observe (không bắt buộc cho smoke):

```bash
node packages/harness-observe-server/src/server.mjs --root /tmp/pilot-B   # port 8796 nếu 8792 bận
```

### 3.3 Prompt (giống hệt nhau, dán nguyên văn)

```
<Jira title — ví dụ: BAP-160 …>

Acceptance criteria:
- <AC 1>
- <AC 2>

Constraints:
- Follow the repository conventions and existing patterns.
- Run the relevant tests before finishing.
```

Không nhắc harness, không gợi ý file, không nói "dùng ESO". Thời gian tối đa **45 phút**, không can thiệp.

### 3.4 Thu dữ liệu

| Arm | Lấy gì | Ở đâu |
|---|---|---|
| A | transcript + (không có hook) | `~/.cursor/projects/<slug>/agent-transcripts/` |
| B | request id + hook trace | Observatory `/api/requests/<id>`, `/tmp/pilot-B/.cursor/session/route-trace.jsonl` |
| C (nếu chạy) | session log | `~/.dsh/sessions/--tmp-pilot-C--/session-*/session.v4.jsonl.zstd` |

Gửi lại: request id (B), đường dẫn transcript (A), session file (C).

### 3.5 Điều kiện pass của smoke

1. Snapshot A **không** có `.harness/` (không lẫn ESO).
2. Arm B có ít nhất 1 check `pass`/`warn` thật (không phải `skip` toàn bộ).
3. Record trích được đủ: `actions`, `testRuns`, `defectEscape`, `acceptance`.
4. Không có dấu hiệu agent thấy đáp án (không có commit tương lai trong A).

Nếu 4/4 → chuyển full pilot.

## 4. Full pilot (3 arm, replay ticket đã merge)

1. Chọn 3 ticket đã merge, có test trong PR.
2. Với mỗi ticket:

```bash
node scripts/pilot-snapshot.mjs \
  --repo ~/Workspaces/baplatform \
  --commit <parent-sha> \
  --out /tmp/full-<ticket>-A \
  --forbid <merge-sha>
```

Lặp cho B/C (cùng `--commit`, cùng `--forbid`). Script trả **exit 2** nếu còn rò rỉ — không chạy tiếp.

3. Hidden test: **không** chép vào snapshot. Sau khi agent dừng:

```bash
# lấy đúng file test của PR từ repo gốc (không phải snapshot)
git -C ~/Workspaces/baplatform diff --name-only <parent> <merge> -- '*test*' '*spec*'
# chép từ commit merge sang snapshot, rồi chạy suite
```

4. Grade: `defect_escape` = số test fail; `acceptance` = AC đạt/không; `rework` = số vòng sửa sau review.

---

## 5. Record mỗi run (dán vào bảng tổng)

```json
{
  "runId": "<ticket>-<arm>", "task": "<ticket>", "arm": "A|B|C", "host": "cursor|dsh",
  "model": "<model id>", "repoCommit": "<sha>", "startedAt": "...", "endedAt": "...",
  "h": 0, "health": {"hooks": true, "guards": true, "evidence": 12, "observe": true},
  "actions": 0, "testRuns": 0, "defectEscape": 0, "acceptance": true, "rework": 0,
  "budgetHit": false, "notes": ""
}
```

`h` lấy từ health gate (H0–H4). `h < 2` → **loại run**, chạy lại.

---

## 6. Trước khi bấm chạy — checklist 30 giây

- [ ] Snapshot A không có `.harness/`, `.cursor/hooks.json`.
- [ ] Snapshot B đã `init profile` và có `harness-hook.mjs`.
- [ ] Cùng commit, cùng prompt, cùng budget.
- [ ] `git log` trong snapshot không thấy commit đáp án.
- [ ] Model được ghi lại trước khi chạy (không đổi giữa các arm).
