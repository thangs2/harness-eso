### 5.1 Các tệp tác động
1. `packages/harness-foundation/src/fingerprint.mjs` *(new)*:
   - Hàm `computeFastFingerprint({ stem, root, scopedPaths })`:
     - `stemHash = sha256(normalizeStem(stem))`
     - `gitHead = readGitHead(root)` (đọc trực tiếp `.git/HEAD` hoặc `.git/refs/heads/...`, không shell git).
     - `indexMtime = fs.statSync(path.join(root, '.git/index')).mtimeMs`
     - Trả về chuỗi băm 16-hex súc tích.
2. `packages/harness-host-generic/src/preflight-hook.mjs`:
   - Thay thế đoạn kiểm tra continuation thô sơ (dòng 81):
     ```javascript
     if (shape === 'antigravity' && typeof data.invocationNum === 'number' && data.invocationNum > 0) {
         const existingPre = readPreflight(root, tree);
         const currentFp = computeFastFingerprint({ stem: turn.userQueryStem, root });
         
         // CHỈ cho phép reuse nếu Fingerprint khớp hoàn toàn và chưa hết hạn:
     ```

   - Test 2 (Intent Drift): Đổi stem trong cùng session $\to$ Hủy short-circuit, đo lại.
