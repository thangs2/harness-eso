## 2. Kết quả Audit Chi tiết từng Host

### 2.1. Google Antigravity (`--tree agents`)

- **File kế hoạch:** [`documents/05.development/07.plan-antigravity.md`](./07.plan-antigravity.md)
- **Đánh giá chất lượng kỹ thuật:** **9.8 / 10**
- **Các giải pháp then chốt đã được xác minh trên codebase:**
  1. **Tuân thủ Protobuf Hook Contract:**
     - File [`packages/harness-host-generic/src/hook-io.mjs`](../../packages/harness-host-generic/src/hook-io.mjs) định dạng chuẩn `{ "injectSteps": [...] }` cho `PreInvocation`, `{ "decision": "allow" | "deny" }` cho `PreToolUse`, và **tuyệt đối không trả `decision`** (trả `{}` và exit 0) cho `PostToolUse` / `Stop` để tránh lỗi parse Protobuf.
  2. **Tự chữa lỗi thư mục làm việc (CWD Self-heal):**
     - [`packages/harness-host-generic/src/dispatcher.mjs`](../../packages/harness-host-generic/src/dispatcher.mjs) tự lùi thư mục khi runner spawn tại `.agents`.
  3. **Hàng đợi Bounded FIFO cho Tool Calls đồng thời:**
     - Xử lý triệt để race condition khi agent gọi song song nhiều lệnh `view_file` trong một step qua queue trong `.agy-tool-cache.json` kết hợp correlation `callId`. Đã được bảo vệ bằng test case trong [`qc/host-guards.test.mjs`](../../qc/host-guards.test.mjs).
  4. **Deterministic Transcript Ownership (Defect F30):**
     - [`packages/harness-observe-server/src/ingest-transcript.mjs`](../../packages/harness-observe-server/src/ingest-transcript.mjs) giải quyết bài toán thư mục brain global bằng cách phân tích `ADDITIONAL_METADATA` (`Active Document:`) và fallback qua `<user_information>` / tool call arguments (`Cwd`, `AbsolutePath`).
  5. **Bảo toàn Invariant F26 (Write Guard Scoping):**
     - Tuân thủ quy định không đưa copy unscoped vào host pack, tự động phân phối qua canonical template [`guard-write.py`](../../profiles/templates/hooks/guard-write.py) trong `host-install.mjs`.
