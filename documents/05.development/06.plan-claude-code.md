> **Mục tiêu:** Đưa Claude Code (`claude` CLI / IDE extension) trở thành host chính thức thứ 3 của `harness-eso` (bên cạnh **Cursor** và **Antigravity**) với **100% parity** ở cả hai mặt phẳng:
> 1. **Standalone Plane (Host Pack):** Preflight, Recon Trinity, Gap Attestation, Brain Guard,Write/Shell Guard, Route Hook, Pre-Compact Cost.
> 2. **Observe Plane (Observatory):** Transcript Ingest (`~/.claude/projects/`), Token & Cache Read breakdown, Tool/Rule attribution, và `Claude` IDE badge.

## 1. Bối cảnh & Tính khả thi kiến trúc

Sau đợt Standalone Revamp ([`04.standalone-revamp-wbs.md`](./04.standalone-revamp-wbs.md)) và commit `fcada79`, toàn bộ runtime của `harness-eso` trên repo consumer đã được đóng gói vào một entry point độc lập duy nhất:

```bash
node .harness/host-pack/harness-hook.mjs --hook <name> --tree <cursor|agents|claude> [--event <event>]
```

Claude Code cung cấp cơ chế mở hoàn toàn tương thích với mô hình này thông qua:
1. **`.claude/settings.json` (`hooks`):** Hỗ trợ các lifecycle events chạy command nhận JSON qua `stdin` và đọc quyết định (`allow`/`deny`/`block` + `additionalContext`) qua `stdout`.
2. **Cấu trúc entry hook:** Dùng wrapper `{ matcher, hooks: [{ type: "command", command }] }` — **trùng khớp 100%** với cấu trúc nested mà [`hook-merge.mjs`](../../packages/harness-foundation/src/hook-merge.mjs) đã hỗ trợ cho Antigravity.
3. **`.mcp.json` & `CLAUDE.md`:** Hỗ trợ đầy đủ bộ ba MCP (`codegraph`, `agentmemory`, `deepseek-direct`) và tệp luật gốc tại root dự án.
4. **Local JSONL Transcripts (`~/.claude/projects/<project-slug>/<session-id>.jsonl`):** Lưu đầy đủ từng turn user/assistant, `tool_use`, `tool_result` và `usage` (`input_tokens`, `output_tokens`, `cache_read_input_tokens`, `cache_creation_input_tokens`).

## 3. Đặc tả Giao thức JSON I/O của Claude Code (`shape = 'claude'`)

### 3.1. Payload `stdin` từ Claude Code gửi vào Hook

Mọi event trong Claude Code đều truyền chung envelope cơ bản qua `stdin`:

```json
{
  "session_id": "d8f0c2e0-...",
  "transcript_path": "/Users/operator/.claude/projects/-Users-operator-Workspaces-x79/d8f0c2e0-....jsonl",
  "cwd": "/Users/operator/Workspaces/x79",
  "permission_mode": "default",
  "hook_event_name": "PreToolUse"
}
```

Các trường riêng theo từng event:
- **`UserPromptSubmit`:** có thêm `"prompt": "<nội dung câu hỏi của user>"`.
- **`PreToolUse`:** có thêm `"tool_name": "Bash"`, `"tool_input": { "command": "..." }`, `"tool_use_id": "toolu_01..."`.
- **`PostToolUse`:** có thêm `"tool_name": "..."`, `"tool_input": { ... }`, `"tool_response": { ... }`, `"tool_use_id": "toolu_01..."`.

### 3.2. Payload `stdout` từ `hook-io.mjs` trả về cho Claude Code

Trong [`packages/harness-host-generic/src/hook-io.mjs`](../../packages/harness-host-generic/src/hook-io.mjs), khi `shape === 'claude'`:

1. **Với `UserPromptSubmit` (`preflight`, `route`):**
   - Nếu cho phép và có `additional_context` (hoặc `injectSteps`):
     ```json
     {
       "hookSpecificOutput": {
         "hookEventName": "UserPromptSubmit",
         "additionalContext": "[HARNESS-ESO PREFLIGHT] ..."
       }
     }
     ```
   - Nếu chặn (`permission === 'deny'`):
     ```json
     {
       "decision": "block",
       "reason": "<user_message || agent_message>"
     }
     ```

2. **Với `PreToolUse` (`guard-shell`, `guard-write`, `guard-brain`, `route`):**
   - Nếu chặn (`permission === 'deny'`):
     ```json
     {
       "hookSpecificOutput": {
         "hookEventName": "PreToolUse",
         "permissionDecision": "deny",
         "permissionDecisionReason": "<agent_message || user_message>"
       }
     }
     ```
   - Nếu cho phép kèm ngữ cảnh (`additional_context`):
     ```json
     {
       "hookSpecificOutput": {
         "hookEventName": "PreToolUse",
         "permissionDecision": "allow",
         "additionalContext": "<additional_context>"
       }
     }
     ```
   - Nếu cho phép bình thường:
     ```json
     {
       "hookSpecificOutput": {
         "hookEventName": "PreToolUse",
         "permissionDecision": "allow"
       }
     }
     ```

3. **Với `PostToolUse` (`gap-tracker`, `post-tool-hint`):**
   - Nếu có gợi ý (`additional_context`):
     ```json
     {
       "hookSpecificOutput": {
         "hookEventName": "PostToolUse",
         "additionalContext": "<additional_context>"
       }
     }
     ```
   - Nếu không có gợi ý: trả `{}`.
