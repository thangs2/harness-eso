---

## 1. "Advance" nghĩa là gì

Không phải thêm feature rời rạc, mà là **đổi trục**: từ "một bộ adapter cố định" sang **fabric có
thể chọn nguyên liệu theo từng host**.

| Trục | Hiện tại (before) | Advance (to-be) |
|---|---|---|
| Nguồn evidence | 1 adapter id trong policy | **chain**: native → external → none, có health và lý do |
| Memory | agentmemory hoặc noop | **native của host** (session/projection) hoặc agentmemory, chọn được |
| Law/Code | docgraph/codegraph | thêm native (skills, index, session query) |
| Verifier | JEV global mode | **VerifierPort** theo claim (`route`/`guard`), shadow/active theo binding |
| Host | cursor/agents/claude | + **DSH** (plugin), sau đó Paseo |
| Chất lượng | check generic | + check `contract` / `tenant` / `migration` |
| Vận hành | profile JSON | + **recipe**, `capability probe`, conformance H0–H4 |

## 2. Mốc

### M1 — Provider fabric (đã xong)

- [x] Provider descriptor: `capability` (`native|external|noop`), `ceiling`, `healthCheck`.
- [x] `createSourceRegistry(policy, extra, {health})` hỗ trợ chain `prefer`/`fallback`, `none`.
- [x] `resolveWithReason()` trả `native | id:<x> | none | exhausted | disabled` để trace được.
- [x] Bỏ self-gating khỏi memory adapter: `enabled()` chỉ trả lời "được phép dùng", registry chọn.
- [x] Sửa bug tiềm ẩn `stem` → `ctx.stem` trong `runCollect` (chỉ lộ ra khi memory bật).
- [x] Test: `qc/provider-resolution.test.mjs` (6 case) + toàn bộ suite 7/7.

**Exit:** policy cũ (`adapter: "docgraph-cli"`) không đổi hành vi; chain chọn đúng native/fallback.

### M2 — DSH host shim (đang làm)

- [x] `@mu/harness-host-dsh`: provider layer, dependency-free
      (`createDshSessionMemory` — provenance `sessionId`/`seq`, ceiling 0.65).
- [x] `probeCapabilities()` trong core: báo cáo per kind (selected, reason, candidates).
- [x] Bridge Claude-hook: `harnessctl dsh bridge --out <dir>` sinh bundle
      (`package.json` + `cordis.patch.yml` + `README.md`), validate `configPath` tương đối.
- [x] Test: 5 case (patch, từ chối absolute, YAML quote, bundle files, readme).
- [x] `createHostRuntime()` trong core: seam để shim bind provider rồi gọi `preflight()`; forward
      `registry` vào `orchestrateTurn` (trước đó thiếu, nên native provider sẽ bị bỏ im lặng).
- [x] `createDshEsoPlugin({ root, policy, searchEvents })`: đăng ký `native:dsh-session`, expose
      `preflight()` + `probe()`; test 5 case (native được dùng, không có shim thì `none`).
- [ ] `apply(ctx, config)` wrapper của Cordis — chờ DSH surface thật, không đoán API.
- [ ] Chạy thử bundle trong DSH thật (cần quota DSH) — chưa chạy diagnostic.
- [ ] `native:dsh-skills` (law).

**Exit:** `DSH + ESO` chạy preflight + guard + evidence; memory chọn native hoặc agentmemory bằng policy.

### M3 — Recipe + probe + conformance

- [x] Dữ liệu probe (`probeCapabilities`, test 3 case).
- [x] `harnessctl capability probe [consumer] [--provider m.mjs] [--json]` — render selected/reason/
      candidates; `--provider` nạp provider của host shim (test 3 case).
- [x] Memory giữ tính **opt-in**: provider `requireExplicit` không được chọn bởi default path, nên
      consumer chưa cấu hình memory vẫn resolve `none` (không tự gọi agentmemory).
- [x] `profiles/recipes/{lite,pro,dsh-native}.json` + loader (`validateRecipe`, `applyRecipe`,
      `listRecipes`); mảng `prefer`/`fallback` **thay thế** khi merge, không nối.
- [x] `capability probe --recipe <id>` áp recipe trước khi probe (test 1 case).
- [x] `profiles/standards/host-conformance.v1.json` + `harnessctl verify host` (H0–H4, read-only).
      H4 là **optional** trừ khi `--require-native`; consumer không có shim vẫn đạt H3.
- [x] Chạy thật trên consumer: H0–H3 pass, H4 skip (chưa có shim), `tierReached = H3`.
- [ ] `airgapped` recipe (nếu cần).

### M4 — VerifierPort

- JEV thành provider theo claim (`route.tie_break`, `guard.shell`), mode `shadow|active` theo binding.
- Budget paid-call dùng chung với Reasoner; ledger ghi `shadow_diff`.

### M5 — Check nâng cao (đang làm)

- [x] `contract-diff` (OpenAPI subset): path/method/status/schema field/type changes → breaking findings.
      Deterministic, không suy diễn layout repo; phần ngoài subset bị bỏ qua thay vì đoán.
- [x] `harnessctl check contract <before.json> <after.json> [--direction response|request] [--json]`.
- [x] `tenant-isolation`: quét statement trên bảng do caller khai báo (`--tables`), báo
      `query-without-tenant` / `insert-without-tenant`; marker `/* tenant:global */` là quyết định,
      không phải finding. CLI: `harnessctl check tenant <file...> --tables ...`.
- [x] `migration-safety`: `drop-table`/`drop-column`/`rename`/`type-change`/`set-not-null`/
      `add-not-null-without-default`; marker `/* breaking:approved */` cho ngoại lệ đã review.
      CLI: `harnessctl check migration <file...>`.
- [ ] Chỉ chặn `hard_blockers`; bỏ ngưỡng score 0–1 khỏi đường gating.

### M6 — Paseo / multi-agent (sau)

- `identity = (host, worktree, agent, session, turn)`; ProtocolShim.
