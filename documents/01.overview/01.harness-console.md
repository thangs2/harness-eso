# Harness Console (`:8791`)

The **Harness Console** (`:8791`) is the **write-side** management interface, intentionally separated from the read-only **Observatory** monitor (`:8792`).

```bash
./harness console   # Starts Console at http://127.0.0.1:8791
```

## Why Console and Observatory Are Separate

A monitor that can mutate the state it displays is a monitor whose audit log cannot be trusted.
* **Console (`:8791`)** handles all mutations: onboarding consumer repositories, running `init profile`, updating `.harness/decision-policy.json`, and granting **Human Consent** (`~/.harness/consent/<projectId>.json`).
* **Observatory (`:8792`)** is strictly read-only: it ingests IDE hook traces and transcripts into SQLite and renders per-turn telemetry.

## Product State Layout (`~/.harness/`)

Console reads and writes machine-wide product state under `HARNESS_PRODUCT_STATE_DIR` (defaults to `~/.harness/`):

```text
~/.harness/
  ├── workspace.json          # Active default project
  ├── tenants.json            # Tenancy registry
  ├── projects/
  │   ├── x79.json            # One JSON file per registered project
  │   └── baplatform.json
  ├── consent/
  │   └── x79.json            # Human consent records written only by Console
  └── attest/
      └── x79.json            # ESO preflight/gap attestations
```

* **One project = one file** (`projects/<id>.json`).
* The project `id` is generated once at creation (slugified from the name) and is **immutable**.
* In Docker deployments, `~/.harness` is mounted into the container at `/data/product-state`.

## 4-Step Onboarding Wizard

1. **Create New Project:** Enter the project identifier/name (e.g., `x79`).
2. **Configuration:** Set the consumer repository root path, observe port, and display name.
3. **Integrations:** Enable Recon & Brain plugins (`docgraph-cli`, `codegraph-cli`, `agentmemory-mcp`, `deepseek-mcp`).
4. **Preview & Initialize:** Review the dry-run file plan (`--plan`) and apply provisioning to the consumer repository.

After provisioning, run `./harness up` (if not already running) and open the **Observatory** at **http://127.0.0.1:8792**.
