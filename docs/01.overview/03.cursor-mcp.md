# Cursor MCP — harness-eso only

Config **riêng** với x79: `.cursor/mcp.json` (mẫu: `mcp.example.json`).

## Servers

| Server | Mục đích |
|--------|----------|
| `codegraph` | Index **harness-eso** (`--path` = repo root). Tool: `codegraph_explore`. |
| `agentmemory-mcp` | `memory_smart_search`, `memory_save` — HTTP `:3111`. |
| `deepseek-direct` | `ask_deepseek_flash`, `ask_deepseek_pro` — cài từ `x79/installation/deepseek`. |

> **Lưu ý:** `docgraph` chạy trực tiếp bằng global CLI (`docgraph --q "<terms>"`), không chạy qua MCP để loại bỏ dependency thừa và tránh đứt kết nối daemon stdio.

**Isolation:** codegraph index = product repo; docgraph repo = consumer (spec shards). Không dùng `x79/.cursor/mcp.json` trong window harness-eso.

## Bật trong Cursor

1. **Settings → MCP** → project config hoặc copy `mcp.json`.
2. Sửa đường dẫn tuyệt đối (`harness-eso`, `x79`, `bun`, `deepseek_direct.js`) nếu clone khác máy — xem `mcp.example.json`.
3. Codegraph index:

```bash
cd /path/to/harness-eso && codegraph init -i
```

4. Docgraph global CLI trên x79 / máy host (nếu chưa): `bash ../x79/installation/docgraph/install.sh` trong clone x79.
5. AgentMemory + DeepSeek: service `:3111` và `installation/deepseek/install.sh` trên máy operator.
6. **MCP: Restart Servers** sau đổi config.

## Isolation

- Window **harness-eso** → rules/skills/MCP **chỉ** từ repo này (`core.workspace-isolation.mdc`).
- Window **x79** → `x79/.cursor/mcp.json` (codegraph trỏ x79, không trộn).
