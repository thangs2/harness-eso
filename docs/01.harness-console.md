# Harness Console (8791)

Tách khỏi Observatory monitor (`:8792`).

```bash
./harness console   # http://127.0.0.1:8791
```

## Lưu project (đơn giản — file JSON)

Một thư mục trên máy (cùng chỗ với `workspace.json`):

```text
harness-eso/.harness/
  workspace.json
  tenants.json
  projects/
    x79.json
    baplatform.json
```

- Mỗi dự án = **một file** `projects/<id>.json`
- `id` sinh **một lần** khi tạo (slug từ tên), **không đổi**
- Thư mục `.harness/` đã **gitignore** — state local sau clone
- Docker observe mount `.harness` → `/data/product-state` (cùng volume với workspace)

Console đọc/ghi qua `HARNESS_PRODUCT_STATE_DIR` (mặc định: `harness-eso/.harness`).

## Wizard

1. Create new project — chỉ nhập **tên** (vd. `x79`)
2. Cấu hình — root, port, tên hiển thị
3. Tích hợp — plug-in
4. Preview → Khởi tạo

Sau đó: `./harness up` → monitor `:8792`.
