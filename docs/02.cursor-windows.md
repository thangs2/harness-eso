# Cursor on Windows — harness-eso

## 1. Layout on disk

Clone siblings under one parent (example):

```text
C:\Users\<you>\Workspaces\
  harness-eso\     ← open this folder in Cursor (product)
  x79\             ← consumer MSX; mount for Observatory
```

Cursor: **File → Open Folder** → `harness-eso` only. Agent law chain: **rules → `core.law-gate` → Read `AGENTS.md`** (see `.cursor/instructions.md`).

## 2. Prerequisites

- **Git** · **Docker Desktop** (WSL2 backend recommended)
- **Bun** for Windows ([bun.sh](https://bun.sh)) — `bun install`, `bun test`, `bun run build:observatory`
- Optional: **Node** if any script expects it (CLI uses `node` for `cli.mjs`)

PowerShell execution policy may block scripts; prefer:

```powershell
powershell -ExecutionPolicy Bypass -File .\docker\observatory.ps1 up C:\Users\<you>\Workspaces\x79
```

Or use **Git Bash** / **WSL** with `./docker/observatory.sh` if you keep a Unix shell.

## 3. Environment (session)

```powershell
$env:HARNESS_REPO_ROOT = "C:\Users\<you>\Workspaces\x79"
$env:HARNESS_AGENT_ROOT = "C:\Users\<you>\Workspaces"
# Cursor transcripts (default):
# $env:HARNESS_CURSOR_HOME = "$env:USERPROFILE\.cursor"
```

Then from `harness-eso`:

```powershell
.\docker\observatory.ps1 build
.\docker\observatory.ps1 up $env:HARNESS_REPO_ROOT
.\docker\observatory.ps1 health
.\docker\observatory.ps1 smoke
```

UI: http://127.0.0.1:8792

## 4. MCP (harness-eso window only)

Use **this repo’s** `.cursor/mcp.json` — not x79’s (`codegraph` → harness-eso, `docgraph` → x79 law, `agentmemory-mcp`, `deepseek-direct`). See `docs/03.cursor-mcp.md` and run `cd .cursor/mcp && bun install` once.

## 5. What not to mix

| Window | Repo | Purpose |
|--------|------|---------|
| Cursor A | **harness-eso** | Observatory, observe-server, hooks packages |
| Cursor B | **x79** | mu services, Angular, `sdlc/`, consumer `.harness/` |

Do not re-add `tools/harness` or full ESO IDE hooks on x79 unless you intentionally change consumer policy.

## 6. Verify after changes

```powershell
cd C:\Users\<you>\Workspaces\harness-eso
bun test
bun run build:observatory
.\docker\observatory.ps1 build
.\docker\observatory.ps1 restart $env:HARNESS_REPO_ROOT
```
