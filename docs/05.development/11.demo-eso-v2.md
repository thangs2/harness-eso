# Demo ESO v2 — control plane end-to-end

**Một lệnh, 11 check, không cần consumer thật.** Demo dựng DB tạm, seed config + evidence, chạy NestJS/Fastify thật rồi gọi HTTP như operator.

> Đây là demo **hành vi đã fix**, không phải bộ test đầy đủ. Bộ đầy đủ là `bun run test` (16 suite, 1103 qc + 224 eso).


## 2. Serve mode — tự tay curl / mở browser

```bash
node scripts/demo-eso-v2.mjs --serve --port=8787
# hoặc: bun run demo:eso:serve
```

Script in ra:

```text
[demo] control plane: http://127.0.0.1:8787
[demo] token:         demo-token
[demo] project:       demo
[demo] DB:            /tmp/eso-demo-XXXX/demo.sqlite

Open:
  http://127.0.0.1:8787/work-overview?project=demo
```

### Curl mẫu

```bash
# public
curl -s http://127.0.0.1:8787/health

# 401 — không token
curl -s -o /dev/null -w '%{http_code}\n' \
  'http://127.0.0.1:8787/config?project=demo'

# 200 — có token
curl -s -H 'Authorization: Bearer demo-token' \
  'http://127.0.0.1:8787/config?project=demo'

# S1 HTML — phải thấy cột Việc có dữ liệu, data-state="READY"
curl -s -H 'Authorization: Bearer demo-token' \
  'http://127.0.0.1:8787/work-overview?project=demo'
```

Mở browser `http://127.0.0.1:8787/work-overview?project=demo`:

- 2 dòng: `sửa cột tenants` (partial, 2 thiếu) và `thêm endpoint` (sufficient).
- Không có nút ghi — S1 chỉ đọc.
- `[Vì sao]` là đường sang S2.

Ctrl-C để dừng; DB giữ lại ở đường dẫn in trên để mở bằng `sqlite3` nếu cần.

## 3. 11 check chứng minh gì

| Check | Ticket | Chứng minh |
|---|---|---|
| `health 200` | ESO-370 | NestJS + Fastify sống, health contract |
| `config` no token → 401 | ESO-370 | Auth **fail-closed**, không còn fail-open |
| `config` with token khớp store | ESO-369 | Đọc đúng version/hash/config |

| preview trả hash | ESO-369 | Preview có hash thật |
| save đúng hash → v2 | ESO-369 | Version +1, hash đổi |
| stale `current_hash` → 409 | ESO-369 | Optimistic lock |
| S1 200 + work value | ESO-380 | Page thật, cột Việc có dữ liệu, không XSS |
| S1 no token → 401 | ESO-380 | Surface không lộ dữ liệu |

## 4. Demo **không** làm gì

- Không chạm consumer thật / `x79`; mọi DB nằm trong `/tmp`.
- Không ghi `comments/artifacts` (tmp evidence folder).
- Không dựng Angular SPA dev server; S1 trong demo là HTML do Nest render. UI Angular build/typecheck nằm trong `bun run test`.
- Không dùng Postgres/Kysely — demo dùng SQLite in-memory/file để chạy một lệnh, không cần service ngoài.
- Không thay thế `bun run test`, Jira hay SLP.

## 6. Troubleshooting

| Lỗi | Cách sửa |
|---|---|
| `dist/main.js is missing` | bỏ `--no-build`, hoặc `cd eso/control-plane && npm run build` |
| `tsc: command not found` | `bun install` ở root (workspaces gồm `eso/*`) |
| `EADDRINUSE` | `--port=8788` hoặc port khác |
| DB locked | dừng serve cũ; mỗi lần chạy tạo temp dir mới |
| `bun install` lỗi lockfile | `bun install` (không `--frozen-lockfile`) rồi chạy lại |
