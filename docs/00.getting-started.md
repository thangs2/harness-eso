# Bắt đầu — harness-eso

Console **8791** (quản lý dự án) · Monitor **8792** (Observatory).

```text
git clone https://github.com/thangs2/harness-eso.git
cd harness-eso
./install.sh
./harness up
```

**Quản lý dự án:** `./harness console` → http://127.0.0.1:8791 (wizard, lưu tại `.harness/projects/*.json`).

Hoặc CLI trước `up`:

```bash
bun run harnessctl configure add ~/Workspaces/x79 --id x79
./harness up
```

IDE: mở thư mục agent, prompt bình thường.

## Cấu hình nằm ở đâu

| Nơi | Nội dung |
|-----|----------|
| `harness-eso/.harness/projects/<id>.json` | Một file / dự án (Console) |
| `harness-eso/.harness/workspace.json` | Dự án đang chạy observe (gitignore) |
| Repo agent | `harness.config.json` + `.harness/` — **tool tạo**, không sửa tay |

Repo agent phải nằm dưới thư mục **`~/Workspaces`** (mặc định) để Docker ghi file khi cấu hình qua web. Đổi: `export HARNESS_AGENT_ROOT=/path/to/parent` trước `./harness up`.

## Đổi dự án mặc định

Tab **Dự án** → **Chọn mặc định** → trong `harness-eso`: `./harness restart`.
