# Operator flow — harness-eso (Docker only)

**Không** dùng `scripts/dev-observe.sh` khi test sản phẩm. Thứ tự **bắt buộc**:

| Bước | Script | Process | Kết quả |
|------|--------|---------|---------|
| **00** | `00.docker-check` | Kiểm tra Docker daemon + `bun` | Exit 0 hoặc dừng |
| **01** | `01.observatory-up` | `observatory build` + `harness up` + `/health` | http://127.0.0.1:8792 |
| **02** | `02.console-up` | Console Docker (`-d` :8791); dừng dev local trên cổng | http://127.0.0.1:8791 → init consumer |
| **03** | `03.verify-observatory` | `/health` + `/api/tenant` | Xác nhận trước prompt IDE |

Sau **02** (provision x79): reload Cursor trên consumer → prompt → **03** hoặc mở Observatory Requests.

## macOS / Linux

```bash
cd ~/Workspaces/harness-eso/docker/process
./00.docker-check.sh
./01.observatory-up.sh
# terminal mới:
./02.console-up.sh
# sau init + prompt trên x79:
./03.verify-observatory.sh
```

## Windows (PowerShell)

```powershell
cd ~\Workspaces\harness-eso\docker\process
.\00.docker-check.ps1
.\01.observatory-up.ps1
# terminal mới:
.\02.console-up.ps1
.\03.verify-observatory.ps1
```

Env tùy chọn: `HARNESS_AGENT_ROOT` (mặc định `~/Workspaces`), `HARNESS_OBSERVE_PORT` (8792).
