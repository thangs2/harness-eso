# The cross-check catalogue — twenty-nine **cross-checks** — the whole point of this file

**A status claim is invalid unless all twenty-nine pass.** Each is a command, not a judgement.

| id | Proves | How | What it catches |
|---|---|---|---|
| **X1** | every link resolves | quét **mọi** `.md` và `.mdc` trong repo, **kể cả thư mục ẩn**; `qc/links.test.mjs` | renamed/deleted files still referenced — và một check có phạm vi hẹp hơn lỗi thì báo xanh |
| **X2** | header per zone | HUMAN: `sot_doc_version` · `source_of_truth` · `status` · `phase` · AI: `human_sot` | documents with no provenance |
| **X3** | `AC` ↔ `SCN` 1:1 — **`SCN` chỉ thuộc `AC`**; test biên (idempotent · isolation · boundary) sống ở §7 của packet với đường dẫn `qc/*.test.mjs`, **không** cần `SCN` riêng | every `AC` id appears in a scenario row's `ac_ref`; no row cites a missing `AC` | an AC added after its matrix |
| **X4** | trace up and down | every `US` cites `UC` + `REQ`; every `P` has a `REQ` | invented requirements; orphan stories |
| **X5** | agent-spec budget | `wc -l` ≤ 150 · `wc -c` ≤ 4 000 | a spec the agent skips |
| **X6** | id uniqueness | chỉ đếm dòng **định nghĩa** (≥6 cột) — bảng lý do 2 cột lặp id là hợp lệ | một id chỉ đúng một dòng |
| **X7** | shape per `type` | for each file: read `type:` → take the required headings from [`03` §2](02.artifacts.md) → check each heading exists | a "user story" with no AC section |
| **X8** | packet per slice | every item has `BIP`/`FIP` or an `OUT` with a reason **and** the number of leaves without a packet equals the recorded debt | a slice that can never be implemented; a folder with 5 packets for 56 leaves passing a check that only looks for *a* packet |
| **X8a** | **task ↔ criterion** | every one of the **349 `AC`** claimed by **≥ 1** work package, and a second claim **only** where it is declared as a split; every package has the 7 fields or `OUT` | behaviour with no owner; a task nobody can be handed |
| **X9** | API ↔ data round trip | every endpoint names **real tables**; every table has **a path from** an endpoint, or an `OUT` with a reason | an endpoint writing to a table nobody defined, and a table nothing can reach |
| **X10** | reference layer has a **revision rule** | each document in `07.technical/` — `01.architecture/` · `02.data-design/` · `03.api/` — states **what change makes it wrong**; `00.index.md` excluded | a contract or a table drifting silently while every slice is built against it |
| **X11** | **every `UC` has ≥ 1 `US`** *and* **≥ 1 `BRD`** | count `UC-*` in the catalogue, grep `US` files and `00.*-narrative/` for each id | a use case nobody serves — the behaviour is described and **nobody owns it**; or a use case with **no narrative**, so the *why* is nowhere |
| **X12** | **every `UC` alternate flow is named by ≥ 1 `AC`** | alternate flows carry ids (`UC-14.1a`); each id must appear in an `AC` file | a branch that was designed and **never tested** |
| **X13** | **≥ 2 catalogue edges per `US`** (`ED1…ED10`) | count edge criteria per US; each must cite `ED1…ED10`, or the US records `OUT` + reason | a story whose only boundary is the first one someone thought of |
| **X14** | **surface is designed only when prototyped** | for each surface: ≥1 wireframe · all **6** states (`ST1…ST6`) · ≥1 flow whose steps each name an `AC` | a screen described by name only, with no empty/loading/error/denied states and no behaviour |

| **X16** | **gia đình đặc tả đủ** | 5 thư mục `01.prd`…`05.nfr-spec` tồn tại, mỗi cái có `00.index.md` **và** index trỏ tới **mọi** file nội dung | xoá cả một loại tài liệu; một file không ai đọc vì index không trỏ tới |

| **X22** | **mọi `OPEN` của packet được phân loại** | §8 của từng packet đối chiếu [`13.open-mapping`](../sdlc/06.analysis/04.quality-control/13.open-mapping.md) §2 | một mục treo không ai nhận — nó biến mất khỏi mọi danh sách |
| **X23** | **mục treo ↔ quyết định, hai chiều** | `13.open-mapping` §2 ↔ `D-63` §4; rỗng là hợp lệ, nhưng hai bên phải khớp | một quyết định được đề xuất mà không đóng mục nào — hoặc ngược lại |
| **X24** | **số trong register = số trong cây** | đếm `AC` · `SCN` · `NFR` · endpoint bằng `grep` rồi so với `03` | con số viết tay trôi khỏi cây — đã xảy ra bốn lần trong một ngày |

| **X28** | **mọi đường dẫn được nêu đều tồn tại** | quét **mọi** file văn bản (`.md` `.mdc` `.mjs` `.json` `.yml` `.sh` Dockerfile) tìm `docs/…`; `qc/links.test.mjs` | đường dẫn viết trong **code** hoặc rule trỏ vào file đã mất — X1 mù ở đó |

**Which of these are actually commands.** Eighteen have a test behind them: **X1 · X3 · X7 · X8 · X9 · X10 · X16–X27**.
The other nine — **X2 · X4 · X5 · X6 · X11 · X12 · X13 · X14 · X15** — are still done by hand. X2 is that way by design
(`HUMAN:`). The remaining eight are **debt**: this file promises *"each is a command, not a judgement"*, and eight of them are
prose. A check nobody runs is a sentence.

**X1 was the worst of them** — the first row of the table, the one everything else stands on, and it had **no test at all**
until now. Its absence has a shape: the scan everyone assumed existed used `glob`, which does not descend into dot-directories,
and read only `.md`. So `AGENTS.md` could point at a path that had not existed for weeks and nothing noticed. The check now
walks the whole repo, `.md` and `.mdc`, hidden directories included — because a check whose **scope is narrower than the error's**
reports success.

X21 earned its place on its first run: it caught a duplicate `02.` that **this pass had just introduced** while fixing a
duplicate `03.`.

**X16–X20 are automated** by [`qc/specification.test.mjs`](../qc/specification.test.mjs). Each was falsified once before
being trusted: removing `12.debt-accept.md` names **`F-12`**, removing `04.srs/` names **`04.srs/ — the whole SRS is
absent`**, removing one metric names **`G-D`**.

**X3 and X4 are the two that catch the errors actually made here:** an AC added without a scenario, and a US that traces to nothing.

## Recording a result

| Column | Rule |
|---|---|
| `measured` | **a date**, from the run |
| `command` | the exact command — so it can be re-run |
| `result` | the **number**, not "ok" |
| `fails` | the **count of violations**, never a list of names only |

**A cell without a date and a command is not evidence.** "Checked" is not a result.

## Why this lives in the standard and not in a project

These twenty-nine checks are **law**, so they ship with harness-eso and apply to every project the standard governs. The file
they came from — `sdlc/02.governance/01.document-status.md` — is this project's **measurement**: which checks passed, on what
date, with what counts. Law left behind in an instance reaches nobody who is not that instance.

The machine lives in `qc/*.test.mjs`. This file says **what must hold**; the tests say **how it is found out**; the instance
register says **what the last run measured**. Three places, three jobs, and no fact stored twice.
