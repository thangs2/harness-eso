# 01 — Contracts: C1 ↔ C2, và cái gì **không** nằm trên đường turn

**Nguồn:** [`c4/02`](../07.architecture/c4/02.container.md) · [`D-46`](../03.inception/02.decision-log/00.index.md) · [`D-47`](../03.inception/02.decision-log/00.index.md)

## 1. Khẳng định quan trọng nhất: **không endpoint nào trên đường turn**

| | |
|---|---|
| Judgement dùng **hiện trạng cục bộ** ([`D-46`](../03.inception/02.decision-log/00.index.md)) | ⇒ C1 **không** gọi C2 khi phán |
| Cache khai báo làm mới **khi provision** ([`D-24`](../03.inception/02.decision-log/00.index.md)) | ⇒ không có endpoint "pull" mỗi turn |
| Evidence ghi **outbox trước**, ship sau ([`D-20`](../03.inception/02.decision-log/00.index.md)) | ⇒ ship là **off-path** |

**Kiểm được:** đường turn **không** có lời gọi mạng. Test: chạy turn với C2 **tắt** ⇒ phán quyết vẫn ra, **mức bảo đảm hạ**,
và **không** có lỗi.

## 2. Bốn endpoint — và **tất cả** đều off-path

**Sáu cho evidence/declaration/graph/sức khoẻ · sáu cho IAM · sáu cho config/SDLC · một cho ticket · hai cho learning.** Không có endpoint nào cho "phán quyết" — vì phán quyết
**không** gọi mạng.

## 3. Hợp đồng từng endpoint

### E1 · `POST /v1/evidence:batch`

```json
{
  "project": "baplatform",
  "batch_id": "uuid",
  "items": [
    {
      "turn_id": "uuid", "seq": 1,
      "at": "2026-10-25T12:00:00Z",
      "actor": { "role": "lead", "status": "FULL" },
      "level": "partial", "mode": "ask", "basis": "retrieved",
      "payload": { "requirements": [], "answers": [], "elections": [], "files_used": [] }
    }
  ]
}
```

| | |
|---|---|
| **200** | `{ "accepted": n, "duplicates": m }` — trùng **không** phải lỗi ([`D-47`](../03.inception/02.decision-log/00.index.md)) |
| **400** | thiếu `project` · thiếu `turn_id` |
| **403** | `project` không khớp phạm vi của credential |
| **409** | `turn_id` đã có với `payload` **khác** — cùng khoá, khác nội dung: **dừng**, không ghi đè |
| **503** | C2 chết ⇒ C1 **giữ** outbox, thử lại; **không** mất dữ liệu |

**`409` là chỗ đáng chú ý:** idempotent theo khoá, **nhưng** cùng khoá mà nội dung khác thì **không** được coi là trùng. Đó là
lỗi lập trình, và nuốt nó là nuốt bằng chứng.

### E2 · `POST /v1/declarations:sync`

| | |
|---|---|
| Chiều **in** | file → DB, rồi DB → file (out) — thứ tự [`D-24`](../03.inception/02.decision-log/00.index.md) |
| **200** | `{ "in": n, "out": m, "conflicts": [] }` |
| **409** | có xung đột ⇒ **dừng**, trả danh sách; **không** chọn bên thắng ([`D-23`](../03.inception/02.decision-log/00.index.md)) |

### E3 · `GET /v1/diagnosis?project=…&turn=…`

Trả câu trả lời cho A-01/A-08, **kèm `unknowns[]`** ([`AC-SUF-02-03`](../06.analysis/03.acceptance-criteria/02.suf-us-02-operator.md)).

### E4 · `GET /v1/projections/{name}`

`name` ∈ `turns` · `risks` · `graph` · `audit`. **UI không chạm bảng** ([`D-47`](../03.inception/02.decision-log/00.index.md)).

### E5 · `POST /v1/graph:batch`

C1 ship kết quả C5. Kèm `build_id` + `completeness` **theo từng câu hỏi** ([`c4/03`](../07.architecture/c4/03.component.md) C5.3).

### E7 · `POST /v1/workers`

```json
{ "project": "baplatform", "worker_id": "uuid?", "role": "build",
  "harness_source": "eso-native", "state": "active" }
```

| | |
|---|---|
| **200** | `{ "worker_id": "…", "state": "active", "open_risks": [] }` |
| **200 khi nghỉ** | `"state": "retired"`, **`open_risks`** = risk đã tạo cho việc đang dở ([`AC-IAM-01-02`](../06.analysis/03.acceptance-criteria/05.iam-us-01-workers.md)) |
| **400** | `role` không có trong project ⇒ `UNKNOWN_ROLE` |
| **403** | `project` không khớp credential |

**Nghỉ mà đang có việc dở ⇒ trả `open_risks`, không im lặng.** Đó là toàn bộ lý do endpoint này trả về risk.

### E8 · `POST /v1/roles`

```json
{ "project": "baplatform", "name": "build",
  "capabilities": ["be"],
  "scope": [ { "verb": "write", "kind": "file", "value": "packages/**" },
             { "verb": "append", "kind": "evidence", "value": "*" } ],
  "bar": [ { "evidence_kind": "slice-table", "min_basis": "retrieved" } ] }
```

| | |
|---|---|
| **200** | `{ "name": "build", "version": 7 }` — **append version**, không `UPDATE` |
| **400** | `bar` rỗng ⇒ `EMPTY_OBLIGATION` · `verb` ngoài tập đóng ⇒ `UNKNOWN_VERB` |
| **403** | không phải `operator` ⇒ `ROLE_CHANGE_FORBIDDEN` |

`verb` là **tập đóng** ([`D-48`](../03.inception/02.decision-log/00.index.md)): cơ chế không cưỡng chế được động từ nó không có tên.

### E9 · `POST /v1/policies`

```json
{ "project": "baplatform", "policy_id": "uuid?",
  "attribute": "path", "operator": "starts_with", "value": "packages/",
  "effect": "deny", "subjects": ["build"] }
```

| | |
|---|---|
| **200** | `{ "policy_id": "…", "version": 3 }` |
| **400** | `attribute` **ngoài tập đóng** ⇒ `UNKNOWN_ATTRIBUTE` — **từ chối khi lưu**, không phải khi chạy ([`AC-IAM-03-03`](../06.analysis/03.acceptance-criteria/07.iam-us-03-policies.md)) |
| **403** | không phải `operator` ⇒ `POLICY_CHANGE_FORBIDDEN` |

**Không có đường nào cho agent** — kể cả gián tiếp, vì hành động này **chỉ** role `operator` gọi được ([`D-48`](../03.inception/02.decision-log/00.index.md) §"chặn ở hành động").

### E10 · `POST /v1/flows`

```json
{ "project": "baplatform", "from": "verify", "to": "audit",
  "carries": ["diff", "rubric"] }
```

| | |
|---|---|
| **200** | `{ "from": "verify", "to": "audit", "carries": ["diff","rubric"] }` |
| **400** | vai không tồn tại ⇒ `UNKNOWN_ROLE` |

**Kiểm điều kiện bàn giao xảy ra ở C1**, không ở endpoint này — bàn giao là hành động **cục bộ** trong turn
([`AC-IAM-04-02`](../06.analysis/03.acceptance-criteria/08.iam-us-04-flows.md)). E10 chỉ **khai** flow.

### E11 · `POST /v1/risk:event`

```json
{ "project": "baplatform", "risk_id": "uuid", "seq": 3,
  "event": "accept", "by": "thangs2net@gmail.com",
  "due": "2026-11-08", "reason": "chấp nhận trong sprint này" }
```

| | |
|---|---|
| **200** | `{ "risk_id": "…", "state": "accepted", "due": "…" }` |
| **400** | `accept` thiếu `due` ⇒ `ACCEPT_WITHOUT_DUE` · `renewed` mà `due` ≤ `due` cũ ⇒ `DUE_NOT_EXTENDED` |
| **403** | role không có quyền `accept` cho `kind` đó ⇒ `ACCEPT_FORBIDDEN` |
| **409** | `(risk_id, seq)` đã có với nội dung khác |

**Đây là đường ghi DUY NHẤT của người vào evidence.** Nó **append**, không `UPDATE` ([`BR-06`](../06.analysis/01.business-analysis/03.business-rules.md)).

### E12 · `POST /v1/config:preview`

```json
{ "project": "baplatform", "change": { "group": "sdlc", "from": "…", "to": "…" } }
```

| | |
|---|---|
| **200** | `{ "hash": "sha256:…", "impact": { "consumers": [], "overrides": [], "artifacts": [] } }` |
| **400** | nhóm không thuộc **bốn nhóm** (`sdlc` · `team` · `tool` · `project`) ⇒ `UNKNOWN_GROUP` |

**`hash` là bắt buộc để lưu** — nó gắn preview với **đúng** thay đổi sẽ lưu ([`AC-IAM-06-02`](../06.analysis/03.acceptance-criteria/10.iam-us-06-config.md)).

| **409** | `sdlc_root` đổi mà **chưa** khai kế hoạch chuyển ⇒ `ROOT_CHANGE_UNPLANNED` ([`AC-CFG-01-02`](../06.analysis/03.acceptance-criteria/11.cfg-us-01-config-page.md)) |

### E15 · `POST /v1/sdlc:init`

```json
{ "project": "baplatform" }
```

| | |
|---|---|
| **200** | `{ "created": [], "existing": [], "out": [ { "artifact": "…", "reason": "no-frontend" } ] }` |
| **400** | thiếu khai báo (`sdlc_root`…) ⇒ `CONFIG_INCOMPLETE`; **0 file sinh** ([`AC-SDLC-01-02`](../06.analysis/03.acceptance-criteria/12.sdlc-us-01-setup.md)) |

**Idempotent:** chạy lại ⇒ `created: []`, `existing: [...]` ([`AC-SDLC-01-01`](../06.analysis/03.acceptance-criteria/12.sdlc-us-01-setup.md)).
**`out[]`** ghi phần **không khớp** `applies_when`, **không** im lặng ([`AC-SDLC-01-03`](../06.analysis/03.acceptance-criteria/12.sdlc-us-01-setup.md)).

**`init` PHẢI tạo các file quản trị** ([`03.artifacts` §2.0](../02.governance/01.standard/02.artifacts.md)): cây chuẩn ·
**`03.document-status.md`** · `04.open-register.md` · `01.agent-manifests/` · `02.quality-gate/`.
Thiếu bất kỳ file nào ⇒ `sdlc:init` trả **`SDLC_INCOMPLETE`** thay vì một cây dở dang — project **có tài liệu mà không có sổ trạng
thái** là một **folder**, không phải một **quy trình**.

### E17 · `POST /v1/sdlc:upgrade`

```json
{ "project": "baplatform", "preset_version": "0.2.0", "approved": true }
```

| | |
|---|---|
| **200** | `{ "impact": [], "applied": true, "reverted_by": null }` — nâng cho **tất cả** project dùng chuẩn đó ([`D-31`](../03.inception/02.decision-log/00.index.md)) |
| **403** | `approved` không có hoặc không phải `operator` ⇒ `APPROVAL_REQUIRED` |
| **409** | đang có thay đổi chưa lưu ⇒ `DIRTY_CONFIG` |

**Vì sao `upgrade` là endpoint riêng, không phải `config:save`:** nó **không** sửa một project — nó sửa **mọi** project dùng cùng chuẩn. Gộp vào `save` là cho một thao tác **diện rộng** đi qua cửa của thao tác **một project**.

### E18 · `POST /v1/ticket:pack`

```json
{ "project": "baplatform", "source": "jira", "key": "ESO-12" }
```

| | |
|---|---|
| **200** | `{ "source": "jira", "content_hash": "…", "pack": { "ac": [], "scope": [], "verify": "…", "forbidden": [], "missing": [] } }` |
| **200 thiếu** | `missing[]` **không rỗng** ⇒ pack được trả **kèm danh sách thiếu**; **không** bịa ([`AC-TICKET-01-02`](../06.analysis/03.acceptance-criteria/22.ticket-us-01-integration.md)) |
| **200 không tool** | `{ "source": "none", "pack": { "from": "local" } }` — `none` **được ghi** ([`AC-TICKET-01-03`](../06.analysis/03.acceptance-criteria/22.ticket-us-01-integration.md)) |
| **404** | ticket không có trong nguồn |
| **403** | `project` không khớp credential |

**Vì sao `missing[]` trả trong **200**, không phải lỗi:** ticket thiếu là **trạng thái bình thường**; cái sai là **đoán** phần thiếu.
Trả 400 sẽ khiến người ta bỏ qua và tự ghép.

**Vì sao `source: "none"` là kết quả hợp lệ:** không Jira/Notion ⇒ năng lực `external` rơi xuống `none`
([`D-48`](../03.inception/02.decision-log/00.index.md) · `REQ-HOST-03`); việc vẫn đến từ **file local**.

**`content_hash`** để `AC-ARCH-01`/evidence trả lời được *"pack lúc đó nói gì"*.

### E19 · `POST /v1/learning:propose`

```json
{ "project": "baplatform", "risk_kind": "missing-evidence", "window": "30d" }
```

| | |
|---|---|
| **200** | `{ "proposal_id": "…", "evidence[]": [], "expected_effect": "…", "revert": "…" }` |
| **422** | **thiếu `revert`** ⇒ `NO_REVERT` — đề xuất không lùi được thì **không được tạo** ([`AC-LEARN-01-02`](../06.analysis/03.acceptance-criteria/19.learn-us-01-propose.md)) |
| **404** | không đủ risk cùng `kind` để thành cụm |

**Vì sao `422` chứ không `400`:** dữ liệu **hợp lệ**, nhưng **không đủ điều kiện** để là một đề xuất — nó sẽ tạo ra thứ không
lùi được.

### E20 · `POST /v1/learning:apply`

```json
{ "project": "baplatform", "proposal_id": "…" }
```

| | |
|---|---|
| **200** | `{ "applied": true, "measure_from": "2026-10-25", "measure_to": "2026-11-24" }` — **mở cửa sổ đo** |
| **403** | không phải `operator` ⇒ `APPLY_FORBIDDEN` ([`AC-LEARN-01-03`](../06.analysis/03.acceptance-criteria/19.learn-us-01-propose.md)) |
| **409** | đề xuất đã áp ⇒ `ALREADY_APPLIED` |

**`measure_from/to` là phần bắt buộc của response:** áp xong **không** được tuyên bố hiệu quả — hiệu quả chỉ kết luận được sau
cửa sổ, và chỉ khi `unsat_rate` **giảm** **và** `defect_rate` **không tăng**
([`AC-LEARN-01-04`](../06.analysis/03.acceptance-criteria/19.learn-us-01-propose.md)).

## 4. Ba luật hợp đồng

| Luật | Vì sao |
|---|---|
| **Mọi request đọc/ghi đều mang `project`**, và nó được **kiểm** với credential | cô lập không thể là "tuỳ tham số" |
| **Không endpoint nào trả "phán quyết mới"** | phán quyết sinh ở C1; C2 chỉ **chứa** cái đã xảy ra |
| **Trùng ≠ lỗi; khác nội dung cùng khoá = lỗi** | outbox ship lại là bình thường; ghi đè bằng chứng thì không |
