# Ticket / SLP — capability spec

## Pack = what a peer receives
`{ac[], scope[], verify, forbidden[], missing[]}`
**Complete** ⇒ usable immediately. **Incomplete** ⇒ `missing[]` **non-empty**, and **never invent** the missing part.

## Three sources
`jira` · `notion` · **`local`** — and **`none`** is valid when neither exists.
No tool ⇒ work comes from a local file; `missing[]` says so if that is absent too.

## Three rules
- incomplete ticket ⇒ **200 + `missing[]`**, never 400 — a caller who gets an error will skip the pack and assemble context by hand
- **append-only**: the ticket changes ⇒ a new pack; the old one stays a true record of that reading (`content_hash`)
- an agent **may not** set the ticket to done ⇒ `DONE_FORBIDDEN`

## Wire
`E18 ticket:pack` · table `ticket_pack` (append-only, `project` leading key).
`tenant`: **N/A with a reason** — isolation comes from the partition.
