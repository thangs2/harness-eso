# Sufficiency — capability spec

## Verdict
`level` ∈ `insufficient` · `partial` · `sufficient` · `cannot-judge` · `unsurfaced`
`basis` ∈ `retrieved` · `verified` · `inferred` — **how it was known this time**, not "verified yesterday"

**Per requirement**, never one aggregate. An aggregate **hides** where it is thin.

## Inputs — **local**, never the record
files · git · graph cache · declaration cache · host capability
The evidence record is an **output**; usable as input only when a declaration grants **kind + TTL**.

## Four requirement sources
`bar` (role obligation) · `work` (ticket AC) · `blast` (affected neighbours) · `declared` (human)
An **empty `bar`** on an agent role is invalid.

## Three rules
- `sufficient` **never** without `basis`
- `cannot-judge` **never** becomes `permitted`; proceeding requires `bypassed` + human + expiry
- **`unknown` ≠ `absent`**: not found is not the same as not existing

## Warning (UC-13)
raise when `level < sufficient` **and** work is about to run · once per `(work, requirement)` · **never blocks** (blocking is `mode`'s job)

## "Why" (UC-09)
four parts: unmet requirements · missing evidence · the earlier conclusion · **`unknowns[]`**
Missing `unknowns[]` = **lying by omission**. No record ⇒ say **"no record"**, do not reconstruct.

## Wire
**0 endpoints on the turn path.** `E3 diagnosis` is read-only, off-path.
Table `evidence_turn` holds `level` · `mode` · `basis` · `rule_version`.
