# Architecture — capability spec

## 5 questions
Q1 which files to read · Q2 what breaks on a column change · Q3 module cycles · Q4 endpoint permissions · Q5 tenant boundary
**One query per question** — no question traverses unbounded.

## Coverage **per question**
`completeness(Q) = min { coverage(kind) : kind ∈ K(Q) }`
**`min`, not average** — a question is only as trustworthy as its weakest kind.

| `completeness` | What may be said |
|---|---|
| ≥ 0.95 | `absent` is **trustworthy** |
| 0.7–0.95 | `absent` is **weak** + state the coverage |
| **< 0.7** | **`unknown`** — may not say "does not exist" |

Thresholds are **data**, not constants.

## Three rules
- **per question** — one global `completeness` is **wrong** (Q1 high, Q5 low)
- **`unknown` ≠ `absent`** — low coverage ⇒ `unknown`
- **heavy queries off-path** — large build/traversal never on the turn path

## Wire
`E5 graph:batch` (C1 ships C5's output). Tables `graph_node` · `graph_edge`, `id` **stable** by logical name.
`rbac`/`tenant`: **N/A with a reason** — isolation comes from the `(project, build_id)` partition.
