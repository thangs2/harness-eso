# IAM — capability spec

## Roles open, verbs closed
- verbs (table `verb`, enforced): `read` `write` `append` `approve` `configure` `handoff`
- capability (open, user-named): `be` `fe` `qc` `design` `pm` `review` `lead` `p` …
- role = `capabilities[]` + `scope[(verb,kind,value)]` + `bar[]`; **1 or N**, no closed catalogue
- `bar` = **obligation**, not permission; empty on an agent role = invalid
- `role_presets[0]` = baplatform's 7 roles (a preset, **not** the mechanism)

## 6 functions
`US-IAM-01` workers (retiring with work in flight ⇒ `OPEN` risk) `02` roles `03` policies `04` flows
`05` accept (**needs `due`**) `06` config (preview hash → save → revert)

## Rules
- **deny-overrides** · authority = `role ∩ grant ∩ slice` (**intersection, never union**)
- only `operator` changes role/policy; agents blocked at the **ACTION** (covers the indirect path too)
- handoff **blocked** if the receiver's `bar` is unmet · `accept` without `due` ⇒ refused
- config saves only when the `hash` matches the preview · revert **moves the pointer** + marks artefacts
- authorisation decisions = `evidence_item` `kind=authz`, **never** a second table
- **0 endpoints on the turn path**; E7–E12 are admin
