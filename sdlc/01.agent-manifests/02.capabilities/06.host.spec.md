# Host capability — capability spec

## Four sources, **fixed** order
`host-native` → `eso-native` → `external` → **`none`**
Stop at the **first available**. Check the **order** — never skip.

## `none` is a **valid** state
No source available ⇒ **keep running**, **lower the guarantee**, and **say so**.
`none` is not an error: hiding it makes the agent **guess**.

## Two rules
- **record the chosen source** + reason, every time — `elections{kind, provider, reason}`
- switching source (even when the old one broke) **must be recorded**; a silent switch ⇒ `SILENT_SWITCH`

## Which capabilities are elected
file read/write · command execution · session memory · skills · pre-step hook · graph · search
A host **lacking** one ⇒ the branch falls through; **never** pretend it exists.

## RBAC coverage
**N/A** — election runs **locally inside the turn**, with no user-facing surface.
The permission that does exist — changing which provider a project uses — is config: `AC-CFG-01-04` (#2).

## Wire
**0 endpoints on the turn path** — election is **local**. The result goes into the evidence `payload`.
Isolation: project A's configuration **never** applies to B.
