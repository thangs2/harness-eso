# Config page + SDLC setup — capability spec

## One page, four groups
`sdlc` (root · zones · header profile · gates) · `team` (presets · roles) · `tool` (jira · notion · plan) · `project`
The four groups **constrain each other** ⇒ save **atomically**, one `version` for all four.

## Rules
- **preview required**: the `hash` from `config:preview` must match at `save`; mismatch ⇒ `PREVIEW_REQUIRED`
- changing `sdlc_root` when documents already exist ⇒ `ROOT_CHANGE_UNPLANNED` unless a migration plan is declared
- installing a preset **never** overwrites hand-edited roles; returns the skipped list
- only `operator` may save ([`D-51`](../../03.inception/02.decision-log/00.index.md))

## SDLC setup
- `sdlc:init` is **idempotent**: rerun ⇒ `created: []`
- missing configuration ⇒ `CONFIG_INCOMPLETE`, **0 files**
- not matching `applies_when` (no FE / no Jira) ⇒ record **`out[]`**, never silent
- `sdlc:upgrade` upgrades **every** project on that `preset_version`; needs approval; returns `impact[]`; revert is **one** action
- `sdlc:check` is **read-only** — the standard's 7 checks

## Wire
E12 preview · E13 save · E14 revert · E15 init · E16 check · E17 upgrade. **All off-path.**
Tables `sdlc_profile` (versioned) · `declaration` · `role_preset`.
