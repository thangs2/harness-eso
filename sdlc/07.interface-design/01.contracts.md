# 01 — Contracts: C1 ↔ C2, và cái gì **không** nằm trên đường turn

**Nguồn:** [`c4/02`](../04.architecture/c4/02.container.md) · [`D-46`](../01.inception/02.decision-log/00.index.md) · [`D-47`](../01.inception/02.decision-log/00.index.md)

## 1. Khẳng định quan trọng nhất: **không endpoint nào trên đường turn**

| | |
|---|---|
| Judgement dùng **hiện trạng cục bộ** ([`D-46`](../01.inception/02.decision-log/00.index.md)) | ⇒ C1 **không** gọi C2 khi phán |
| Cache khai báo làm mới **khi provision** ([`D-24`](../01.inception/02.decision-log/00.index.md)) | ⇒ không có endpoint "pull" mỗi turn |
| Evidence ghi **outbox trước**, ship sau ([`D-20`](../01.inception/02.decision-log/00.index.md)) | ⇒ ship là **off-path** |

**Kiểm được:** đường turn **không** có lời gọi mạng. Test: chạy turn với C2 **tắt** ⇒ phán quyết vẫn ra, **mức bảo đảm hạ**,
và **không** có lỗi.

## 2. Bốn endpoint — và **tất cả** đều off-path

| # | Endpoint | Ai gọi · khi nào | Idempotent | Trên đường turn |
|---|---|---|---|---|
| **E1** | `POST /v1/evidence:batch` | C1 · khi đầy lô **hoặc** cuối phiên | ✅ `(project, turn_id, seq)` | ❌ |
| **E2** | `POST /v1/declarations:sync` | `provision.sh` · **in** (file→DB) rồi **out** (DB→file) | ✅ theo `content_hash` | ❌ |
| **E3** | `GET /v1/diagnosis` | C3 · khi người hỏi "vì sao" | — (chỉ đọc) | ❌ |
| **E4** | `GET /v1/projections/{name}` | C3 · mọi màn hình | — (chỉ đọc) | ❌ |
| **E5** | `POST /v1/graph:batch` | C1 · sau khi C5 chạy xong | ✅ theo `(project, build_id, node_id, edge_key)` | ❌ |
| **E6** | `GET /v1/health` | C1 · trước khi ship | — | ❌ |

**Năm endpoint cho evidence/declaration/graph, một cho sức khoẻ.** Không có endpoint nào cho "phán quyết" — vì phán quyết
**không** gọi mạng.

## 3. Hợp đồng từng endpoint

### E1 · `POST /v1/evidence:batch`

```json
{
  "project": "baplatform",
  "batch_id": "uuid",
  "items": [
    {
      "turn_id": "uuid", "seq": 1,
      "at": "2026-10-25T12:00:00Z",
      "actor": { "role": "lead", "status": "FULL" },
      "level": "partial", "mode": "ask", "basis": "retrieved",
      "payload": { "requirements": [], "answers": [], "elections": [], "files_used": [] }
    }
  ]
}
```

| | |
|---|---|
| **200** | `{ "accepted": n, "duplicates": m }` — trùng **không** phải lỗi ([`D-47`](../01.inception/02.decision-log/00.index.md)) |
| **400** | thiếu `project` · thiếu `turn_id` |
| **403** | `project` không khớp phạm vi của credential |
| **409** | `turn_id` đã có với `payload` **khác** — cùng khoá, khác nội dung: **dừng**, không ghi đè |
| **503** | C2 chết ⇒ C1 **giữ** outbox, thử lại; **không** mất dữ liệu |

**`409` là chỗ đáng chú ý:** idempotent theo khoá, **nhưng** cùng khoá mà nội dung khác thì **không** được coi là trùng. Đó là
lỗi lập trình, và nuốt nó là nuốt bằng chứng.

### E2 · `POST /v1/declarations:sync`

| | |
|---|---|
| Chiều **in** | file → DB, rồi DB → file (out) — thứ tự [`D-24`](../01.inception/02.decision-log/00.index.md) |
| **200** | `{ "in": n, "out": m, "conflicts": [] }` |
| **409** | có xung đột ⇒ **dừng**, trả danh sách; **không** chọn bên thắng ([`D-23`](../01.inception/02.decision-log/00.index.md)) |

### E3 · `GET /v1/diagnosis?project=…&turn=…`

Trả câu trả lời cho A-01/A-08, **kèm `unknowns[]`** ([`AC-SUF-02-03`](../03.analysis/03.acceptance-criteria/02.suf-us-02-operator.md)).

### E4 · `GET /v1/projections/{name}`

`name` ∈ `turns` · `risks` · `graph` · `audit`. **UI không chạm bảng** ([`D-47`](../01.inception/02.decision-log/00.index.md)).

### E5 · `POST /v1/graph:batch`

C1 ship kết quả C5. Kèm `build_id` + `completeness` **theo từng câu hỏi** ([`c4/03`](../04.architecture/c4/03.component.md) C5.3).

## 4. Ba luật hợp đồng

| Luật | Vì sao |
|---|---|
| **Mọi request đọc/ghi đều mang `project`**, và nó được **kiểm** với credential | cô lập không thể là "tuỳ tham số" |
| **Không endpoint nào trả "phán quyết mới"** | phán quyết sinh ở C1; C2 chỉ **chứa** cái đã xảy ra |
| **Trùng ≠ lỗi; khác nội dung cùng khoá = lỗi** | outbox ship lại là bình thường; ghi đè bằng chứng thì không |
