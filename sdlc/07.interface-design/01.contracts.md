# 01 — Contracts: C1 ↔ C2, và cái gì **không** nằm trên đường turn

**Nguồn:** [`c4/02`](../04.architecture/c4/02.container.md) · [`D-46`](../01.inception/02.decision-log/00.index.md) · [`D-47`](../01.inception/02.decision-log/00.index.md)

## 1. Khẳng định quan trọng nhất: **không endpoint nào trên đường turn**

| | |
|---|---|
| Judgement dùng **hiện trạng cục bộ** ([`D-46`](../01.inception/02.decision-log/00.index.md)) | ⇒ C1 **không** gọi C2 khi phán |
| Cache khai báo làm mới **khi provision** ([`D-24`](../01.inception/02.decision-log/00.index.md)) | ⇒ không có endpoint "pull" mỗi turn |
| Evidence ghi **outbox trước**, ship sau ([`D-20`](../01.inception/02.decision-log/00.index.md)) | ⇒ ship là **off-path** |

**Kiểm được:** đường turn **không** có lời gọi mạng. Test: chạy turn với C2 **tắt** ⇒ phán quyết vẫn ra, **mức bảo đảm hạ**,
và **không** có lỗi.

## 2. Bốn endpoint — và **tất cả** đều off-path

| # | Endpoint | Ai gọi · khi nào | Idempotent | Trên đường turn |
|---|---|---|---|---|
| **E1** | `POST /v1/evidence:batch` | C1 · khi đầy lô **hoặc** cuối phiên | ✅ `(project, turn_id, seq)` | ❌ |
| **E2** | `POST /v1/declarations:sync` | `provision.sh` · **in** (file→DB) rồi **out** (DB→file) | ✅ theo `content_hash` | ❌ |
| **E3** | `GET /v1/diagnosis` | C3 · khi người hỏi "vì sao" | — (chỉ đọc) | ❌ |
| **E4** | `GET /v1/projections/{name}` | C3 · mọi màn hình | — (chỉ đọc) | ❌ |
| **E5** | `POST /v1/graph:batch` | C1 · sau khi C5 chạy xong | ✅ theo `(project, build_id, node_id, edge_key)` | ❌ |
| **E6** | `GET /v1/health` | C1 · trước khi ship | — | ❌ |
| **E7** | `POST /v1/workers` | C3 · tạo/sửa/nghỉ worker | ✅ theo `worker_id` | ❌ |
| **E8** | `POST /v1/roles` | C3 · vai + `scope` + `bar` | ✅ append version | ❌ |
| **E9** | `POST /v1/policies` | C3 · luật + thuộc tính | ✅ append version | ❌ |
| **E10** | `POST /v1/flows` | C3 · edge A→B | ✅ theo `(from,to)` | ❌ |
| **E11** | `POST /v1/risk:event` | C3 · **accept**/mitigate/remediate | ✅ append (`seq`) | ❌ |
| **E12** | `POST /v1/config:{preview,save,revert}` · `POST /v1/sdlc:{init,check,upgrade}` | C3 · thiết lập | ✅ `preview`+`init` | ❌ |

**Sáu endpoint cho evidence/declaration/graph/sức khoẻ; sáu cho IAM và thiết lập.** Không có endpoint nào cho "phán quyết" — vì phán quyết
**không** gọi mạng.

## 3. Hợp đồng từng endpoint

### E1 · `POST /v1/evidence:batch`

```json
{
  "project": "baplatform",
  "batch_id": "uuid",
  "items": [
    {
      "turn_id": "uuid", "seq": 1,
      "at": "2026-10-25T12:00:00Z",
      "actor": { "role": "lead", "status": "FULL" },
      "level": "partial", "mode": "ask", "basis": "retrieved",
      "payload": { "requirements": [], "answers": [], "elections": [], "files_used": [] }
    }
  ]
}
```

| | |
|---|---|
| **200** | `{ "accepted": n, "duplicates": m }` — trùng **không** phải lỗi ([`D-47`](../01.inception/02.decision-log/00.index.md)) |
| **400** | thiếu `project` · thiếu `turn_id` |
| **403** | `project` không khớp phạm vi của credential |
| **409** | `turn_id` đã có với `payload` **khác** — cùng khoá, khác nội dung: **dừng**, không ghi đè |
| **503** | C2 chết ⇒ C1 **giữ** outbox, thử lại; **không** mất dữ liệu |

**`409` là chỗ đáng chú ý:** idempotent theo khoá, **nhưng** cùng khoá mà nội dung khác thì **không** được coi là trùng. Đó là
lỗi lập trình, và nuốt nó là nuốt bằng chứng.

### E2 · `POST /v1/declarations:sync`

| | |
|---|---|
| Chiều **in** | file → DB, rồi DB → file (out) — thứ tự [`D-24`](../01.inception/02.decision-log/00.index.md) |
| **200** | `{ "in": n, "out": m, "conflicts": [] }` |
| **409** | có xung đột ⇒ **dừng**, trả danh sách; **không** chọn bên thắng ([`D-23`](../01.inception/02.decision-log/00.index.md)) |

### E3 · `GET /v1/diagnosis?project=…&turn=…`

Trả câu trả lời cho A-01/A-08, **kèm `unknowns[]`** ([`AC-SUF-02-03`](../03.analysis/03.acceptance-criteria/02.suf-us-02-operator.md)).

### E4 · `GET /v1/projections/{name}`

`name` ∈ `turns` · `risks` · `graph` · `audit`. **UI không chạm bảng** ([`D-47`](../01.inception/02.decision-log/00.index.md)).

### E5 · `POST /v1/graph:batch`

C1 ship kết quả C5. Kèm `build_id` + `completeness` **theo từng câu hỏi** ([`c4/03`](../04.architecture/c4/03.component.md) C5.3).

### E7 · `POST /v1/workers`

```json
{ "project": "baplatform", "worker_id": "uuid?", "role": "build",
  "harness_source": "eso-native", "state": "active" }
```

| | |
|---|---|
| **200** | `{ "worker_id": "…", "state": "active", "open_risks": [] }` |
| **200 khi nghỉ** | `"state": "retired"`, **`open_risks`** = risk đã tạo cho việc đang dở ([`AC-IAM-01-02`](../03.analysis/03.acceptance-criteria/05.iam-us-01-workers.md)) |
| **400** | `role` không có trong project ⇒ `UNKNOWN_ROLE` |
| **403** | `project` không khớp credential |

**Nghỉ mà đang có việc dở ⇒ trả `open_risks`, không im lặng.** Đó là toàn bộ lý do endpoint này trả về risk.

### E8 · `POST /v1/roles`

```json
{ "project": "baplatform", "name": "build",
  "capabilities": ["be"],
  "scope": [ { "verb": "write", "kind": "file", "value": "packages/**" },
             { "verb": "append", "kind": "evidence", "value": "*" } ],
  "bar": [ { "evidence_kind": "slice-table", "min_basis": "retrieved" } ] }
```

| | |
|---|---|
| **200** | `{ "name": "build", "version": 7 }` — **append version**, không `UPDATE` |
| **400** | `bar` rỗng ⇒ `EMPTY_OBLIGATION` · `verb` ngoài tập đóng ⇒ `UNKNOWN_VERB` |
| **403** | không phải `operator` ⇒ `ROLE_CHANGE_FORBIDDEN` |

`verb` là **tập đóng** ([`D-48`](../01.inception/02.decision-log/00.index.md)): cơ chế không cưỡng chế được động từ nó không có tên.

### E9 · `POST /v1/policies`

```json
{ "project": "baplatform", "policy_id": "uuid?",
  "attribute": "path", "operator": "starts_with", "value": "packages/",
  "effect": "deny", "subjects": ["build"] }
```

| | |
|---|---|
| **200** | `{ "policy_id": "…", "version": 3 }` |
| **400** | `attribute` **ngoài tập đóng** ⇒ `UNKNOWN_ATTRIBUTE` — **từ chối khi lưu**, không phải khi chạy ([`AC-IAM-03-03`](../03.analysis/03.acceptance-criteria/07.iam-us-03-policies.md)) |
| **403** | không phải `operator` ⇒ `POLICY_CHANGE_FORBIDDEN` |

**Không có đường nào cho agent** — kể cả gián tiếp, vì hành động này **chỉ** role `operator` gọi được ([`D-48`](../01.inception/02.decision-log/00.index.md) §"chặn ở hành động").

### E10 · `POST /v1/flows`

```json
{ "project": "baplatform", "from": "verify", "to": "audit",
  "carries": ["diff", "rubric"] }
```

| | |
|---|---|
| **200** | `{ "from": "verify", "to": "audit", "carries": ["diff","rubric"] }` |
| **400** | vai không tồn tại ⇒ `UNKNOWN_ROLE` |

**Kiểm điều kiện bàn giao xảy ra ở C1**, không ở endpoint này — bàn giao là hành động **cục bộ** trong turn
([`AC-IAM-04-02`](../03.analysis/03.acceptance-criteria/08.iam-us-04-flows.md)). E10 chỉ **khai** flow.

### E11 · `POST /v1/risk:event`

```json
{ "project": "baplatform", "risk_id": "uuid", "seq": 3,
  "event": "accept", "by": "thangs2net@gmail.com",
  "due": "2026-11-08", "reason": "chấp nhận trong sprint này" }
```

| | |
|---|---|
| **200** | `{ "risk_id": "…", "state": "accepted", "due": "…" }` |
| **400** | `accept` thiếu `due` ⇒ `ACCEPT_WITHOUT_DUE` · `renewed` mà `due` ≤ `due` cũ ⇒ `DUE_NOT_EXTENDED` |
| **403** | role không có quyền `accept` cho `kind` đó ⇒ `ACCEPT_FORBIDDEN` |
| **409** | `(risk_id, seq)` đã có với nội dung khác |

**Đây là đường ghi DUY NHẤT của người vào evidence.** Nó **append**, không `UPDATE` ([`BR-06`](../03.analysis/01.business-analysis/03.business-rules.md)).

### E12 · `POST /v1/config:*` và `POST /v1/sdlc:*`

| Endpoint | Vào | Ra | Ghi chú |
|---|---|---|---|
| `config:preview` | thay đổi cấu hình | `{ hash, impact: { consumers[], overrides[], artifacts[] } }` | `hash` **bắt buộc** để lưu ([`AC-IAM-06-02`](../03.analysis/03.acceptance-criteria/10.iam-us-06-config.md)) |
| `config:save` | thay đổi + **`hash`** | `{ version }` | **nguyên tử**; `hash` lệch ⇒ `409 PREVIEW_REQUIRED` |
| `config:revert` | thay đổi đã lưu | `{ reverted_to, marked_artifacts[] }` | dời con trỏ, **đánh dấu** artefact ([`D-32`](../01.inception/02.decision-log/00.index.md)) |
| `sdlc:init` | project | `{ created[], existing[], out[] }` | **idempotent** — chạy lại ⇒ `created: []` |
| `sdlc:check` | project | `{ checks: [{ id, pass, reason }] }` | 7 phép kiểm, **chỉ đọc** |
| `sdlc:upgrade` | preset/version | `{ impact[], reverted_by? }` | `GRANT` — người duyệt ([`D-15`](../01.inception/02.decision-log/00.index.md)) |

**`sdlc:init` trả `out[]`** — phần **không khớp** `applies_when` (không FE, không Jira) ghi `OUT` kèm lý do, **không** im lặng
([`AC-SDLC-01-03`](../03.analysis/03.acceptance-criteria/12.sdlc-us-01-setup.md)).

## 4. Ba luật hợp đồng

| Luật | Vì sao |
|---|---|
| **Mọi request đọc/ghi đều mang `project`**, và nó được **kiểm** với credential | cô lập không thể là "tuỳ tham số" |
| **Không endpoint nào trả "phán quyết mới"** | phán quyết sinh ở C1; C2 chỉ **chứa** cái đã xảy ra |
| **Trùng ≠ lỗi; khác nội dung cùng khoá = lỗi** | outbox ship lại là bình thường; ghi đè bằng chứng thì không |
