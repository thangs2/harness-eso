# Page contract — Setup profile + consumer

**Actor:** A-01 operator. **Entry:** `/setup`. **Exit:** consumer detail, hoặc quay lại danh sách.

## 1. Mục tiêu

Đăng ký **profile** (template) → gắn với **consumer** cụ thể → lưu snapshot có version → consumer tồn tại để xử lý case-by-case.

## 3. Harness — Lite · Pro · DSH native

**Quyết định nền:** [`D-89`](../../03.inception/02.decision-log/06.architecture-va-data.md). Ba tên là **ba nguồn harness**, không phải ba mức chất lượng.

### 3.1 Artifact-model mapping

| Page khái niệm | Tầng trong `03.artifact-model/02.model.md` | Ghi chú |
|---|---|---|
| Profile template (`profile` row) | **template** | Dùng lại; không phải config của một consumer |
| Consumer snapshot (`sdlc_profile` version) | **instance** | Gắn `project`, có version; sửa = version mới |
| Kết quả setup (file/config) | **render** | Chỉ sinh khi apply; page này preview, không ghi |
| Ledger quyết định | **ledger** | Không thuộc setup; thuộc runtime/evidence |

**Luật:** không được trộn `template` với `instance`. Chọn harness/profile ở bước 1 là chọn **template**; lưu ở bước 4 mới tạo **instance**.

### 3.2 Ba nguồn harness

| | **Lite — market harness** | **Pro — ESO native harness** | **DSH native** |
|---|---|---|---|
| Nguồn | MCP có sẵn: agentmemory · codegraph · docgraph · graphify… | ESO tự viết **memory + code graph + docs graph** | Session memory · skills · plugin system của DSH |
| ESO làm gì | Gate/record; gọi tool ngoài qua adapter | Cung cấp provider native; chạy được khi host không có gì | ESO là **plugin cộng thêm**; gate/record qua `agent/pre-step` |
| Portable | ❌ mỗi host cấu hình MCP riêng; data ở tool ngoài | ✅ **một harness SoT**; mọi host là adapter, không copy memory/graph | ❌ gắn DSH |
| Maturity | Có (v1 tools) | **planned** — G-B/G-E chưa build | **partial** — O-2 plugin |
| Dùng khi | Pilot, repo nhỏ, đã có MCP stack | Monolith/microservices, cần topology + continuity | Consumer chạy DSH |

**DSH + Pro** là composition `DSH native + ESO native plugin`, không phải loại thứ tư. UI phải hiện nó như một lựa chọn ghép, không phải card thứ tư.

### 3.3 Host × harness

| Host | Native harness | Lite | Pro | DSH native |
|---|---|---|---|---|
| Cursor | ❌ | ✅ MCP | ✅ adapter (planned) | — |
| Antigravity | ❌ | ✅ MCP | ✅ adapter (planned) | — |
| Claude Code | 🟡 memory/skills | ✅ | ✅ adapter (planned) | — |
| Codex | **defer** | ngoài v2.0 | ngoài v2.0 | — |
| DSH | ✅ session/skills/plugin | qua plugin | ✅ **plugin ESO native** (planned) | ✅ |

Codex không có đặc tả hook trong repo; không được hiển thị như native. `Pro` chưa build: chọn được nhưng **apply phải chặn** với lý do `G-B/G-E chưa có`, không giả vờ chạy.

### 3.4 ESO native gồm gì

| Bộ | Yêu cầu tối thiểu | Nguồn |
|---|---|---|
| **Code graph** | **Monolith trước** tới `method`/`dto`/`entity`/`table`; microservices (`service`/`route`/`event`/`datastore`/`saga`/`tenant`) chỉ sau khi monolith đạt acceptance; `unknown ≠ absent` | `REQ-ARCH-01` · `D-18` · `D-90` |
| **Docs graph** | **Specific-relative docs**: doc neo code/topology node; edge `specifies` · `constrains` · `derived_from` · `supersedes`; không phải semantic search | `REQ-ARCH-01` + yêu cầu mới |
| **Memory** | Short-term + long-term; typed/versioned; neo file + node/edge; `strength`; `hit`/`weak`/`miss`; `save`/migrate | `ESO-MEMORY` E-1…E-7 |

### 3.5 Hành vi cũ đang sai

| Chỗ | Cũ (sai) | Đúng (D-89) |
|---|---|---|
| Lite | "host-only, tắt law/code/memory" | **Market harness** dùng MCP ngoài |
| Pro | "full external evidence" | **ESO native harness** tự viết memory + graph |
| DSH native | "memory native fallback agentmemory" | **Harness của DSH**; Pro chỉ là composition |
| Recipe JSON | `lite.json` tắt memory; `pro.json` chỉ external | **v1 legacy**, không dùng làm contract v2 |

## 4. State

| State | Hiển thị |
|---|---|
| loading | skeleton theo bước |
| form invalid | lỗi cạnh field; không cho Next |
| plan loading | spinner; disable Save |
| plan error | lỗi + Retry; không cho Save |
| warning | danh sách cảnh báo; vẫn cho Save sau xác nhận |
| saved | navigate consumer detail, banner “đã lưu” |
| denied | 403 từ API; không lộ dữ liệu |

## 5. API

| Method | Path | Dùng |
|---|---|---|

## 6. Data

- `project(project)` — danh tính.
- `profile(id, version, name, harness, host_profile, config_json)` — template (mới, D-?).
- `sdlc_profile(project, version, …, profile_id, profile_version)` — snapshot.
- `sdlc_profile` giữ `sdlc_root`, `zones`, `header_profile`, `gates`, `tools`, `team`, `project_meta`.
- Không thêm cột config vào `project` (`23.project.md`).
