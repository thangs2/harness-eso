# Page contract — Plugins / provider cho consumer

**Actor:** A-01 operator. **Entry:** `/consumers/:id/plugins`. **Exit:** quay lại consumer detail sau khi lưu version mới.

## 1. Mục tiêu

Cho phép **override** provider của một consumer so với recipe, có nguồn gốc rõ (`recipe` hay `override`), có prerequisite/health, và lưu thành version mới. Không trộn page này vào setup.

## 1.1 Quan hệ với harness

Page này **không chọn harness**; nó override provider **trong harness đã chọn**:

| Harness | Slot lấy từ | Ghi chú |
|---|---|---|
| **Lite (market)** | MCP có sẵn: agentmemory/codegraph/docgraph… | Mỗi host cấu hình riêng; không portable |
| **Pro (ESO native)** | ESO native providers: memory/code graph/docs graph | **Một harness SoT** dùng chung mọi host; DSH plugin chỉ là adapter, không copy |
| **DSH native** | DSH session/skills/plugin | `brain` là host pointer, không phải plugin ESO |
| **DSH + Pro** | DSH native + ESO native providers | Composition; dùng **cùng SoT** của Pro; slot phải hiện provider nào thuộc bên nào |

Slot/option không được gộp ba nguồn này thành một danh sách phẳng không nhãn.

## 2.1 Taxonomy facets — mỗi option phải khai

Nguồn: `sdlc/03.inception/03.artifact-model/06.taxonomy.md` §1–§8. Catalog hiện chỉ có group/slot; **thiếu facet** nên UI không được tự gán.

| Slot | `product-role` | `provided-by` | `context-source` | `enforcement-point` |
|---|---|---|---|---|
| `law` | `collect` | `eso`/`third-party` | `enterprise-rules` | sau đọc |
| `code` | `collect` | `third-party` | `knowledge-graph: code` | sau đọc |
| `memory` | `collect` | `eso`/`host`/`third-party` | `memory` | sau đọc |
| `jev` | `decide` | `third-party` | — | trước ghi / trước đọc |
| `l3_route` | `decide` | `eso`/`host` | — | trước đọc |
| `brain` | `execute` | **`host`** | — | — (sản phẩm không gọi model) |
| `host_pack` | `collect`+`decide` | `eso` | — | trước ghi / sau ghi |

**Luật hiển thị:**

1. Mỗi option có badge `product-role` + `provided-by` + `maturity`.
2. `maturity: planned` → **xám, không cho bật**; không được giả vờ shipped.
3. `none`/`noop-*`/`off` là **tắt có ý thức**, không phải thiếu; phải có trong mọi slot.
4. `custom-*` phải khai `provided-by: custom` + contract path; không phải `eso`, không phải `third-party`.
5. Hai option cùng `owns-kinds` → từ chối; một kind chỉ một SoT.
6. `brain` là **con trỏ cấu hình host**, không phải plugin ESO cung cấp.
7. `knowledge-graph: docs` **không có slot** trong catalog → hiện “chưa cài được”, không tạo slot giả.

## 3. Field / component

Mỗi slot là một card:

| Thành phần | Nội dung |
|---|---|
| Source badge | `recipe:pro` hoặc `override` |
| Select | options từ catalog; custom cần path |
| Mode | JEV `off/shadow/active`; các slot khác không |
| Prerequisite | service/index/key; trạng thái `ok`/`missing`/`unknown` |
| Hint | từ catalog `hint` + `hintDiagram` |
| Reset | quay về recipe default cho slot đó |
| Warning | active JEV thiếu key/consent; native memory thiếu host capability; graph thiếu index |

## 4. Hành vi

1. Mở page → load consumer snapshot + recipe + catalog; mỗi slot hiện giá trị hiệu lực và source.
2. Đổi slot → đánh dấu `override`, bật nút Save; không tự ghi.
3. `Reset` → xoá override, quay về recipe default.
4. Save → **validate toàn bộ** → plan lại → tạo `sdlc_profile` version mới (hoặc bảng override riêng, OPEN-4) → detail.
5. Rời page khi dirty → confirm.
6. JEV `active` khi thiếu key/consent → chặn Save, hiện lý do.
7. Graph adapter khi service/index missing → warning, không chặn nếu operator xác nhận.

## 5. State

| State | Hiển thị |
|---|---|
| loading | skeleton slot cards |
| empty catalog | lỗi “catalog không tải được”, không hiện slot bịa |
| slot invalid | lỗi cạnh slot |
| dirty | banner “có thay đổi chưa lưu” |
| saving | disable toàn bộ |
| saved | navigate detail |
| denied | 403, không lộ slot/data |

## 6. API

| Method | Path | Dùng |
|---|---|---|
| GET | `/api/v1/catalog/plugins` | catalog + source (`file`/`embedded`) |
| GET | `/api/v1/consumers/:id/plugins` | giá trị hiệu lực + source từng slot |
| POST | `/api/v1/consumers/:id/plugins/plan` | plan thay đổi, không ghi |
| PUT | `/api/v1/consumers/:id/plugins` | lưu override/version mới |

## 7. Data

- `consumer_plugin(project, version, slot, adapter_id, mode, source, options_json)` — nếu tách bảng (OPEN-4).
- Hoặc lưu trong `sdlc_profile.integration` version mới; mỗi slot có `source: recipe|override`.

## 9. Non-goals

- Không chọn recipe/consumer ở page này.
- Không lưu secret vào DB/UI; chỉ hiện trạng thái có/không.
- Không tự thêm slot ngoài catalog.
