# C4 L1 — Context: hệ ↔ cái gì **ngoài** nó

> **C4 = cấu trúc tĩnh.** Luồng · sequence · ERD · hành trình người dùng nằm ở tài liệu khác
> ([`03`](../../02.governance/01.standard/02.artifacts.md) §2).
>
> **Một mức duy nhất:** file này **chỉ** L1. Container ở [`02.container.md`](./02.container.md).

## 1. Ranh giới — câu phải trả lời trước khi vẽ

**Hệ thống ESO gồm những gì?** Trả lời: **mọi thứ chạy trên máy của người dùng mà ta viết ra** — adapter nằm **trong**
host, control plane, Postgres, và graph extractor. **Không** gồm: host, provider, project của người dùng, trình duyệt.

| Trong ranh giới | Ngoài ranh giới |
|---|---|
| adapter (plugin trong host) | **host** — Cursor · DSH · Antigravity |
| control plane API + UI | **provider** — docgraph · codegraph · memory · LLM |
| Postgres | **project** của người dùng (file + git) |
| graph extractor (.NET) | **trình duyệt** của operator |

**Chỗ dễ sai:** adapter chạy **trong process của host** ⇒ ai đó sẽ nói nó "thuộc host". **Không.** Nó là code **ta** viết, ta
sửa, ta chịu trách nhiệm — chỉ **deploy** trong process khác. Đây là bản chất của "gắn vào, không thay thế" (`D-11`).

## 3. Quan hệ — cái gì **đi qua** ranh giới

| Từ | Đến | Đi qua cái gì | **Không** đi qua |
|---|---|---|---|
| A-01 | Control Plane | khai báo · câu hỏi · duyệt · `Done` | — |
| A-05 Host | Adapter | gọi hook · gọi skill | **không** quyết phán quyết |
| Adapter | A-05 Host | inject rule/skill · **nói ra năng lực thiếu** | không sửa host |
| Adapter | Factory | — | — |
| Adapter | A-07 Project | đọc file · **ghi trong `allowed_files`** · đọc git | **không** ghi ngoài phạm vi |
| Adapter | Control Plane | evidence (**async, outbox**) · hỏi khai báo | **không** đồng bộ trên đường turn |
| Control Plane | Postgres | SQL | — |
| Control Plane | A-06 Provider | hỏi (theo **thứ tự election**) | không giả vờ provider là của ta |
| A-08 | Control Plane | **chỉ đọc** | không sửa record |

## 4. Ba điều L1 này **quyết**, và chúng có hệ quả

| Quyết định | Hệ quả xuống L2 |
|---|---|
| Adapter nằm **trong** host, không phải service riêng | phán quyết phải **chạy được cục bộ**, không gọi mạng trên đường turn |
| Control plane **một** deployment, **cùng máy** (`D-20`) | nhưng vẫn là **process riêng** — không phải thư viện |
| Project là **ngoài** hệ, nhưng ta **ghi** vào nó | `allowed_files` là ranh giới **ghi**, phải cưỡng chế ở adapter |
