## 3. Serve mode

Script in:

```text
[demo] control plane: http://127.0.0.1:8787
[demo] token:         demo-token
[demo] project:       demo
[demo] DB:            /tmp/eso-demo-XXXX/demo.sqlite
```

Mở `http://127.0.0.1:8787/work-overview?project=demo`:

- 2 dòng: `sửa cột tenants` (partial, 2 thiếu), `thêm endpoint` (sufficient).
- Cột **Việc** có dữ liệu; `data-state="READY"`; không có `ST6_READY`.
- Không có nút ghi — S1 chỉ đọc.

Curl:

```bash
curl -s http://127.0.0.1:8787/health

curl -s -o /dev/null -w '%{http_code}\n' \
  'http://127.0.0.1:8787/config?project=demo'          # 401

curl -s -H 'Authorization: Bearer demo-token' \
  'http://127.0.0.1:8787/config?project=demo'          # 200

curl -s -H 'Authorization: Bearer demo-token' \
  'http://127.0.0.1:8787/work-overview?project=demo'   # HTML
```

Ctrl-C để dừng; DB giữ ở path in ra.

## 7. Troubleshooting

| Lỗi | Sửa |
|---|---|
| `dist/main.js is missing` | bỏ `--no-build`, hoặc `(cd eso/control-plane && npm run build)` |
| `tsc: command not found` | `bun install` ở root |
| `EADDRINUSE` | `--serve --port=8788` |
| DB locked | dừng serve cũ; mỗi lần tạo temp dir mới |
| `bun install` lockfile | `bun install` (không frozen) rồi chạy lại |
