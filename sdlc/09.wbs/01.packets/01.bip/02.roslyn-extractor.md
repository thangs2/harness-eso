## 4. Contract & transaction

| | |
|---|---|
| **in** | solution **compile được**; `manifest_entry` đã có cho `build_id` |
| **out** | `graph_node` + `graph_edge` + `source_claim` cho một `build_id` |
| **ordering** | `manifest` **trước** (cần mẫu số) |
| **must not change** | `manifest_entry` — extractor **không** được sửa mẫu số |
| **môi trường** | `manifest` yêu cầu **build chạy được** của solution đích: cần **SDK .NET**, **NuGet cache**, và quyền **ghi `obj/`** trong repo đó. Thiếu một cái ⇒ **không** có mẫu số ⇒ `OUT`, **không** được coi là `coverage = 0` |
| **idempotent** | cùng `build_id` chạy hai lần ⇒ **cùng** số node |

## 4.1 Giá phải trả — Roslyn chỉ C#, không phải extractor vạn năng

Theo [`D-91`](../../../03.inception/02.decision-log/06.architecture-va-data.md):

| Cons | Ảnh hưởng slice |
|---|---|
| .NET SDK/runtime + sidecar | image/CI riêng; Node không chạy Roslyn trực tiếp |
| solution phải build được | SDK, NuGet, `obj/`; build hỏng ⇒ `OUT`, không `coverage=0` |
| MSBuild/analyzer/source-generator là code execution | sandbox/trust boundary |
| solution load nặng | off-path + incremental |
| Roslyn ↔ SDK/TFM version | capability probe; lệch ⇒ hạ coverage |
| chỉ C#/VB | TS/JS/NestJS/Java/Go/Python là adapter riêng, không thuộc slice này |

**Scope:** `ESO-401` là **C# Roslyn extractor**. Nó không được nhận là "extractor cho mọi ngôn ngữ"; TS/Java/Go/Python có Story riêng.
