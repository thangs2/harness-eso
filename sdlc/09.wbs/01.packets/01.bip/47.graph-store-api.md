## 3. Business binding

| `BR` | Câu | Vì sao ràng buộc slice này |
|---|---|---|
| **`BR-05`** | **`unknown` ≠ `absent`** | `coverage` dưới floor phải ra `unknown` + `unknowns[]` (`AC-GRAPH-03-04`). Trả `absent` là nói *"không tồn tại"* khi thật ra *"chưa đọc đủ"* |
| **`BR-05`** | `completeness` theo **câu hỏi**, không theo project | Một số cho mỗi project gộp ba câu cao với hai câu thấp ⇒ **nói dối cả năm câu** (`AC-GRAPH-03-01`) |
| **`BR-06`** | `source_claim` chỉ ghi thêm | Nguồn của edge không được sửa — nếu không, *"vì sao cạnh này tồn tại"* mất |
| **`BR-12`** | Cô lập project | `AC-GRAPH-03-03`: project B có graph, query project A ⇒ 0 dòng + `OUT_OF_SCOPE` |

## 4. Contract & transaction

| | |
|---|---|
| endpoints | `API-28` `POST /v1/graph/index` (ghi theo `build_id`) · `API-29` `POST /v1/graph/rebuild` (thay **cùng** `build_id`) · `API-30` `POST /v1/graph/q1` (chỉ đọc) |
| header | **bắt buộc** `x-eso-turn-phase: off-path \| judging`; thiếu ⇒ `400 TURN_PHASE_REQUIRED`, không chạy graph |
| idempotency | `(project, build_id)` là khoá; index/rebuild lần hai **không** nhân đôi |
| lỗi đã đăng ký | `CONFLICT` (cùng khoá khác nội dung) · `TOOLCHAIN_UNAVAILABLE` (503) · `OUT_OF_SCOPE` (403) · `FANOUT_CAPPED` (200) |
| **must not change** | `API-1`–`API-27`; bảng `evidence_*`; `ticket_pack`; `manifest_entry` (chỉ **đọc** để lấy mẫu số) |

## 5. Data & persistence

| Bảng | Vào/ra | Vì sao |
|---|---|---|
| `graph_node` · `graph_edge` | ghi (index/rebuild) · đọc (Q1–Q5) | khoá `(project, build_id)`; `project` **đầu tiên** |
| `source_claim` | ghi (append) | nguồn của từng edge (`BR-06`) |
| `completeness` | ghi (`value` = `min(coverage(kind))`) | mẫu số từ `manifest_entry` **cùng** `build_id`; `value` **không** NULL |

**DDL:** database `graph` có bảng từ Stage 5b — [`26.graph-schema`](../../../07.technical/02.data-design/26.graph-schema.md) §2 (`graph_node` · `graph_edge` · `source_claim` · `completeness`), khoá `(project, build_id, …)`, `source_claim` gắn **edge** và append-only; RLS `ENABLE` + `FORCE` + `WITH CHECK` (§5).
