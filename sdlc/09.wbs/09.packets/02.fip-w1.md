# FIP — `W1` = **`OUT`**, có lý do

| | |
|---|---|
| slice | `W1-1` … `W1-5` |
| **status** | **`OUT`** |
| lý do | wave **không** có bề mặt: `02.wave-map` §1 cho W1 = **0** `AC-UI-*`, và `X14` không đòi bề mặt nào cho nó |

**Luật [`03`](../../02.governance/01.standard/03.bip-fip.md) §1:** slice chỉ `[be]` ⇒ **BIP**, và `FIP = OUT` **kèm lý do**. Ghi `OUT` ở đây là
**tuân** luật, không phải bỏ qua.

## Khi nào file này phải đổi

Nếu **bất kỳ** task nào của W1 sinh ra thứ người dùng **thấy** — kể cả một màn hình đọc graph — thì:
`FIP` **phải** được viết thật, và `X14` đòi **6 trạng thái + ≥1 luồng** trước khi nó tính là thiết kế.
