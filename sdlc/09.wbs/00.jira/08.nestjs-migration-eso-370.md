## 4. Ranh giới còn lại

- `s1.presenter.ts` vẫn import `eso/core/src/ui-frames.mjs`. Đây là **core domain ngoài control-plane**, chưa migrate; không phải `.mjs` trong control-plane.
- `eso/ui` (Angular) là stack riêng, không thuộc phạm vi migration này.
- `qc/eso-graph-q4-q5.test.mjs` và `qc/eso-batch-adversarial-qc.test.mjs` là thay đổi chưa commit của phiên khác; không đưa vào commit migration.

## 5. Hệ quả

- Control plane chỉ còn **một** HTTP stack: NestJS `server.ts`.
- `qc/eso-cp-nestjs.test.mjs` import `dist/server.js`; `scripts/run-tests.mjs` build `eso/control-plane` trước khi chạy suite, nên clean clone không còn phụ thuộc `dist/` có sẵn.
- Merge vẫn bị chặn bởi `MERGE_BLOCKED.md`; migration này không gỡ block.

## 6. Structure correction — 2026-11-05

- `src/` root chỉ còn `main.ts` và `app.module.ts`; không còn domain file nằm phẳng.
- `config` sở hữu `domain/config-change.ts`, `infrastructure/persistence/config.schema.ts`, `infrastructure/persistence/repositories/config.repository.ts`.
- `flow`, `debt`, `scope` mỗi module có `domain/`, `<module>.module.ts`, `index.ts`.
- `modules/s1` đổi thành `modules/work-overview`; controller/module/presenter đổi tên theo domain, route `/work-overview`.
- UI features đổi `s1-work…s5-artefact` thành `work-overview`, `diagnosis`, `declaration`, `risk`, `audit`.
- `node eso/ui/scripts/check-structure.mjs` → pass; 58 test CP/S1/UI pass.

- `prebuild` xoá `dist` trước `tsc`; build chỉ còn `dist/main.js`, không còn `dist/server.js` cũ.
