## 2. W1 — graph, và thí nghiệm có thể bác bỏ

| # | Việc | DoD |
|---|---|---|
| W1-1 | Postgres schema: `node` · `edge` · `source_claim` · `completeness` | chạy migration; RLS theo project |
| W1-2 | Roslyn extractor: `module`·`namespace`·`class`·`method`·`entity`·`table` + `path` | build được baplatform, có số node/edge **thật** |
| W1-3 | Edge có `kind` và `sources[]` (ba nguồn — D-25) | xung đột ⇒ hạ `completeness` |
| W1-4 | Truy vấn **Q1**: "đọc file nào cho symbol X" | trả lời ≤ 2s |
| W1-5 | **Thí nghiệm 5 ticket** | recall + precision ghi thành số |

**Gate W1 (đã chốt — [`D-39`](../01.inception/02.decision-log/00.index.md)):** **recall ≥ 0,8 · precision ≥ 0,5**. Không đạt ⇒
dừng, **bổ sung nguồn** (b)/(c) trước khi làm W2.

> **Vì sao precision chỉ 0,5:** thừa file là **chi phí đọc**; thiếu file là **sai**. Hai lỗi không ngang nhau.

**Cách đo — *prospective*, không retrospective:**

```text
1. chọn ticket baplatform THẬT, chưa implement
2. graph dự đoán  : "phải đọc/ sửa file nào"            ← ghi lại, ĐÓNG BĂNG
3. implement thật (quy trình thường của baplatform)
4. so dự đoán với `git diff` thật  ⇒ recall · precision
```

| Quyết định | |
|---|---|
| **Đối tượng** | **baplatform** — chỉ nó kiểm được quy ước ABP |
| **Theo dõi** | **ticket ESO** (một Task mỗi lần đo) |
| **Ground truth** | `git diff` của lần implement đó |
| **Cái giá** | phải **chờ** 5 ticket thật xong — *"không sợ chậm"* |

**Đã loại:** *5 ticket lịch sử* (đáp án có sẵn ⇒ dễ tự lừa) · *đo trên harness-eso* (không có ABP ⇒ gate vô nghĩa).
