Mô hình **khái niệm** của sản phẩm. Không mô tả wiring hiện tại của code (đó là
[`documents/01.overview/03.architecture.md`](../../documents/01.overview/03.architecture.md)); file này giữ
những mô hình **định hướng**, tức những thứ code phải tiến tới.

| File | Câu hỏi |

| [`01.product-axes.md`](./01.product-axes.md) | sản phẩm được xác định bằng những trục nào, và tại sao là hai trục chứ không phải một |
