# 05 — Gate ↔ artifact: what flows into which gate

> **Why this map.** `01.sdlc-delivery-lifecycle-standard` §2 says **what each stage produces**; §3 says **what a transition needs**.
> Neither answers: *"if I change a `REQ`, **which gates reopen**?"* — and that is the practical question behind `L3`.

## 1. Artifact → gates that consume it

| Artifact | Gate that **consumes** it | Changing it ⇒ reopen |
|---|---|---|
| `REQ-*` | 2 · 4 · 6 | the `US` tracing to it · that `US`'s `AC` · `SCN` |
| `UC-*` | 2 | `US` derived from it |
| `US-*` | 3 · 6 | its `AC` · the `SCN` covering that `AC` |
| `AC-*` | 3 · 4 · 5 · 7 | `SCN` · endpoint · table · test |
| `BR-*` | 2 · 6 | every `AC`/`SCN` it constrains |
| `SCN-*` | 7 | RED packet |
| endpoint (`E*`) | 5 · 6 | tables · BIP plane C |
| entity · schema | 6 | BIP plane D |
| C4 | 6 | WBS · BIP plane B |
| BIP/FIP | 7 · 8 | RED packet · code |
| RED packet | 8 | code |

## 2. Change one thing → how much reopens

| Change | Reopens | Real example from this session |
|---|---|---|
| `REQ` | 2 → 3 → 7 | adding `REQ-LEARN-01` forced `US-LEARN-01` + AC + SCN |
| `US` | AC → SCN | adding `AC-EV-01-05` (rbac) left a missing SCN, **caught by the RTM** |
| `AC` | SCN → test | `AC-IAM-02-05` was added **after** its matrix ⇒ missing row ⇒ `SCN-IAM-07b` added |
| `standard` | **every document on the same `sot_doc_version`** | changing the header scheme migrated **33 files** |
| file renamed/deleted | every **link** to it | `01.lifecycle` → `01.sdlc-delivery-lifecycle-standard` touched 2 files |

## 3. Three reopen checks **already enforced** (partially)

| Check | Where | Catches |
|---|---|---|
| **links resolve** | before each commit | renamed/deleted file still linked |
| **`§` references** | before each commit | reference to a section that no longer exists |
| **1:1 AC↔SCN** | RTM ([`03.iam-rtm`](../../03.analysis/04.quality-control/03.iam-rtm.md)) | AC added without a scenario |
| **id uniqueness** | id count | two files sharing an `AC-*` |
| **header per zone** | frontmatter count | missing `source_of_truth` / `human_sot` |
| **agent-spec budget** | `wc -l` / `wc -c` | spec over 150 lines / 4 000 chars |

## 4. What is **not** checked — and is therefore real debt

| Not checked | Consequence |
|---|---|
| which `US` must be revisited when a `REQ` changes | read table §1 **by hand** |
| which documents share a `standard` version | cannot tell which are stale |
| artifact mapping **derived** from headers | `D-50` says generate; **it is hand-written today** |

⇒ Table §1 is a **hand-written proxy for something that should be generated from headers**. That debt is already recorded in
[`05.document-status`](../05.document-status.md); it is not a new finding.
