# 03 — Gate ↔ artifact: cái gì **chảy** vào cổng nào

> **Vì sao cần bản đồ này.** `01.sdlc-delivery-lifecycle-standard` §2 nói **stage sinh ra gì**; §3 nói **chuyển stage cần gì**.
> Nhưng không chỗ nào trả lời: *"nếu tôi sửa `REQ`, **những cổng nào** phải mở lại?"* — và đó là câu hỏi thực tế của `L3`.

## 1. Artifact → cổng dùng nó

| Artifact | Cổng **tiêu thụ** | Sửa nó ⇒ mở lại |
|---|---|---|
| `REQ-*` | 2 · 4 · 6 | `US` truy nó · `AC` của `US` đó · `SCN` |
| `UC-*` | 2 | `US` sinh từ nó |
| `US-*` | 3 · 6 | `AC` của nó · `SCN` phủ `AC` đó |
| `AC-*` | 3 · 4 · 5 · 7 | `SCN` · endpoint · bảng · test |

## 2. Sửa một chỗ → mở lại **bao nhiêu**

| Sửa | Mở lại | Ví dụ thật trong phiên này |
|---|---|---|
| `REQ` | 2 → 3 → 7 | thêm `REQ-LEARN-01` ⇒ phải thêm `US-LEARN-01` + AC + SCN |
| `US` | AC → SCN | thêm `AC-EV-01-05` (rbac) ⇒ SCN thiếu, **bắt được bằng RTM** |
| `AC` | SCN → test | `AC-IAM-02-05` thêm **sau** matrix ⇒ thiếu dòng SCN ⇒ đã thêm `SCN-IAM-07b` |
| `standard` | **mọi tài liệu cùng `sot_doc_version`** | đổi header scheme ⇒ migrate **33 file** |
| xoá/đổi tên file | mọi **link** trỏ tới nó | đổi `01.lifecycle` → `01.sdlc-delivery-lifecycle-standard` ⇒ 2 file ref |

## 3. Ba cột "đổi nguồn ⇒ mở lại" **đã có phép kiểm** (một phần)

| Kiểm | Ở đâu | Bắt được gì |
|---|---|---|
| **link resolve** | trước mỗi commit | file đổi tên/xoá mà link còn |
| **`§` ref** | trước mỗi commit | trỏ tới mục không tồn tại |
| **1:1 AC↔SCN** | RTM ([`03.iam-rtm`](../../03.analysis/04.quality-control/03.iam-rtm.md)) | AC thêm mà SCN thiếu |
| **id không trùng** | đếm id | hai file cùng `AC-*` |
| **header theo vùng** | đếm frontmatter | thiếu `source_of_truth` / `human_sot` |
| **ngân sách spec AI** | `wc -l` / `wc -c` | spec vượt 150 dòng / 4 000 ký tự |

## 4. Cái **chưa** kiểm được — và đó là nợ thật

| Chưa kiểm | Hậu quả |
|---|---|
| `REQ` đổi ⇒ `US` nào phải xem lại | phải **đọc tay** bảng §1 |
| `standard` đổi ⇒ tài liệu nào cùng version | không biết cái nào lệch |
| mapping artifact **dẫn xuất** từ header | `D-50` nói phải sinh; **hiện đang viết tay** |

⇒ Bảng §1 là **bản viết tay của một thứ đáng lẽ sinh ra từ header**. Đó là nợ đã ghi ở
[`05.document-status`](../05.document-status.md), không phải phát hiện mới.
