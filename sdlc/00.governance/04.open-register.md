# 04 — Register `OPEN`: câu chưa rõ, và đề xuất

**Chuẩn:** [`03.sdlc-standard/02.gates.md`](./03.sdlc-standard/02.gates.md) §4 — *"`OPEN` không nằm trong register là **không tồn tại**"*

> **Vì sao file này trước Interface và Data.** Chín câu dưới đây quyết định **hình dạng** của cả API và schema. Viết
> interface trước khi trả lời chúng là **đoán**, rồi schema sẽ phải sửa theo.
>
> Mỗi câu có **đề xuất** để duyệt nhanh. Duyệt = chuyển thành quyết định; không duyệt = sửa đề xuất.

## 1. Chín câu chặn Stage 4–5

| open_id | Câu hỏi | Đề xuất | Ảnh hưởng | Chặn gì |
|---|---|---|---|---|
| **OP-01** | C1 làm mới **cache khai báo** khi nào? | đầu mỗi turn, **nhưng** dùng cache cũ nếu không gọi được; tuổi ghi vào phán quyết | API (có endpoint "pull declaration") · D-46 (TTL) | interface C1↔C2 |
| **OP-02** | Evidence ship **khi nào**? | **hai** thời điểm: ngưỡng kích thước/số mục, và cuối phiên; **không** chặn turn | API ingest (batch) · schema (idempotent) | interface + schema |
| **OP-03** | Ai gọi **graph extractor** — C1 hay C2? Kết quả ghi ở đâu? | **C1 spawn**, kết quả **C1 gửi C2** qua cùng đường evidence (batch riêng) | API · ranh giới container | interface |
| **OP-04** | Lúc chạy, C1 đọc **`harness.profile.json`** hay **DB**? | **file là bản bền, đọc lúc chạy**; DB là bản vận hành + sync (`D-23`) | schema · sync | interface + schema |
| **OP-05** | `visibility` **lưu** hay **tính**? | **tính** từ `project` của artefact × `project` của người hỏi; **không** lưu cờ | schema (không cần cột) | schema |
| **OP-06** | Một turn record = **một bảng + JSONB** hay **nhiều bảng**? | **jsonb** cho phần biến thiên (requirements · answers · elections) + **cột** cho phần hay truy vấn (project · actor · level · mode · at) | schema · index | schema |
| **OP-07** | `project` id do ai sinh, dạng gì? | **A-01 khai** trong `harness.profile.json`; dạng slug ổn định; **không** sinh từ đường dẫn | schema · API · `D-42` | schema |
| **OP-08** | Cache cũ **bao lâu** thì phải hạ mức bảo đảm? | **có TTL khai báo** (mặc định 24h); quá TTL ⇒ `basis` tối đa là `retrieved` và **ghi tuổi** | D-46 · phán quyết | interface + schema |
| **OP-09** | UI đọc evidence **trực tiếp bảng** hay **qua projection**? | **qua endpoint projection** — UI **không** chạm bảng | API · `c4/03` (C1 không phụ thuộc C3) | interface |

## 2. Vì sao chín câu này, không phải mười

Mỗi câu ở trên **đổi hình dạng** của API hoặc schema. Câu không đổi hình dạng thì để `DRAFT`, không chặn.

| Loại câu | Xử lý |
|---|---|
| đổi **hình dạng** API/schema | **phải** chốt trước Stage 4–5 |
| chỉ đổi **giá trị** (ngưỡng, TTL) | là **dữ liệu**, chốt sau được |
| đổi **hành vi** nhưng không đổi hình dạng | là quyết định ở stage sau |

## 3. Ba câu tôi **không** đưa vào, và vì sao

| Câu | Vì sao không chặn |
|---|---|
| Neo4j khi nào | đã có trigger rõ ([`D-22`](../01.inception/02.decision-log/00.index.md)); schema Postgres **không** đổi theo |
| UI dùng chart library nào | không đổi API (OP-09 đã chốt: qua projection) |
| tên gọi bề mặt | đã chốt Control Plane ([`D-35`](../01.inception/02.decision-log/00.index.md)) |

## 4. Cách đóng một `open_id`

1. Duyệt đề xuất ⇒ ghi thành quyết định `D-nn`, trỏ về nó từ đây.
2. Đổi `status` của dòng thành `ĐÓNG · D-nn`.
3. Nếu đề xuất bị **bác** ⇒ ghi phương án thay thế, **không** xoá dòng.

**Không** xoá dòng đã đóng: nó là bằng chứng rằng câu đó **đã** được hỏi — và người đọc sau cần biết nó **không** bị bỏ qua.
