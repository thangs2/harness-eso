## 2. Three root rules

| Rule | Content |
|---|---|
| **L1 · Invent nothing** | missing information ⇒ **`OPEN`** with where it will come from. Never infer and present it as fact |
| **L2 · One unticked box ⇒ block** | gates have no partial pass. `P` means **a gap was named**, not "nearly there" |
| **L3 · Change a source ⇒ reopen** | edit `REQ`/`US`/`AC`/`BR` ⇒ every dependent document **must** be marked ([`03`](./03.artifacts.md) §5) |

**L2 and L3 are the rules ESO breaks most** — L2 because "probably enough", L3 because one edit gets made and the rest forgotten.

| Question | If not |
|---|---|
| Does each stage have a **gate** and **evidence**? | the standard is only a description |
| Does each **mark/status** have a closed definition? | `P` and `—` get confused and progress lies |
