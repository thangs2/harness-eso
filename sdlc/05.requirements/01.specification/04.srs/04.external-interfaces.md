# SRS `10` — Giao diện ngoài

## 1. HTTP — 21 endpoint `API-1`…`API-22`

| Nhóm | Endpoint |
|---|---|
| Bằng chứng | `API-1` batch · `API-21` turns/:id |
| Tri thức | `API-2` declarations:sync |
| Chẩn đoán | `API-3` diagnosis · `API-4` projections/{name} |
| Kiến trúc | `API-5` graph:batch |
| Đội | `API-7` workers · `API-8` roles · `API-9` policies · `API-10` flows |
| Nợ | `API-11` risk:event |
| Cấu hình | `API-12` preview · `API-13` save · `API-14` revert |
| SDLC | `API-15` init · `API-16` check · `API-17` upgrade |
| Ticket | `API-18` pack |
| Học | `API-19` propose · `API-20` apply |
| Ngoại lệ | `API-22` bypass |

**`API-6` chưa có thân** — đã đăng ký trong index, chưa có đặc tả. Xem `OPEN` ở registry.

→ [`01.contracts`](../../../07.technical/03.api/01.contracts.md)

## 2. Mã lỗi

Registry là **nguồn duy nhất**; mã dùng mà chưa đăng ký là **chưa tồn tại**. Kiểm bằng `X9b`.

→ [`00.index` §4](../../../07.technical/03.api/00.index.md)

## 3. Dữ liệu

Bảng + `CHECK` + khoá ngoại. `project` và `visibility` là hai trục **trực giao** (`BR-13`).

→ [`02.schema`](../../../07.technical/02.data-design/02.schema.md)

## 4. Host

Ba năng lực tối thiểu: đọc/ghi file · chạy lệnh · gọi phán quyết. Thiếu ⇒ `none` + hạ bảo đảm.

→ [`11.host-capability`](../../../07.technical/01.architecture/11.host-capability.md)

## 5. Lệnh cục bộ

`init profile` · `observe` — đường chạy không qua HTTP.
