# SRS `03` — Yêu cầu chức năng

**Nguồn duy nhất:** [`04.requirements`](../../04.requirements.md) — SRS **không** chép lại phát biểu.

## 1. Hai mươi mốt yêu cầu

| Nhóm | id | Ưu tiên |
|---|---|---|
| Host | `REQ-HOST-01` `REQ-HOST-02` `REQ-HOST-03` | MUST · MUST · MUST |
| Console (control plane) | `REQ-UI-01` | MUST |
| Knowledge | `REQ-KB-01` `REQ-KB-02` `REQ-KB-03` | MUST · MUST · SHOULD |
| Knowledge artifacts | `REQ-KNOW-01` `REQ-KNOW-02` `REQ-KNOW-03` `REQ-KNOW-04` `REQ-KNOW-05` | MUST · MUST · SHOULD · MUST · MUST |
| Judge | `REQ-JUDGE-01` `REQ-JUDGE-02` `REQ-JUDGE-03` `REQ-JUDGE-04` | 4 MUST |
| Evidence | `REQ-EVID-01` `REQ-EVID-02` `REQ-EVID-03` | MUST · MUST · SHOULD |
| Agent | `REQ-AGENT-01` `REQ-AGENT-02` | MUST · MUST |
| Architecture | `REQ-ARCH-01` `REQ-ARCH-02` `REQ-ARCH-03` | MUST · SHOULD · MUST |
| Memory | `REQ-MEM-01` | MUST |
| Learning | `REQ-LEARN-01` `REQ-LEARN-02` | SHOULD · MUST |

**19/19 id viết đủ** — index viết tắt (`\`-02\``) thì không grep được, và một index không grep được là index không kiểm được.

## 2. Điều kiện đã đặc tả

Mỗi `REQ` trong shard đã có đủ bốn thứ: phát biểu kiểm được · **không thuộc** (ranh giới) · **kiểm bằng** (đường kiểm) ·
ưu tiên MoSCoW. Bảng §3 của shard là chỗ kiểm điều này.
