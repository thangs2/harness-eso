## 2. Vì sao NFR tách 6 file

Mỗi nhóm có **cách đo riêng** và **người chốt ngưỡng riêng** (hiệu năng = Arch · bảo mật = Security · toàn vẹn = BE).
Gộp một file thì mỗi lần chốt một ngưỡng là một lần sửa file mà ba người cùng mở.
