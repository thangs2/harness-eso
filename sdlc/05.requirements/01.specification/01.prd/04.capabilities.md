# PRD `04` — Năng lực sản phẩm

**Nguồn:** [`06.eso-features`](../../../06.analysis/01.business-analysis/06.eso-features.md) — mỗi chức năng có actor ·
`REQ` · `UC` · `US` · số `AC` · trạng thái.

## 1. Hai mươi ba năng lực — 18 của v1, 5 của v2

| Nhóm | id | Năng lực |
|---|---|---|
| Phán quyết | `F-01` … `F-04` | mức đủ/thiếu · nêu thiếu gì · cảnh báo · giải thích vì sao |
| Bằng chứng | `F-05` · `F-06` | ghi & tra record · đánh dấu quá khứ khi revert |
| Tri thức | `F-07` · `F-08` · `F-09` | chọn theo `applies_when` · nâng `shared` · cô lập project |
| Học | `F-10` | đề xuất tự sửa cách làm |
| Đội | `F-11` · `F-12` | worker/role/policy/flow · duyệt nợ |
| Cấu hình | `F-13` · `F-14` | page config · thiết lập SDLC |
| Host | `F-15` | chọn nguồn năng lực |
| Kiến trúc | `F-16` | mô hình + 5 câu hỏi |
| Ticket | `F-17` · `F-18` | pack · đặt "xong" |

## 2. Mỗi năng lực có **một** file đặc tả

Bảng hành vi chi tiết (vào · ra · từ chối · mã lỗi · `AC`) nằm ở **FRD**, một file cho mỗi chức năng:
[`03.frd/`](../03.frd/00.index.md).

## 3. Revision rule

Sai khi `06.eso-features` có chức năng mới mà `03.frd/` không có file tương ứng.
