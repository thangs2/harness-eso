# BRD `05` — Mười bốn quy trình nghiệp vụ

Mỗi use case có: actor · trigger · trước/sau · **luồng chính có bước** · **luồng thay thế có mã** · bất biến.

| id | Use case | Actor | Điều kiện sau (một câu) |
|---|---|---|---|
| `UC-01` | Hỏi **đã đủ chưa** | A-02 · A-01 | một phán quyết kèm lý do, **giống nhau** bất kể ai hỏi |
| `UC-02` | Nói **"chưa đủ"** và **thiếu gì** | A-02 | danh sách thiếu **cụ thể**, không phải "cần thêm context" |
| `UC-03` | Ghi lại **vì sao** | A-02 | đọc lại được sau N tháng, **không cần hỏi ai** |
| `UC-04` | Khai **đội agent** | A-01 | cùng một việc, agent khác vai ⇒ xử lý khác |
| `UC-05` | Đưa **project** vào | A-01 | tri thức **riêng**, không lẫn project khác |
| `UC-06` | Chọn **skill/luật nào áp** | A-02 | chọn **kiểm được**: vì sao áp, vì sao không |
| `UC-07` | **Nâng** skill dùng chung | A-01 | mọi project theo bản mới, **trừ** project đã đè |
| `UC-08` | **Rút lại** skill đã nâng | A-01 | biết **artefact nào** đã tạo trên bản hỏng |
| `UC-09` | Hỏi **"vì sao bị chặn"** | A-01 · A-08 | trả lời được **không cần đọc log thô** |
| `UC-10` | Hệ **đề xuất tự sửa** | A-02 → A-01 | đề xuất có **bằng chứng** và **cách lùi** |
| `UC-11` | **Duyệt** ticket đã xong | A-01 | `Done` chỉ khi **người** nói Done |
| `UC-12` | Hiểu project **gồm những gì** | A-02 | biết phải đọc file nào, **không** đọc cả repo |
| `UC-13` | **Cảnh báo dù không hỏi** | Hệ → A-01 · A-02 | `unsurfaced` giảm: phán quyết được nêu ra |
| `UC-14` | Chọn **nguồn năng lực** | A-02 | nhánh đã chọn **được ghi**; thiếu hết ⇒ `none` + hạ bảo đảm |
