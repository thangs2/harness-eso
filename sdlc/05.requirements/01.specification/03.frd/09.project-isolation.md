# FRD `F-09` — **Cô lập project**

**Use case:** UC-05 · **Actor:** — (cưỡng chế) · **Nhóm `AC`:** `AC-KB*`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | mọi truy vấn đọc/ghi |
| **Đầu ra** | 0 dòng của project khác; hỏi chéo trả **"không tìm thấy"** |
| **Luật xử lý** | `BR-12` `BR-13` |
| **Trạng thái** | — |

## 2. Kiểm hợp lệ

1. cô lập ở **tầng dữ liệu**, không phải "câu truy vấn viết cẩn thận"
2. câu trả lời cho *có nhưng ngoài quyền* **giống hệt** câu cho *không có*

## 3. Từ chối

- truy vấn chéo project ⇒ 0 dòng, không lỗi
- hai truy vấn không `SET project` ⇒ 0 dòng, **không** trả toàn bộ

## 4. Mã lỗi
