# FRD `F-07` — Chọn tri thức theo **`applies_when`**

**Use case:** UC-06 · **Actor:** A-02 · **Nhóm `AC`:** `AC-KB*`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `API-2` `POST /v1/declarations:sync` · `declaration` ở `pool`/`shared`/`project` |
| **Đầu ra** | `Resolved{…}` — mỗi mục ghi `from` = `project` / `shared` / `pool` |
| **Luật xử lý** | `BR-02` |
| **Trạng thái** | — |

## 2. Kiểm hợp lệ

1. `override` của project **thắng**; ghi `overridden_by`
2. cùng input ⇒ **cùng thứ tự** (tất định)
3. không mục nào khớp ⇒ trả lời được **vì sao không**

## 3. Từ chối

- sửa `applies_when` khi không có quyền ⇒ từ chối + ghi
- xung đột sync ⇒ **dừng**, nêu file + hai hash, không tự chọn bản thắng

- ``FORBIDDEN``

→ registry: [`00.index` §4](../../../07.technical/03.api/00.index.md). Mã không có trong registry là **chưa tồn tại**.
