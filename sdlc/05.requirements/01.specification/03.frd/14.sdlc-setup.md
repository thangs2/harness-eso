# FRD `F-14` — **Thiết lập SDLC**

**Use case:** UC-05 · **Actor:** A-01 · **Nhóm `AC`:** `AC-SDLC*`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `API-15` init · `API-16` check · `API-17` upgrade |
| **Đầu ra** | cây · header · template · cổng theo profile |
| **Luật xử lý** | `BR-09` |
| **Trạng thái** | — |

## 2. Kiểm hợp lệ

1. `init` sinh **đủ** cây; thiếu khai báo thì **không** sinh gì
2. `upgrade` nâng **tất cả** + trả ảnh hưởng; revert một hành động

## 3. Từ chối

- `init` khi thiếu khai báo ⇒ từ chối, nêu thiếu gì, **0** file sinh
- `init` khi đã có cây ở gốc cũ ⇒ **không** sinh cây thứ hai

## 4. Mã lỗi

_Không có mã lỗi riêng — từ chối theo luật ở §3._

→ registry: [`00.index` §4](../../../07.technical/03.api/00.index.md). Mã không có trong registry là **chưa tồn tại**.

- `AC`: `AC-SDLC*` — xem [`03.acceptance-criteria`](../../../06.analysis/03.acceptance-criteria/) theo tiền tố.
