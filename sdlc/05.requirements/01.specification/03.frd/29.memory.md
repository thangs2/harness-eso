# `F-24` — ESO native memory: short + long, typed/versioned, portable

**Nhóm `AC`:** `AC-MEM*`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | fact/decision/pattern/preference từ một turn hoặc migration agentmemory; `project`, `scope` (`repo`·`service`·`route`·`module`), `sessionIds`, `files`, topology refs |
| **Xử lý** | chuẩn hoá record; version mới nếu sửa; tính `strength`; promote short→long khi đủ điều kiện; recall theo keyword/concept + traversal topology |
| **Đầu ra** | record typed/versioned + `provenance`; recall trả `hit`/`weak`/`miss`; `migrated-from/at` khi migrate |
| **Luật xử lý** | `REQ-MEM-01` · `ESO-MEMORY` E-1…E-7 |
| **Trạng thái** | `declared` → `stored` → `recalled` |

## 2. Kiểm hợp lệ

- thiếu `id`/`version`/`type`/`content`/`provenance`/`scope` ⇒ **từ chối**
- record append-only; sửa ⇒ **version mới**, bản cũ còn, `isLatest` đúng
- `fetch` phân biệt `hit`/`weak`/`miss`; **miss không được** trả như hit yếu
- memory project A **không** đọc được từ project B
- host adapter không được giữ bản sao riêng; mọi host đọc/ghi cùng SoT
- migrate agentmemory phải giữ đủ 12 trường + `migrated-from`/`migrated-at`

## 3. Từ chối

- **Record thiếu trường bắt buộc** — từ chối ghi; không suy diễn giá trị.
- **Update/delete trực tiếp record** — từ chối; append version mới.
- **Copy memory sang từng host** — từ chối; host chỉ là adapter tới cùng SoT.
- **Trả `absent` khi recall `miss`** — từ chối; `miss` khác `absent`.
