# FRD `F-16` — **Mô hình kiến trúc** + 5 câu hỏi

**Use case:** UC-12 · **Actor:** A-02 · **Nhóm `AC`:** `AC-ARCH*` · `AC-GRAPH*`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `API-5` `POST /v1/graph:batch` |
| **Đầu ra** | danh sách file + `completeness` **của từng câu hỏi** |
| **Luật xử lý** | `BR-05` |
| **Trạng thái** | — |

## 2. Kiểm hợp lệ

1. độ phủ đo **theo từng câu hỏi**, không phải một số chung
2. `unknown` kèm **độ phủ**, **không** `absent`
3. thừa file cũng là sai như thiếu file

## 3. Từ chối

- hỏi trên **đường turn** ⇒ không chạy (câu nặng chạy ngoài)
- graph vừa rebuild ⇒ coverage 0, **không** claim phủ đủ

## 4. Mã lỗi

_Không có mã lỗi riêng — từ chối theo luật ở §3._

→ registry: [`00.index` §4](../../../07.technical/03.api/00.index.md). Mã không có trong registry là **chưa tồn tại**.
