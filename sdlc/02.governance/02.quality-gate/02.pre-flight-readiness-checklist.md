## 3. Escalation

| Situation | Action |
|---|---|
| one **wrong** box in stages 1–5 | **stop**, fix the document, do not start the slice |
| interface/data missing but logic verified | **`READY-SPLIT`** — do the available part, hold the rest **by name** |
| BIP `BLOCKED` | must carry an **owner** in [`04.open-register`](../04.open-register.md) |
