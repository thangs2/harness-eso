# US-ARCH-01 — Hiểu project **gồm những gì** trước khi sửa

## Story

> **Là** lead, **tôi muốn** hỏi *"sửa X thì phải đọc file nào"* và nhận câu trả lời **kèm độ phủ của chính câu hỏi đó**, **để** không phải đọc cả repo để tìm ra 5 file.

## Độ phủ theo **từng câu hỏi**, không một số chung

Năm câu hỏi ở [`15 §1`](../../07.architecture/15.code-graph-baplatform.md), và mỗi câu có độ phủ riêng — câu code-level cao, câu
tenant-level thấp. Một `completeness` chung sẽ **che** đúng chỗ mù.


## AC

| ID | type | Nội dung |
|---|---|---|
| `AC-ARCH-01-01` | happy | trả danh sách file + `completeness` **của câu hỏi đó** |
| `AC-ARCH-01-02` | edge | graph chưa đủ ⇒ `unknown` kèm độ phủ, **không** `absent` |
| `AC-ARCH-01-03` | failure | câu hỏi nặng **không** chạy trên đường turn |
| `AC-ARCH-01-04` | edge | `id` node **ổn định** qua rebuild |
