# US-CONSUMER-01 — Consumer API không vượt project của token

## Story

> **Là** operator, **tôi muốn** mọi endpoint consumer chỉ đọc/ghi project gắn với token, để token project A không tạo, xem hoặc sửa profile của project B.

## Giá trị thật thuộc về ai

| Ai | Hậu quả nếu không có |
|---|---|
| **A-01** | một token có thể thao tác dữ liệu của consumer khác |
| **A-02** | không thể tin ranh giới tenant khi review hoặc chạy multi-consumer |

## Vì sao không gộp với US khác

`US-GRAPH-03` chỉ cô lập graph; consumer API là bề mặt control-plane riêng. Gộp sẽ khiến một AC graph phải kiểm một route consumer — sai chủ.

## Trong phạm vi

- `ESO_AUTH_PROJECT` là project của token.
- `ConsumerController` lấy project từ auth context, không tin `body.id`.
- `list` chỉ trả project của token.
- `create`/`plan` với `id` khác project ⇒ `403 OUT_OF_SCOPE`.
- Thiếu `ESO_AUTH_PROJECT` ⇒ fail closed.

## Ngoài phạm vi

- Graph schema, API-28, Q1–Q5, docs graph.
- Multi-token/multi-project mapping (MVP một token = một project).
