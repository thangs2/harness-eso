# `policy` — luật dạng vị từ, ghim `role_version`

```sql
CREATE TABLE policy (
  project    text NOT NULL,
  policy_id  uuid NOT NULL,
  version    int  NOT NULL,
  attribute  text NOT NULL REFERENCES attribute_def (name),
  operator   text NOT NULL,            -- eq | starts_with | in
  value      text NOT NULL,
  effect     text NOT NULL,            -- allow | deny
  subjects   jsonb NOT NULL,           -- [{role_name, role_version}] — GHIM version, không tên trần
  status     text NOT NULL,
  PRIMARY KEY (project, policy_id, version)
);
```

**`subjects` ghim `role_version`, không giữ tên trần.** `role` có `version` và `status ∈ {current, superseded}`; giữ tên
trần thì `role@7` đổi `bar` ⇒ luật áp cho `build` **đổi kết quả** mà `policy` **không đổi một byte** ⇒ cùng một câu hỏi,
hai phán quyết — **`BR-01` vỡ**, và **không có gì** báo sai.

| | |
|---|---|
| Dạng | `[{ "role_name": "build", "role_version": 7 }]` |
| Đổi vai | **tạo** `policy` version mới — không sửa `subjects` cũ |
| Vai bị xoá | `subjects` vẫn trỏ version cũ; luật cũ **đọc lại được** (append-only) |
| Kiểm | `subjects[i].role_version` phải tồn tại trong `role` ở version đó — **không** cần `status='current'` |

## Quyết định uỷ quyền ghi vào **đâu**

`AC-IAM-03-01` đòi ghi **cả hai** luật khớp + luật quyết. **Không** thêm bảng `authz_decision`:

```sql
-- dùng evidence_item có sẵn
INSERT INTO evidence_item (project, turn_id, seq, kind, payload)
VALUES (…, 'authz', '{"matched":[…],"decided":…,"effect":"deny"}');
```

**Vì sao không bảng riêng:** nó **là** evidence; thêm bảng là thêm **đường ghi thứ hai** vào cùng một sự thật — và hai
đường thì một đường sẽ quên `scope`.

## `cite` policy — và vì sao **không** chứng minh được "có hiệu lực lúc đó"

`16.why-cites` `OPEN-6`. `D-63` `DQ-11`.

`policy` ghim **`role_version`** nhưng **không** ghim **thời điểm hiệu lực**. Nên câu *"policy này có hiệu lực lúc turn đó không"*
**không trả lời được từ dữ liệu** — và cố trả lời nó là dựng một trục thời gian thứ hai bên cạnh `version`.

**Đóng bằng `OUT`:** `cite` mang **`policy_version`**, và thế là **đủ**. "Có hiệu lực lúc đó" là **suy luận** từ version, không
phải dữ liệu. Ghi ra để người sau không đi tìm một cột không nên tồn tại.
