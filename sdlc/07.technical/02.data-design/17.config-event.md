# `config_event` — lịch sử cấu hình, cho `API-14` revert

> Thêm 2026-10-26 — [`X9`](../../02.governance/01.document-status.md) tìm ra: `E14 config:revert` cần `event_id` (lần lưu gần nhất) và
> `marked_artifacts`, mà **không bảng nào giữ**.

```sql
CREATE TABLE config_event (
  project     text        NOT NULL,
  event_id    uuid        NOT NULL,
  version     int         NOT NULL,      -- version sau lần lưu này
  kind        text        NOT NULL,      -- save | revert
  marked      jsonb       NOT NULL,      -- artefact bị đánh dấu khi revert
  actor       text        NOT NULL,
  at          timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (project, event_id)
);
```

**`revert` là một sự kiện, không phải `UPDATE`** — cùng nguyên tắc evidence: dời con trỏ thì **ghi** một sự kiện, không sửa lịch sử.
