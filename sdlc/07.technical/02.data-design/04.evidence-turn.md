# `evidence_turn` — một turn: mức, basis, mode, bốn con số

```sql
CREATE TABLE evidence_turn (
  project      text        NOT NULL,
  turn_id      uuid        NOT NULL,
  at           timestamptz NOT NULL,
  actor_role   text        NOT NULL,
  actor_status text        NOT NULL,      -- FULL | DECLARED | DEGRADED
  level        text        NOT NULL,      -- đóng (xem CONSTRAINT cuối bảng)
  mode         text        NOT NULL,      -- đóng
  basis        text        NOT NULL,      -- đóng
  rule_version text        NOT NULL,      -- để tính lại diagnosis
  payload      jsonb       NOT NULL,      -- requirements · answers · elections · files_used
  CONSTRAINT turn_level_closed  CHECK (level IN ('insufficient','partial','sufficient','cannot-judge','unsurfaced')),
  CONSTRAINT turn_mode_closed   CHECK (mode  IN ('block','ask','do','permitted','bypassed')),
  CONSTRAINT turn_basis_closed  CHECK (basis IN ('retrieved','verified','inferred')),
  CONSTRAINT turn_actor_closed  CHECK (actor_status IN ('FULL','DECLARED','DEGRADED')),
  PRIMARY KEY (project, turn_id)
);
```

**Vì sao `level`/`mode`/`basis` là **cột** chứ không trong `jsonb`:** chúng là **điều kiện lọc** thường xuyên —
*"các turn `cannot-judge` của project X trong 7 ngày"* phải là một index scan, không phải quét `jsonb`.

## Luật sửa

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;

4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
