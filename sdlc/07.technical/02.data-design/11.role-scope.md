# `role_scope` — cặp `(động từ, phạm vi)`

`scope` không phải một chuỗi: nó là **cặp**, nếu không thì "được ghi vào `packages/**`" và "được ghi vào bất cứ đâu" có
cùng một hình dạng.

```sql
CREATE TABLE role_scope (              -- scope là CẶP (động từ, phạm vi)
  project      text NOT NULL,
  role_name    text NOT NULL,
  role_version int  NOT NULL,
  verb         text NOT NULL REFERENCES verb (name),
  kind         text NOT NULL,          -- file | evidence | declaration | risk
  value        text NOT NULL,          -- glob (file) hoặc kind/’*’
  PRIMARY KEY (project, role_name, role_version, verb, kind, value),
  FOREIGN KEY (project, role_name, role_version) REFERENCES role (project, name, version)
);
```

**`verb` có `FK` tới [`verb`](08.verb.md)** — đó là **toàn bộ** cơ chế chặn "động từ lạ", không cần `if` nào trong code.

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `role_scope` khác file này;
3. `03.api` có endpoint ghi vào `role_scope` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
