# `role` — vai: `scope` và `bar`

`role` là **mở** ở `capabilities`, **đóng** ở chỗ khác: tập capability do `AC` đóng, schema **không** đóng — nên nó là
`text[]` tự do.

```sql
CREATE TABLE role (
  project      text NOT NULL,
  name         text NOT NULL,
  version      int  NOT NULL,
  capabilities text[] NOT NULL,        -- be|fe|qc|design|pm|review|lead|p|…  (MỞ — AC đóng tập, schema không)
  bar          jsonb NOT NULL,         -- [{evidence_kind, min_basis}]  — rỗng = không hợp lệ
  status       text NOT NULL,          -- current | superseded
  PRIMARY KEY (project, name, version)
);
```

**`bar` rỗng là không hợp lệ** (`AC-IAM-02-02`) — vai không đòi gì thì không cưỡng chế được gì.

`scope` của vai nằm ở bảng riêng [`role_scope`](11.role-scope.md), vì nó là **cặp** `(động từ, phạm vi)`.

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `role` khác file này;
3. `03.api` có endpoint ghi vào `role` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
