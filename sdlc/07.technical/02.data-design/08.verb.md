# `verb` — tập **đóng** động từ

Động từ là **bảng**, không phải enum trong code ([`D-11`](../../03.inception/02.decision-log/00.index.md)): thêm động từ là thêm
dòng, và `AC-IAM-02-05` kiểm được bằng `FK`.

```sql
CREATE TABLE verb (              -- ĐÓNG: cơ chế chỉ cưỡng chế được động từ nó có tên
  name text PRIMARY KEY          -- read | write | append | approve | configure | handoff
);
```

**Vì sao đóng:** `scope` trỏ tới `verb (name)`, nên một động từ lạ bị **`FK` từ chối** — không cần một `if` nào trong code
để chặn.

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `verb` khác file này;
3. `03.api` có endpoint ghi vào `verb` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
