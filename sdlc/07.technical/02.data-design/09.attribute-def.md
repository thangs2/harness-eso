# `attribute_def` — thuộc tính dùng trong vị từ policy

Thuộc tính là **bảng**, cùng lý do với [`verb`](08.verb.md) ([`D-11`](../../03.inception/02.decision-log/00.index.md)).

```sql
CREATE TABLE attribute_def (     -- ĐÓNG: thuộc tính dùng trong vị từ policy
  name text PRIMARY KEY          -- project | path | harness_source | risk_kind | stage
);
```

`policy.attribute` tham chiếu bảng này, nên một vị từ trên thuộc tính không tồn tại bị `FK` từ chối.

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `attribute_def` khác file này;
3. `03.api` có endpoint ghi vào `attribute_def` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
