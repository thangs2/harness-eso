# `sdlc_profile` — cây SDLC đã thiết lập

> Thêm 2026-10-25 — nợ #2 của [`03.document-status`](../../02.governance/01.document-status.md).

```sql
CREATE TABLE sdlc_profile (
  project        text NOT NULL,
  version        int  NOT NULL,
  sdlc_root      text NOT NULL,        -- documents | docs | sdlc | SDLC | …  (D-49)
  zones          jsonb NOT NULL,       -- [{name: human|agent, path, header_profile}]
  header_profile text NOT NULL,        -- khoá bắt buộc theo vùng
  gates          jsonb NOT NULL,       -- stage → điều kiện
  tools          jsonb NOT NULL,       -- {jira?, notion?, plan?}
  team           jsonb NOT NULL,       -- {presets[], roles[]} — nhóm `team` của D-51
  project_meta   jsonb NOT NULL,       -- {identity, modules, profile_path} — nhóm `project`
  preset_version text,                 -- bản chuẩn đang áp (D-31)
  status         text NOT NULL,        -- current | superseded
  PRIMARY KEY (project, version)
);
```

**`sdlc_root` là dữ liệu, không phải hằng số** ([`D-49`](../../03.inception/02.decision-log/00.index.md)): đổi tên thư mục gốc là **một
version mới**, không phải `UPDATE` — nên lịch sử cấu hình tra được.

**`preset_version` là thứ `sdlc:upgrade` đọc** để biết project nào đang ở bản nào ([`API-17`](../03.api/01.contracts.md)).

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `sdlc_profile` khác file này;
3. `03.api` có endpoint ghi vào `sdlc_profile` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.

## `hash` và `verified_at` ở đâu; `upgrade` lấy `base` từ đâu

`35.config-four-groups` `OPEN-5` · `36.sdlc-setup` `OPEN-3`. `D-63`.

Cả hai cần **bản gốc của từng artefact**, không chỉ hash của cả cây:

```sql
CREATE TABLE sdlc_artifact (          -- con của profile, không phải bảng rời
  project     text NOT NULL,
  version     int  NOT NULL,          -- version của `sdlc_profile`
  path        text NOT NULL,
  content_hash text NOT NULL,         -- `hash` gắn với **version**, không với dòng
  verified_at timestamptz,            -- NULL = `unverified`
  PRIMARY KEY (project, version, path)
);
```

**`upgrade` lấy `base` từ đây**, không từ cây trên đĩa: đĩa là trạng thái **hiện tại** (có thể đã bị sửa tay), `sdlc_artifact`
là trạng thái **đã thoả thuận**. Ba trạng thái §6.1 (`in-sync` · `drifted` · `unknown`) so `content_hash` của đĩa với dòng này.

**`verified_at = NULL` là `unverified`, không phải "verify hỏng"** — đây là `ST6` ở tầng dữ liệu.
