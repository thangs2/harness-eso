# `role_preset` — preset là **nội dung**, không thuộc project

```sql
CREATE TABLE role_preset (
  preset_id text NOT NULL,             -- baplatform-7-roles | …
  version   text NOT NULL,
  content   jsonb NOT NULL,
  PRIMARY KEY (preset_id, version)
);
```

**Ngoại lệ có lý do:** bảng này **không** có `project` — nó thuộc **`pool`** (nguồn chung), không phải dữ liệu project
([`D-48`](../../03.inception/02.decision-log/00.index.md): preset là nội dung, không phải cơ chế). Đọc được bởi mọi project, **ghi** chỉ
`operator`.

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `role_preset` khác file này;
3. `03.api` có endpoint ghi vào `role_preset` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
