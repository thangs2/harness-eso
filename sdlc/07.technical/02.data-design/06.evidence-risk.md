# `evidence_risk` — nợ: mở, nhận, giảm, đóng, mở lại

```sql
CREATE TABLE evidence_risk (
  project  text        NOT NULL,
  risk_id  uuid        NOT NULL,
  seq      int         NOT NULL,
  at       timestamptz NOT NULL,
  gap_id   text        NOT NULL,          -- danh tính CỦA NỢ, không của sự kiện
  event    text        NOT NULL,          -- đóng: xem CHECK bên dưới
  kind     text        NOT NULL,          -- missing-evidence|reverted-source|...
  by       text,
  payload  jsonb       NOT NULL,          -- artifact_ids · missing[] · review_by · reason
  PRIMARY KEY (project, risk_id, seq),
  CONSTRAINT evidence_risk_seq_from_one CHECK (seq >= 1),
  CONSTRAINT evidence_risk_event_closed CHECK (event IN (
      'opened', 'accepted', 'mitigated', 'remediated', 'expired',
      'closed',     -- người đóng: hết nợ. **Không** phải trạng thái cuối (xem `reopened`)
      'reopened'    -- đóng sai ⇒ mở lại; không có nó thì "sửa bằng sự kiện" là lời hứa rỗng
  ))
);
```

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `evidence_risk` khác file này;
3. `03.api` có endpoint ghi vào `evidence_risk` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
