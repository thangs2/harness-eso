# `memory_topology_ref` — neo memory vào **node/edge**, không chỉ vào file

**Nguồn:** [`ESO-MEMORY` E-2](../../05.requirements/03.eso-memory.md) · [`D-73`](../../03.inception/02.decision-log/06.architecture-va-data.md) ·
[`03.v2-high-level-design` §6.3](../01.architecture/03.v2-high-level-design.md) · [`BR-05`](../../06.analysis/01.business-analysis/03.business-rules.md)

`files[]` trả lời *"memory này nói về file nào"*. Một fact kiểu *"`order.created` đổi schema ở v2"* **không thuộc file nào
cả** — nó thuộc một **edge của topology**. Bảng này giữ tham chiếu đó.

**Database:** `ctx` — cùng database với [`memory_record`](24.memory-record.md) ⇒ có **FK thật**. Khác database với `graph`
([`D-73`](../../03.inception/02.decision-log/06.architecture-va-data.md)) ⇒ **không** FK sang `graph_node`/`graph_edge`.
Tham chiếu sang graph là **tham chiếu mềm**.

```sql
CREATE TABLE memory_topology_ref (
  project    text        NOT NULL,       -- = ownerId (D-22); phần ĐẦU của khoá
  memory_id  uuid        NOT NULL,
  version    int         NOT NULL,
  ref_seq    int         NOT NULL CHECK (ref_seq >= 1),
  node_kind  text        NOT NULL,       -- service | route | event | module | file
  node_id    text,                       -- id TẠI THỜI ĐIỂM GHI — có thể chết sau rebuild
  path       text        NOT NULL,       -- toạ độ nguồn — sống sót sau rebuild
  symbol     text,                       -- hàm/class trong path (nếu có)
  commit_sha text,                       -- commit lúc ghi (nếu có)
  PRIMARY KEY (project, memory_id, version, ref_seq),
  CONSTRAINT memory_ref_kind_closed
    CHECK (node_kind IN ('service','route','event','module','file')),
  CONSTRAINT memory_ref_has_coordinate
    CHECK (num_nonnulls(node_id, path, symbol) >= 1),
  FOREIGN KEY (project, memory_id, version)
    REFERENCES memory_record (project, memory_id, version) ON DELETE RESTRICT
);
```

**`node_id` một mình là chưa đủ.** Một lần `drop` + extract lại `graph` là mọi `node_id` trỏ vào hư không, và **không cách
nào biết cái nào đã mất**. Toạ độ nguồn (`path` · `symbol` · `commit_sha`) là thứ **dựng lại được**; `node_id` chỉ để so
khớp nhanh khi graph còn nguyên — hệ quả trực tiếp của [`D-73`](../../03.inception/02.decision-log/06.architecture-va-data.md).

## 1. Phân giải — qua **API**, không qua SQL

| Việc | Cách |
|---|---|
| Từ memory ra node hiện tại | gọi API tra `(path, symbol, commit_sha)` trong database `graph` |
| Từ node ra memory | lọc bảng này theo `(project, node_id)` hoặc `(project, path)` — **cùng** database `ctx` |
| `node_id` đã chết, toạ độ còn | phân giải lại theo toạ độ; **không** coi là mất |
| Không phân giải được | trả **`unknown`**, **không** `absent` ([`BR-05`](../../06.analysis/01.business-analysis/03.business-rules.md)) |

**`ON DELETE RESTRICT`, không `CASCADE`:** memory là evidence, không phải bản sao của graph. Xoá một version memory phải
là quyết định của người, không phải hệ quả của một lệnh dọn bảng — và bảng cha vốn đã append-only (`REVOKE DELETE`).

## 2. Quan hệ với `memory_record`

```text
memory_record (project, memory_id, version) 1 ──── n memory_topology_ref (…, ref_seq)
```

- **0 ref là hợp lệ**: một `preference` không thuộc node nào; khi đó `files[]` (nếu có) là neo duy nhất.
- **n ref cùng một fact**: *"`order.created` đổi schema ở v2"* neo vào cả `event` lẫn `route` tiêu thụ nó.
- Một ref thuộc **đúng một version**: sửa cách neo = version mới của memory, không `UPDATE` bảng này.

## 3. Cô lập project (RLS)

```sql
ALTER TABLE memory_topology_ref ENABLE ROW LEVEL SECURITY;
ALTER TABLE memory_topology_ref FORCE ROW LEVEL SECURITY;

CREATE POLICY memory_ref_project_only ON memory_topology_ref
  USING      (project = current_setting('eso.project', true))
  WITH CHECK (project = current_setting('eso.project', true));
```

Cùng luật với bảng cha: `USING` lọc đọc, `WITH CHECK` chặn ghi, `FORCE` để chủ bảng không bỏ qua policy.

## 4. Index

| Index | Cho truy vấn |
|---|---|
| `(project, node_id)` | *"mọi thứ đã biết về node R"* — traversal (E-4) |
| `(project, path)` | phân giải lại sau rebuild graph |
| `(project, node_kind, path)` | *"mọi `route` đã biết"* |

## 5. Migration

1. Sau [`memory_record`](24.memory-record.md) — FK cần bảng cha.
2. Bật RLS + `REVOKE UPDATE, DELETE, TRUNCATE` **cùng** migration với bảng cha.
3. Không backfill: chưa từng có bảng memory nào (`02.schema` §2 cũ ghi *"`memory_fact` không tồn tại"*).

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `memory_topology_ref` khác file này;
3. `03.api` có endpoint ghi vào `memory_topology_ref` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
