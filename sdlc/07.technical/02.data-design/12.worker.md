# `worker` — một agent, giữ **đúng một** role

```sql
CREATE TABLE worker (
  project        text NOT NULL,
  worker_id      uuid NOT NULL,
  role_name      text NOT NULL,
  harness_source text NOT NULL,        -- host-native | eso-native | external | none
  state          text NOT NULL,        -- declared | active | paused | retired
  PRIMARY KEY (project, worker_id),
  CONSTRAINT worker_state_closed CHECK (state IN ('declared','active','paused','retired'))
);
```

**Nghỉ ⇒ không xoá** ([`D-33`](../../03.inception/02.decision-log/00.index.md)): `state = retired`, dòng vẫn còn — vì việc
đang giữ phải chuyển chủ thành một risk `OPEN`, và một dòng bị xoá thì không chuyển được gì (`AC-IAM-01-02`).

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `worker` khác file này;
3. `03.api` có endpoint ghi vào `worker` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.

## `CHECK` **đã có**; `FK` tới `role` thì **không nên** có

`30.worker-lifecycle` `OPEN-5` nói `worker` *"không có `FK` tới `role`, `state` không có `CHECK`"*. Nửa sau **sai**: `CHECK` có từ
đầu —

```sql
CONSTRAINT worker_state_closed CHECK (state IN ('declared','active','paused','retired'))
```

Nửa trước **đúng, và nên giữ nguyên.** `FK (project, role_name) → role` đòi thêm cột `role_version` vào `worker`, mà `worker`
**không** ghim version vai: vai được nâng version thì worker **vẫn** là worker đó. `FK` sẽ chặn đúng ca nâng vai — tức là chặn
`AC-IAM-02-*`.

**Kiểm tầng ứng dụng**, không `FK`: `API-7` trả `UNKNOWN_ROLE` khi `role_name` không có version nào `current|superseded`.
