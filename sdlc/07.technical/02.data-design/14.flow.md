# `flow` — bàn giao có hướng, mang bằng chứng

```sql
CREATE TABLE flow (
  project   text NOT NULL,
  from_role text NOT NULL,
  to_role   text NOT NULL,
  carries   jsonb NOT NULL,            -- loại bằng chứng phải mang
  PRIMARY KEY (project, from_role, to_role)
);
```

**Không có `flow` cho chiều ngược** — flow **có hướng**; `B→A` là dòng riêng
([`US-IAM-04`](../../06.analysis/02.user-stories/08.flows.md)).

## Luật sửa

File này **sai** khi:

1. DDL ở đây khác DDL chạy thật — file là bản đọc được của schema, không phải nguồn song song;
2. [`01.entities`](01.entities.md) mô tả `flow` khác file này;
3. `03.api` có endpoint ghi vào `flow` mà file này không nêu;
4. một `CHECK` hoặc `FK` bị bỏ mà không có quyết định — mỗi cái đang thay cho một `if` trong code.
