# 03 — Định dạng **declaration**: một skill/rule là gì

> **Vì sao file này chặn.** `C1.3 Resolver` phân giải 3 vùng, nhưng `applies_when` trước đây được mô tả bằng lời ở **bốn chỗ**
> (`D-19` · `D-30` · `03 §3.3` · `03 §3.4`) và **không chỗ nào là định dạng chuẩn**. Không có file này thì `Resolver` **không có
> gì để đọc**.

## 1. Một declaration = **một file markdown** trong git

```text
{zone}/{kind}/{name}.md          # zone: pool | shared | project
                                 # kind: skills | rules
```

```markdown
---
id: jira-flow
version: 1.3
kind: skill
applies_when:
  always: false
  paths: ["**/*.jira.md"]
  tenant_model: multi
  consistency_need: strong
declared_by: A-01
declared_at: 2026-10-25
requires: [jira-pack]
---
# nội dung…
```

| Trường | Bắt buộc | Vì sao |
|---|---|---|
| `id` | ✅ | danh tính **ổn định**; đổi id = đổi mọi tham chiếu |
| `version` | ✅ | **sự thật ghi trong evidence**, không phải để ghim ([`D-31`](../../03.inception/02.decision-log/00.index.md)) |
| `kind` | ✅ | `skill` (nội dung) · `rule` (ràng buộc) |
| **`applies_when`** | ✅ | **điều kiện áp** — thiếu nó là declaration **vô điều kiện**, và vô điều kiện là mặc định áp **mọi** nơi |
| `declared_by` | ✅ | [`D-15`](../../03.inception/02.decision-log/00.index.md): ai khai |
| `requires` | ⬜ | declaration khác phải có trước |

## 2. `applies_when` — **từ vựng đóng 10 thuộc tính**

| Thuộc tính | Giá trị | Lấy từ |
|---|---|---|
| `always` | `true` | — |
| `paths` | glob | đường dẫn file |
| `service_count` | `one` · `few` · `many` · `hundreds` | **đo** từ graph |
| `team_count` | `1` · `2-5` · `6+` | **khai** |
| `consistency_need` | `weak` · `strong` | **khai** |
| `coupling` | `low` · `high` | **đo** từ graph |
| `tenant_model` | `single` · `multi` | **khai** |
| `read_write_ratio` | `read-heavy` · `write-heavy` · `balanced` | **đo** |
| `deploy_independence` | `together` · `apart` | **đo** |
| `observability_need` | `low` · `high` | **khai** |
| `latency_budget` | ms | **khai** |
| `failure_domain` | `one` · `many` | **khai** |

### Luật: **3 thuộc tính phải do người khai**, không được suy

`consistency_need` · `tenant_model` · `failure_domain`

**Vì sao đúng ba cái này:** chúng là **ý định**, không phải thuộc tính của code. Graph **không** suy được "hệ này cần nhất quán
mạnh" — đó là **quyết định của người**.

⇒ Nếu một declaration dùng một trong ba cái đó mà project **chưa khai** ⇒ declaration đó **không khớp**, và hệ phải nói
*"chưa khai"*, **không** mặc định.

### Thuộc tính lạ ⇒ **từ chối khi lưu**

Cùng luật với policy ([`AC-IAM-03-03`](../../06.analysis/03.acceptance-criteria/07.iam-us-03-policies.md)): một điều kiện tham chiếu
thuộc tính không tồn tại là điều kiện **không bao giờ khớp**, và nó **trông như** đang bảo vệ.

## 3. Ba vùng và **thứ tự thắng**

```text
pool      nguồn chung      (A-01 quản)
  ▼ kế thừa
shared    dùng cho mọi project
  ▼ kế thừa
project   tập hiệu lực cuối
```

| Thứ tự | Nguồn | Ghi chú |
|---|---|---|
| 1 (thắng) | `project` **override** | phải khai trong `overrides` — **hiện ra** |
| 2 | `project` **use** | chọn trực tiếp từ pool |
| 3 | `shared` **inheritance** | nâng là nâng cho tất cả ([`D-31`](../../03.inception/02.decision-log/00.index.md)) |
| 4 | `pool` | chỉ là **nguồn**, không tự áp |

**Kết quả phân giải** (`Resolved`) — thứ `Resolver` trả và evidence ghi:

```json
{ "id": "jira-flow", "version": "1.3", "from": "shared", "overridden_by": "project/skills/jira-flow.md" }
```

`from` ∈ `pool` · `shared` · `project`. `overridden_by` chỉ có khi bị đè.

## 4. Điều **không** hợp lệ

| Ca | Vì sao |
|---|---|
| `applies_when` rỗng | vô điều kiện = áp mọi nơi, và đó là **quyết định**, phải viết `always: true` |
| `paths` và `always: true` cùng lúc | mâu thuẫn; `always` thắng và `paths` thành **trang trí** ⇒ từ chối |
| `version` không đổi khi nội dung đổi | evidence sẽ ghi sai bản |
| hai declaration cùng `id` trong **cùng** zone | không xác định cái nào thắng |

## 5. Quan hệ với bảng `declaration`

[`02.schema`](02.schema.md) §2 lưu `(project, kind, path, version, applies_when jsonb, status)`. **File là nguồn**, DB là **bản
vận hành** ([`D-23`](../../03.inception/02.decision-log/00.index.md)); `sync_state` giữ hash hai bên.

**`status`** ∈ `current` · `superseded` · `revoked` — **cả ba đọc được**, chỉ `current` chọn được
([`D-33`](../../03.inception/02.decision-log/00.index.md)).
