# 02 — Schema: bảng, khoá, cưỡng chế

**Nguồn:** [`01.entities.md`](01.entities.md) · [`D-22`](../../03.inception/02.decision-log/00.index.md) · [`D-47`](../../03.inception/02.decision-log/00.index.md)

> **Đây là phác thảo DDL, không phải migration.** Chưa có code ([`D-40`](../../03.inception/02.decision-log/00.index.md)). Mục
> đích: chốt **hình dạng** để BIP có plane D.

## 1. Bốn luật của schema này

| Luật | Cách cưỡng chế |
|---|---|
| **partition theo `project`** | mọi bảng evidence có `project` là **phần đầu** của khoá chính + index đầu tiên |
| **cô lập** | `ROW LEVEL SECURITY` bật trên mọi bảng evidence; policy theo `current_setting('eso.project')` |
| **record chỉ append** | `REVOKE UPDATE, DELETE` khỏi role ứng dụng; ghi qua function `insert` |
| **`jsonb` chỉ cho phần không lọc** | cột nào cần `WHERE`/index **phải** là cột thật ([`D-47`](../../03.inception/02.decision-log/00.index.md)) |

## 2. Bảng evidence

### `evidence_turn`

```sql
CREATE TABLE evidence_turn (
  project      text        NOT NULL,
  turn_id      uuid        NOT NULL,
  at           timestamptz NOT NULL,
  actor_role   text        NOT NULL,
  actor_status text        NOT NULL,      -- FULL | DECLARED | DEGRADED
  level        text        NOT NULL,      -- insufficient|partial|sufficient|cannot-judge|unsurfaced
  mode         text        NOT NULL,      -- block|ask|do|permitted|bypassed
  basis        text        NOT NULL,      -- retrieved|verified|inferred
  rule_version text        NOT NULL,      -- để tính lại diagnosis
  payload      jsonb       NOT NULL,      -- requirements · answers · elections · files_used
  PRIMARY KEY (project, turn_id)
);
```

**Vì sao `level`/`mode`/`basis` là **cột** chứ không trong `jsonb`:** chúng là **điều kiện lọc** thường xuyên —
*"các turn `cannot-judge` của project X trong 7 ngày"* phải là một index scan, không phải quét `jsonb`.

### `evidence_item`

```sql
CREATE TABLE evidence_item (
  project  text     NOT NULL,
  turn_id  uuid     NOT NULL,
  seq      int      NOT NULL,
  kind     text     NOT NULL,             -- judgement | file_use | election | claim
  payload  jsonb    NOT NULL,
  PRIMARY KEY (project, turn_id, seq),
  FOREIGN KEY (project, turn_id) REFERENCES evidence_turn (project, turn_id)
);
```

**`PRIMARY KEY (project, turn_id, seq)` chính là khoá idempotent** của ingest ([`D-47`](../../03.inception/02.decision-log/00.index.md)).
Gửi trùng ⇒ `ON CONFLICT DO NOTHING`; trùng khoá **khác** payload ⇒ `409` ([`E1`](../03.api/01.contracts.md)).

### `evidence_risk`

```sql
CREATE TABLE evidence_risk (
  project  text        NOT NULL,
  risk_id  uuid        NOT NULL,
  seq      int         NOT NULL,
  at       timestamptz NOT NULL,
  event    text        NOT NULL,          -- opened|accepted|mitigated|remediated|expired
  kind     text        NOT NULL,          -- missing-evidence|reverted-source|...
  by       text,
  payload  jsonb       NOT NULL,          -- artifact_ids · missing[] · review_by · reason
  PRIMARY KEY (project, risk_id, seq)
);
```

**Trạng thái risk = `MAX(seq)`**, không phải cột `status` ([`BR-06`](../../06.analysis/01.business-analysis/03.business-rules.md)).

### `declaration`

```sql
CREATE TABLE declaration (
  project      text        NOT NULL,
  kind         text        NOT NULL,      -- skill|rule|policy|agent
  path         text        NOT NULL,
  applies_when jsonb       NOT NULL,      -- globs / always / …
  content_hash text        NOT NULL,
  version      text,
  status       text        NOT NULL,      -- current|superseded|revoked  ([`D-33`](../../03.inception/02.decision-log/00.index.md))
  PRIMARY KEY (project, kind, path, version)
);
```

**`status` ở đây có ba giá trị** — và `revoked` **đọc được**, không chọn được ([`D-33`](../../03.inception/02.decision-log/00.index.md)).

## 3.1 Bảng cho **IAM** — đường ghi đã có endpoint

> Thêm 2026-10-25. Bản trước **không có bảng nào** cho worker/role/policy/flow ⇒ [#1](../../06.analysis/01.business-analysis/05.iam-functions.md)
> đủ Stage 2–3 mà **trống Stage 5**.

### Hai **từ vựng đóng** — là bảng, không phải enum trong code

```sql
CREATE TABLE verb (              -- ĐÓNG: cơ chế chỉ cưỡng chế được động từ nó có tên
  name text PRIMARY KEY          -- read | write | append | approve | configure | handoff
);

CREATE TABLE attribute_def (     -- ĐÓNG: thuộc tính dùng trong vị từ policy
  name text PRIMARY KEY          -- project | path | harness_source | risk_kind | stage
);
```

**Vì sao là bảng, không phải enum trong code:** [`D-11`](../../03.inception/02.decision-log/00.index.md) — ngưỡng/luật là **dữ liệu**.
Thêm động từ là thêm dòng, và `AC-IAM-02-05` kiểm được bằng `FK`.

### Vai **mở**

```sql
CREATE TABLE role (
  project      text NOT NULL,
  name         text NOT NULL,
  version      int  NOT NULL,
  capabilities text[] NOT NULL,        -- be|fe|qc|design|pm|review|lead|p|…  (MỞ)
  bar          jsonb NOT NULL,         -- [{evidence_kind, min_basis}]  — rỗng = không hợp lệ
  status       text NOT NULL,          -- current | superseded
  PRIMARY KEY (project, name, version)
);

CREATE TABLE role_scope (              -- scope là CẶP (động từ, phạm vi)
  project      text NOT NULL,
  role_name    text NOT NULL,
  role_version int  NOT NULL,
  verb         text NOT NULL REFERENCES verb (name),
  kind         text NOT NULL,          -- file | evidence | declaration | risk
  value        text NOT NULL,          -- glob (file) hoặc kind/’*’
  PRIMARY KEY (project, role_name, role_version, verb, kind, value),
  FOREIGN KEY (project, role_name, role_version) REFERENCES role (project, name, version)
);
```

**`verb` có `FK` tới `verb`** — đó là **toàn bộ** cơ chế chặn "động từ lạ", không cần `if` nào trong code.

```sql
CREATE TABLE worker (
  project        text NOT NULL,
  worker_id      uuid NOT NULL,
  role_name      text NOT NULL,
  harness_source text NOT NULL,        -- host-native | eso-native | external | none
  state          text NOT NULL,        -- declared | active | paused | retired
  PRIMARY KEY (project, worker_id)
);
```

**Nghỉ ⇒ không xoá** ([`D-33`](../../03.inception/02.decision-log/00.index.md)): `state = retired`, dòng vẫn còn.

### Luật và flow

```sql
CREATE TABLE policy (
  project    text NOT NULL,
  policy_id  uuid NOT NULL,
  version    int  NOT NULL,
  attribute  text NOT NULL REFERENCES attribute_def (name),
  operator   text NOT NULL,            -- eq | starts_with | in
  value      text NOT NULL,
  effect     text NOT NULL,            -- allow | deny
  subjects   text[] NOT NULL,          -- tên vai
  status     text NOT NULL,
  PRIMARY KEY (project, policy_id, version)
);

CREATE TABLE flow (
  project   text NOT NULL,
  from_role text NOT NULL,
  to_role   text NOT NULL,
  carries   jsonb NOT NULL,            -- loại bằng chứng phải mang
  PRIMARY KEY (project, from_role, to_role)
);
```

**Không có `flow` cho chiều ngược** — flow **có hướng**; B→A là dòng riêng ([`US-IAM-04`](../../06.analysis/02.user-stories/08.us-iam-04-flows.md)).

### Preset là **nội dung**, không thuộc project

```sql
CREATE TABLE role_preset (
  preset_id text NOT NULL,             -- baplatform-7-roles | …
  version   text NOT NULL,
  content   jsonb NOT NULL,
  PRIMARY KEY (preset_id, version)
);
```

**Ngoại lệ có lý do:** bảng này **không** có `project` — nó thuộc **`pool`** (nguồn chung), không phải dữ liệu project
([`D-48`](../../03.inception/02.decision-log/00.index.md): preset là nội dung, không phải cơ chế). Đọc được bởi mọi project, **ghi** chỉ
`operator`.

### Quyết định uỷ quyền ghi vào **đâu**

`AC-IAM-03-01` đòi ghi **cả hai** luật khớp + luật quyết. **Không** thêm bảng `authz_decision`:

```sql
-- dùng evidence_item có sẵn
INSERT INTO evidence_item (project, turn_id, seq, kind, payload)
VALUES (…, 'authz', '{"matched":[…],"decided":…,"effect":"deny"}');
```

**Vì sao không bảng riêng:** nó **là** evidence; thêm bảng là thêm **đường ghi thứ hai** vào cùng một sự thật — và hai đường
thì một đường sẽ quên scope.

## 3.2 Bảng cho **SDLC đã thiết lập**

> Thêm 2026-10-25 — nợ #2 của [`03.document-status`](../../02.governance/03.document-status.md).

```sql
CREATE TABLE sdlc_profile (
  project        text NOT NULL,
  version        int  NOT NULL,
  sdlc_root      text NOT NULL,        -- documents | docs | sdlc | SDLC | …  (D-49)
  zones          jsonb NOT NULL,       -- [{name: human|agent, path, header_profile}]
  header_profile text NOT NULL,        -- khoá bắt buộc theo vùng
  gates          jsonb NOT NULL,       -- stage → điều kiện
  tools          jsonb NOT NULL,       -- {jira?, notion?, plan?}
  team           jsonb NOT NULL,       -- {presets[], roles[]} — nhóm `team` của D-51
  project_meta   jsonb NOT NULL,       -- {identity, modules, profile_path} — nhóm `project`
  preset_version text,                 -- bản chuẩn đang áp (D-31)
  status         text NOT NULL,        -- current | superseded
  PRIMARY KEY (project, version)
);
```

**`sdlc_root` là dữ liệu, không phải hằng số** ([`D-49`](../../03.inception/02.decision-log/00.index.md)): đổi tên thư mục gốc là **một
version mới**, không phải `UPDATE` — nên lịch sử cấu hình tra được.

**`preset_version` là thứ `sdlc:upgrade` đọc** để biết project nào đang ở bản nào ([`E17`](../03.api/01.contracts.md)).

## 3.2b Bảng cho **lịch sử cấu hình** (E14 revert)

> Thêm 2026-10-26 — [`X9`](../../02.governance/03.document-status.md) tìm ra: `E14 config:revert` cần `event_id` (lần lưu gần nhất) và
> `marked_artifacts`, mà **không bảng nào giữ**.

```sql
CREATE TABLE config_event (
  project     text        NOT NULL,
  event_id    uuid        NOT NULL,
  version     int         NOT NULL,      -- version sau lần lưu này
  kind        text        NOT NULL,      -- save | revert
  marked      jsonb       NOT NULL,      -- artefact bị đánh dấu khi revert
  actor       text        NOT NULL,
  at          timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (project, event_id)
);
```

**`revert` là một sự kiện, không phải `UPDATE`** — cùng nguyên tắc evidence: dời con trỏ thì **ghi** một sự kiện, không sửa lịch sử.

## 3.3 Bảng cho **ticket pack**

> Thêm 2026-10-25 — nợ #8 của [`03.document-status`](../../02.governance/03.document-status.md).

```sql
CREATE TABLE ticket_pack (
  project      text        NOT NULL,
  source       text        NOT NULL,     -- jira | notion | local | none
  ticket_key   text        NOT NULL,
  fetched_at   timestamptz NOT NULL,
  content_hash text        NOT NULL,     -- pack lúc đó nói gì
  pack         jsonb       NOT NULL,     -- ac[] · scope[] · verify · forbidden[] · missing[]
  PRIMARY KEY (project, source, ticket_key, fetched_at)
);
```

**Append-only, không `UPDATE`:** ticket đổi thì **pack mới**, pack cũ vẫn là **sự thật** của lần đọc trước. Nhờ vậy trả lời được
*"turn đó chạy trên pack nào"* — cùng lý do `FileUse` ghi hash ([`D-34`](../../03.inception/02.decision-log/00.index.md)).

**`source: "none"`** là giá trị hợp lệ — không tool, không phải lỗi ([`E18`](../03.api/01.contracts.md)).

## 3.4 Bảng **đề xuất** (learning)

```sql
CREATE TABLE proposal (
  project         text NOT NULL,
  proposal_id     uuid NOT NULL,
  version         int  NOT NULL,
  risk_kind       text NOT NULL,          -- loại thiếu lặp lại
  evidence        jsonb NOT NULL,         -- risk_id[] — bằng chứng, không phải ý kiến
  expected_effect text NOT NULL,
  revert          jsonb NOT NULL,         -- BẮT BUỘC (không rỗng)
  status          text NOT NULL,          -- proposed | applied | reverted
  applied_at      timestamptz,
  measure_window  tstzrange,              -- mở khi áp; kết luận sau cửa sổ
  PRIMARY KEY (project, proposal_id, version)
);
```

**`revert` NOT NULL và không rỗng** — ràng buộc ở **schema**, không chỉ ở API: đề xuất không lùi được thì **không tồn tại**.

**`measure_window`** là cách `AC-LEARN-01-04` trở thành dữ liệu: hiệu quả chỉ kết luận được khi cửa sổ đã đóng, và khi cả hai
chỉ số đi đúng chiều.

**`status`** là **tính từ sự kiện**, không phải cột sửa tay — cùng nguyên tắc `evidence_risk` ([`BR-06`](../../06.analysis/01.business-analysis/03.business-rules.md)).

## 4. Cưỡng chế cô lập

```sql
ALTER TABLE evidence_turn ENABLE ROW LEVEL SECURITY;

CREATE POLICY turn_project_only ON evidence_turn
  USING (project = current_setting('eso.project', true));
```

| | |
|---|---|
| Mọi kết nối phải `SET LOCAL eso.project = …` trước khi đọc | nếu không ⇒ **không** thấy dòng nào, không phải thấy hết |
| Thiếu setting ⇒ **rỗng**, không phải toàn bộ | đây là chỗ dễ cấu hình sai nhất |
| `project` **không** đến từ client | [`E1`](../03.api/01.contracts.md) kiểm với credential |

**`visibility` không có cột** ([`D-47`](../../03.inception/02.decision-log/00.index.md)): nó là **phép so** `project` bản ghi × `project`
người hỏi, thực hiện ở tầng ứng dụng. RLS lo **cô lập**; `visibility` lo **quyền xem chi tiết trong cùng project**.

## 5. Chỗ `jsonb` **không** được dùng

| Cấm | Vì sao |
|---|---|
| đặt `level`/`mode`/`basis` trong `payload` | phải lọc/index ⇒ phải là cột |
| đặt `project` trong `payload` | khoá partition phải là cột |
| đặt `at` trong `payload` | truy vấn thời gian là truy vấn phổ biến nhất |

## 6. Index tối thiểu

| Index | Cho truy vấn |
|---|---|
| `(project, at DESC)` trên `evidence_turn` | *"turn gần đây"* |
| `(project, level)` | *"turn `cannot-judge`"* |
| `(project, risk_id, seq)` | vòng đời risk |
| `(project, build_id)` trên `graph_node`/`graph_edge` | rebuild |
| `(project, term)` trên `existence_claim` | tra kết quả âm |
