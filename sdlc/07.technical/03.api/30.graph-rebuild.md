# `API-29` — `POST /v1/graph/rebuild`

`POST /v1/graph/rebuild`

Dựng lại **toàn phần** index của **một** `build_id` đã có — dùng khi build trước hỏng/thiếu, hoặc khi cần chứng minh
**idempotent**: cùng `build_id` dựng lại **không** nhân đôi node/edge ([`AC-GRAPH-03-02`](../../06.analysis/03.acceptance-criteria/57.graph-store-api.md)).

## Hợp đồng

| | |
|---|---|
| **Consumer** | operator / CLI · **không** UI |
| **Trên đường turn** | ❌ — off-path ([`D-22`](../../03.inception/02.decision-log/00.index.md)); trong lúc phán ⇒ `409 HEAVY_ON_TURN` |
| **Idempotent** | ✅ theo `(project, build_id)` — dựng lại N lần ⇒ **cùng** số node/edge, `0` duplicate |
| **Bảng ghi** | `graph_node` · `graph_edge` của **đúng** `build_id` đó; **không** chạm build khác |

```json
POST /v1/graph/rebuild
{ "project": "baplatform", "build_id": "9f1c2a…" }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | cô lập như `API-28` |
| `build_id` | **có** | build **đã** index; nếu chưa từng có ⇒ dựng như `API-28` (cùng kết quả, không lỗi) |

```json
202 Accepted
{ "project": "baplatform", "build_id": "9f1c2a…", "status": "queued",
  "replayed": false, "accepted_at": "2026-11-05T09:10:00.000Z" }
```

| Mã | Khi nào | Ghi chú |
|---|---|---|
| **202** | đã nhận việc | C5 dựng lại off-path; `status: queued` |
| **202** + `PARSE_FAILED` | một file parse lỗi | `failed_files[]`; coverage giảm ([`AC-GRAPH-01-02`](../../06.analysis/03.acceptance-criteria/55.graph-roslyn.md)) |
| **400** | thiếu `project`/`build_id` | `MISSING_INPUT` |
| **403** | project ngoài quyền **hoặc** không tồn tại | `OUT_OF_SCOPE` — **cùng** câu |
| **409** | gọi trong lúc phán | `HEAVY_ON_TURN` |
| **503** | toolchain không dựng được | `TOOLCHAIN_UNAVAILABLE` ([`AC-GRAPH-01-05`](../../06.analysis/03.acceptance-criteria/55.graph-roslyn.md)) |

**Dựng lại là thay thế, không cộng dồn.** Bản ghi của `build_id` cũ bị thay trong **một** giao dịch; không có trạng thái
"nửa index" đọc được. `API-28` **không** được hứa điều này (index lần đầu không có gì để thay).
