# `API-37` — `GET /v1/memory/{id}`

`GET /v1/memory/{id}?project=…&version=…`

Đọc **một** record memory (một version, hoặc bản `is_latest`). Nguồn đọc là view `memory_latest`
([`24` §2](../02.data-design/24.memory-record.md)) — `is_latest` **không** phải cột.

## Hợp đồng

| | |
|---|---|
| **Consumer** | C1 host adapter (đầu phiên) · C3 · CLI · **không** UI |
| **Trên đường turn** | ❌ — đọc memory trong lúc phán vẫn là gọi C2 ⇒ `409 HEAVY_ON_TURN` ([`D-46`](../../03.inception/02.decision-log/00.index.md)) |
| **Idempotent** | — (chỉ đọc) |
| **Bảng đọc** | `memory_record` (qua view `memory_latest`) · `memory_topology_ref` |

```json
GET /v1/memory/8f2c1d4e-…?project=baplatform
```

| Tham số | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | thiếu ⇒ `400 MISSING_INPUT` |
| `version` | không | vắng ⇒ bản `is_latest`; không phải số nguyên ⇒ `400 MISSING_INPUT` |

```json
200 OK
{ "project": "baplatform", "memory_id": "8f2c1d4e-…", "version": 2,
  "memory_type": "fact", "title": "…", "content": "…",
  "concepts": [], "files": ["src/Orders/Order.cs"], "session_ids": ["turn-9f1c2a"],
  "strength": 0.7, "strength_effective": 0.62, "tier": "long",
  "scope_kind": "service", "scope_value": "orders", "provenance": "native",
  "migrated_from": null, "migrated_at": null, "content_hash": "sha256:…",
  "created_at": "2026-11-04T10:00:00.000Z", "updated_at": "2026-11-05T09:40:00.000Z",
  "is_latest": true,
  "topology": [ { "ref_seq": 1, "node_kind": "route", "node_id": "n-17",
                  "path": "src/Orders/Order.cs", "symbol": "Create", "commit_sha": "c1a…" } ],
  "as_of": "2026-11-05T09:45:00.000Z" }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `is_latest` | **có** | **tính** từ view tại thời điểm đọc — không lưu |
| `strength_effective` | **có** | `strength × exp(−λ · (now − updated_at))`, tính lúc đọc ([`24` §4](../02.data-design/24.memory-record.md)); `as_of` nói tính ở lúc nào |
| `topology[]` | **có**, có thể `[]` | `ref_seq` theo thứ tự đã ghi; toạ độ nguồn (`path`/`symbol`/`commit_sha`) sống sót sau rebuild graph |
| `content` | **có** | nội dung của **đúng** version được hỏi, không phải bản mới nhất nếu `version` được chỉ định |

| Mã | Khi nào | HTTP |
|---|---|---|
| `NO_RECORD` | không có `(project, memory_id, version)` — record chưa từng có hoặc version không tồn tại | 404 |
| `MISSING_INPUT` | thiếu `project`, hoặc `version` không phải số nguyên | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại (memory project B **không** được lộ) ([`AC-MEM-01-03`](../../06.analysis/03.acceptance-criteria/59.memory-contract.md)) | 403 |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
