# `API-12` — `POST /v1/config:preview`

`POST /v1/config:preview`

```json
{ "project": "baplatform", "change": { "group": "sdlc", "from": "…", "to": "…" } }
```

| | |
|---|---|
| **200** | `{ "hash": "sha256:…", "impact": { "consumers": [], "overrides": [], "artifacts": [] } }` |
| **400** | nhóm không thuộc **bốn nhóm** (`sdlc` · `team` · `tool` · `project`) ⇒ `UNKNOWN_GROUP` |

**`hash` là bắt buộc để lưu** — nó gắn preview với **đúng** thay đổi sẽ lưu ([`AC-IAM-06-02`](../../06.analysis/03.acceptance-criteria/10.iam-us-06-config.md)).

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà file bảng không đổi · mã lỗi ở đây không còn trong
registry · hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.

## Bảng

| Bảng | Đọc/ghi | Cột |
|---|---|---|
| [`sdlc_profile`](../02.data-design/16.sdlc-profile.md) | **đọc** | `version` · `team` |
| [`role_preset`](../02.data-design/15.role-preset.md) | **đọc** | `preset_id` · `version` · `content` — nguồn của **diff** ở `ST5` |

`role_preset` là **nội dung dùng chung** (không có `project`), nên `API-12` đọc được mà không phá cô lập: preset không thuộc
project nào. Diff phải đọc nó — không thì `S3` hiện *"preset mới hơn"* mà không biết mới ở đâu.
