# `API-35` — `POST /v1/graph/docs`

`POST /v1/graph/docs`

**Docs graph — doc nào thực sự governs node này.** Trả doc neo vào code/topology bằng quan hệ **cụ thể**
([`US-GRAPH-02`](../../06.analysis/02.user-stories/56.graph-docs.md) · [`AC-GRAPH-02`](../../06.analysis/03.acceptance-criteria/56.graph-docs.md)).

## Hợp đồng

| | |
|---|---|
| **Consumer** | A-02 · CLI / C3 **off-path** · **không** UI graph |
| header | **bắt buộc** `x-eso-turn-phase: off-path \| judging` |
| **Trên đường turn** | ❌ — trong lúc phán ⇒ `409 HEAVY_ON_TURN` |
| **Idempotent** | — (chỉ đọc) |
| **Bảng đọc** | `graph_node` · `graph_edge` (cạnh doc ↔ code/topology) |

```json
POST /v1/graph/docs
{ "project": "baplatform", "node": { "kind": "method", "id": "OrderService.Create" }, "build_id": "9f1c2a…" }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | cô lập project ([`AC-GRAPH-02-04`](../../06.analysis/03.acceptance-criteria/56.graph-docs.md)) |
| `node.kind` | **có** | tập đóng `method` · `service` · `route` · `module` ([`AC-GRAPH-02-01`](../../06.analysis/03.acceptance-criteria/56.graph-docs.md) · `E-3`) |
| `node.id` | **có** | định danh node; thiếu ⇒ `400 MISSING_INPUT` |
| `build_id` | không | như `API-30` |

```json
200 OK
{ "project": "baplatform", "status": "ready",
  "as_of": "2026-11-05T09:30:00.000Z",
  "docs": [ { "doc_path": "sdlc/07.technical/02.data-design/23.project.md",
              "relation": "constrains", "via": [ "doc:project", "method:OrderService.Create" ] } ],
  "unknowns": [] }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `docs[].relation` | **có** | tập đóng `specifies` · `constrains` · `derived_from` · `supersedes` ([`US-GRAPH-02`](../../06.analysis/02.user-stories/56.graph-docs.md) §Trong phạm vi) |
| `docs[].via[]` | **có** | đường đi từ doc tới node — không có đường thì không phải neo |
| `unknowns[]` | **có** | doc **không** anchor ⇒ `unknown`, **không** đoán bằng similarity ([`AC-GRAPH-02-02`](../../06.analysis/03.acceptance-criteria/56.graph-docs.md)) |

**Doc bị supersede không được trả như hiện hành.** Bản cũ chỉ xuất hiện với `relation: supersedes` trỏ **tới bản mới** — trace giữ,
hiện hành là bản mới ([`AC-GRAPH-02-03`](../../06.analysis/03.acceptance-criteria/56.graph-docs.md)).

| Mã | Khi nào | HTTP |
|---|---|---|
| `UNLINKED_DOC` | doc không có anchor ⇒ `status: unknown` + `unknowns[]` | 200 |
| `MISSING_INPUT` | thiếu `project`/`node` | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại | 403 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
