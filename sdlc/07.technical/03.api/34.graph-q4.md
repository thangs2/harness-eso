# `API-33` — `POST /v1/graph/q4`

`POST /v1/graph/q4`

**Q4 — endpoint cần permission gì, grant ở đâu.** Hai tầng: `endpoint → permission → grant`
([`18.graph-queries`](../01.architecture/18.graph-queries.md) §2 · [`AC-ARCH-05`](../../06.analysis/03.acceptance-criteria/34.arch-us-05-permissions.md)).

## Hợp đồng

| | |
|---|---|
| **Consumer** | A-02 · CLI / C3 **off-path** · **không** UI graph |
| **Trên đường turn** | ❌ — trong lúc phán ⇒ `409 HEAVY_ON_TURN` |
| **Idempotent** | — (chỉ đọc) |
| **Bảng đọc** | `graph_node` · `graph_edge` · `completeness` |

```json
POST /v1/graph/q4
{ "project": "baplatform", "endpoint": "POST /api/orders", "build_id": "9f1c2a…" }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | cô lập project |
| `endpoint` | **có** | định danh endpoint trong graph (method + route); thiếu ⇒ `400 MISSING_INPUT` |
| `build_id` | không | như `API-30` |

```json
200 OK
{ "project": "baplatform", "question": "Q4", "status": "ready",
  "as_of": "2026-11-05T09:26:00.000Z",
  "completeness": { "question": "Q4", "value": 0.74,
                    "kinds": { "endpoint": 0.9, "permission": 0.74, "grant": 0.8 }, "floor": 0.7 },
  "answer": { "endpoint": "POST /api/orders", "permission": "Orders.Create",
              "grants": [ { "where": "role:operator", "path": "src/Auth/Permissions.cs" } ],
              "dangling_grants": [] },
  "unknowns": [] }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `answer.permission` | **có** khi `status=ready` | nói permission mà **không** chỉ grant ⇒ `NO_GRANT_PATH` ([`AC-ARCH-05-03`](../../06.analysis/03.acceptance-criteria/34.arch-us-05-permissions.md)) |
| `answer.grants[]` | **có** | mỗi grant phải có `where` |
| `answer.dangling_grants[]` | **có**, có thể `[]` | grant trỏ record đã xoá: **nêu**, không nói "có grant" ([`AC-ARCH-05-05`](../../06.analysis/03.acceptance-criteria/34.arch-us-05-permissions.md)) |

| Mã | Khi nào | HTTP |
|---|---|---|
| `LOW_COVERAGE` | phủ dưới `floor` ⇒ `unknown` | 200 |
| `DYNAMIC_UNKNOWN` | permission **khai động** (string ghép) ⇒ `unknown`, nêu lý do "khai động" ([`AC-ARCH-05-02`](../../06.analysis/03.acceptance-criteria/34.arch-us-05-permissions.md)) | 200 |
| `PERM_UNDECLARED` | endpoint không khai permission ⇒ `unknown`, **không** kết luận "public" | 200 |
| `DANGLING_GRANT` | grant trỏ record đã xoá | 200 |
| `NO_GRANT_PATH` | có permission mà **không** chỉ được grant ⇒ **từ chối** | 422 |
| `MISSING_INPUT` | thiếu `project`/`endpoint` | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại | 403 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
