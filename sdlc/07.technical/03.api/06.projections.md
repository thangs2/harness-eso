# `API-4` — `GET /v1/projections/{name}`

`GET /v1/projections/{name}`

`GET /v1/projections/turns?project=baplatform&page=1` — **UI không chạm bảng** ([`D-47`](../../03.inception/02.decision-log/00.index.md)).

Bốn `name`, **bốn** hình dạng. Mỗi hình dạng chỉ chứa thứ **bề mặt đọc nó** cần — projection thừa trường là bảng bị lách qua cửa sau.

#### `turns` → nuôi **S1** ([`7.2`](../../09.wbs/01.packets/02.fip/02.s1-work.md))

```json
{ "items": [ { "turn_id": "8f2c…", "at": "2026-10-27T14:02:11.000Z", "work": "…",
               "level": "partial", "basis": "verified", "mode": "ask",
               "missing_count": 2 } ],
  "page": 1, "total": 37, "complete": true }
```

| Trường | Vì sao **bắt buộc** |
|---|---|
| `work` | **tên việc** — `AC-UI-01-07` đòi cột này; nó **không** có trong `evidence_turn.payload` ([`4.1` `OPEN`](../../09.wbs/01.packets/01.bip/13.requirement-source.md)) ⇒ xem `OPEN-1` dưới |
| `level` · `basis` · `mode` | **ba** cột, **không** gộp — `AC-UI-01-12` kiểm chúng **khác nhau** trên màn hình |
| `missing_count` | số thiếu của **đúng dòng** (`AC-UI-01-05`), không phải tổng của trang |
| `complete` | `false` khi `completeness` dưới ngưỡng ⇒ `S1` hiện dải cảnh báo (`AC-UI-01-06`) |
| `page` · `total` | `total` là **dữ liệu**, không phải nhãn — đổi trang **không** được làm nó thành *"không còn gì"* |

**Thứ tự: `at` giảm dần** (`AC-UI-01-07`: *"mới nhất trước"*) — **không** theo `turn_id`, **không** theo thứ tự chèn.

#### `risks` → nuôi **S4** ([`7.5`](../../09.wbs/01.packets/02.fip/05.s4-debt.md))

```json
{ "items": [ { "risk_id": "…", "gap_id": "…", "kind": "missing-evidence",
               "state": "accepted", "age_days": 12, "overdue_days": 3,
               "artefacts": ["src/a.ts"], "level": "insufficient", "basis": "verified" } ],
  "page": 1, "total": 8, "complete": true }
```

| Trường | Vì sao **bắt buộc** |
|---|---|
| `kind` | **loại nợ** — `AC-UI-04-07` đòi; và **không** được thay bằng một từ chung ("thiếu") |
| `age_days` | **tuổi** — tính **ở server**; client tính là hai chỗ tính |
| `overdue_days` | **`quá hạn n`** — `null` khi chưa quá hạn, **không** `0` (0 là *"quá hạn 0 ngày"*, khác *"chưa quá hạn"`) |
| `state` | `open` · `accepted` · `expired` · `closed` · `reopened` — **năm** giá trị, **không** gộp `open`+`accepted` |
| `level` · `basis` | để `cannot-judge` và `insufficient` **hiện khác nhau** — hai nợ, hai hành động |
| `artefacts[]` | cột `artefact ⚠` — rỗng là **thật** rỗng, không phải chưa tải |

**`expired` phải có mặt trong danh sách mặc định.** Nó **không** `closed`, **không** `open`, và **không ai bấm** — bộ lọc hai nhóm làm nó **mất hút**.

#### `graph` · `audit`

| `name` | Nuôi | Ghi chú |
|---|---|---|
| `graph` | chẩn đoán, không phải màn hình | hình dạng theo [`18.graph-queries`](../01.architecture/18.graph-queries.md); **chưa** có bề mặt nào đọc ⇒ `OPEN-2` |
| `audit` | **`7.7`** | hình dạng **chưa** chốt — `7.7` đang `OPEN` vì `guarantee` chưa có nhà; **đóng khi** `7.7` `READY` |

| | |
|---|---|
| **200** | `{items, page, total, complete}` — **luôn** đủ bốn khoá; `items: []` là **rỗng thật** |
| **403** | `project` ngoài quyền **hoặc** không tồn tại ⇒ `OUT_OF_SCOPE`, **cùng** câu |
| **400** | `name` ngoài bốn giá trị ⇒ `UNKNOWN_PROJECTION` |
| **`OPEN-1`** | **`work` lấy từ đâu** — `evidence_turn.payload` **không** có trường tên việc. Owner `data`. Chặn `AC-UI-01-07` |
| **`OPEN-2`** | **`graph`/`audit` hình dạng** — chưa bề mặt nào đọc; đóng khi bề mặt đó tồn tại |

## `now` — giờ của **server**, không phải tham số của client

`API-4` **không** nhận `as_of`/`now`. Mọi hình chiếu phụ thuộc thời gian (`risks` với `expired`) được tính ở **giờ server** lúc đọc — đúng
[`D-46`](../../03.inception/02.decision-log/00.index.md) *"câu trả lời là sự thật ở thời điểm đọc"* và [`D-83`](../../03.inception/02.decision-log/06.architecture-va-data.md).
Test bơm `now` qua **dependency injection** ở tầng process; một client cũ **không** được tự chọn thời điểm để có đáp án khác.

registry · hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.
