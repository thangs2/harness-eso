# `API-2` — `POST /v1/declarations:sync`

| | |
|---|---|
| Chiều **in** | file → DB, rồi DB → file (out) — thứ tự [`D-24`](../../03.inception/02.decision-log/00.index.md) |
| **200** | `{ "in": n, "out": m, "conflicts": [] }` |
| **409** | có xung đột ⇒ **dừng**, trả danh sách; **không** chọn bên thắng ([`D-23`](../../03.inception/02.decision-log/00.index.md)) |

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà file bảng không đổi · mã lỗi ở đây không còn trong
registry · hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.
