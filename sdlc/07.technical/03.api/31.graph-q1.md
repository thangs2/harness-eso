# `API-30` — `POST /v1/graph/q1`

`POST /v1/graph/q1`

**Q1 — sửa X thì phải đọc file nào.** Trả **read set** quanh một symbol/file, kèm `completeness` **của chính Q1**
([`18.graph-queries`](../01.architecture/18.graph-queries.md) §2–§4 · [`AC-ARCH-02`](../../06.analysis/03.acceptance-criteria/31.arch-us-02-readset.md)).

## Hợp đồng

| | |
|---|---|
| **Consumer** | A-02 · CLI / C3 **off-path** · **không** UI graph (xem [`08.ui-design/01.surfaces`](../../08.ui-design/01.surfaces.md) §7) |
| **Trên đường turn** | ❌ — off-path; trong lúc phán ⇒ `409 HEAVY_ON_TURN` ([`AC-GRAPH-03-05`](../../06.analysis/03.acceptance-criteria/57.graph-store-api.md)) |
| **Idempotent** | — (chỉ đọc) |
| **Bảng đọc** | `graph_node` · `graph_edge` · `completeness` |

```json
POST /v1/graph/q1
{ "project": "baplatform", "symbol": "OrderService.Create", "build_id": "9f1c2a…" }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | cô lập project ([`AC-GRAPH-03-03`](../../06.analysis/03.acceptance-criteria/57.graph-store-api.md)) |
| `symbol` **hoặc** `file` | **đúng một** | thiếu cả hai ⇒ `400 MISSING_INPUT` |
| `build_id` | không | mặc định build mới nhất của project — `OPEN-API-GRAPH-04` |

**Độ sâu là hằng số của câu (≤ 2 tầng), không phải tham số** — [`18` §2](../01.architecture/18.graph-queries.md) cấm traversal không trần.
`floor`/`threshold` là **dữ liệu** ([`D-11`](../../03.inception/02.decision-log/00.index.md)), đọc từ cấu hình server, **không** nhận từ request.

```json
200 OK
{ "project": "baplatform", "question": "Q1", "status": "ready",
  "as_of": "2026-11-05T09:20:00.000Z",
  "completeness": { "question": "Q1", "value": 0.96,
                    "kinds": { "class": 0.98, "method": 0.96, "entity": 0.97, "dto": 0.99, "references": 0.96 },
                    "floor": 0.7 },
  "answer": { "read_set": [ { "path": "src/Order/OrderService.cs", "kind": "method", "via": ["references"] } ],
              "returned": 1, "total": 1, "capped": false },
  "unknowns": [] }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `status` | **có** | `ready` · `unknown` · `refused` |
| `completeness.value` | **có** | phủ **của Q1**; `min` trên `K(Q1)` ([`18` §3](../01.architecture/18.graph-queries.md)) |
| `answer.read_set` | **có**, có thể `[]` | `[]` là **rỗng thật** khi phủ đủ ([`AC-ARCH-02-04`](../../06.analysis/03.acceptance-criteria/31.arch-us-02-readset.md)); vẫn phải nêu phủ của `references` |
| `answer.capped` · `total` | **có** khi bị chặn | danh sách cắt ở trần `maxFanout`; `total` là **tổng thật** ([`AC-ARCH-02-05`](../../06.analysis/03.acceptance-criteria/31.arch-us-02-readset.md)) |
| `unknowns[]` | **có**, kể cả `[]` | `unknown` ≠ `absent` ([`BR-05`](../../06.analysis/01.business-analysis/03.business-rules.md)) |

| Mã | Khi nào | HTTP |
|---|---|---|
| `LOW_COVERAGE` | `value < floor` ⇒ `status: unknown` + `unknowns[]`, **không** kết luận `absent` | 200 |
| `FANOUT_CAPPED` | chạm trần fan-out ⇒ `capped: true` + `total` thật | 200 |
| `NO_COVERAGE` | không có số phủ ⇒ **từ chối** trả lời | 422 |
| `MISSING_INPUT` | thiếu `project`, hoặc không có `symbol`/`file` | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại | 403 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |

**Không bao giờ trả lời trần.** Thiếu `completeness` là `NO_COVERAGE` ([`AC-ARCH-02-03`](../../06.analysis/03.acceptance-criteria/31.arch-us-02-readset.md)).
