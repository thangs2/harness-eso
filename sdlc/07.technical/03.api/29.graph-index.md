# `API-28` — `POST /v1/graph/index`

`POST /v1/graph/index`

Dựng index graph cho **một** `build_id` của một consumer. C2 spawn **C5** (extractor) làm việc nặng dưới đây; C5 là process con,
chạy **theo yêu cầu** ([`01.c4/02`](../01.architecture/01.c4/02.container.md) §1).

## Hợp đồng

| | |
|---|---|
| **Consumer** | `provision.sh` / CLI của operator · **không** có UI (xem [`08.ui-design/01.surfaces`](../../08.ui-design/01.surfaces.md) §7) |
| **Trên đường turn** | ❌ — off-path ([`D-22`](../../03.inception/02.decision-log/00.index.md)); gọi trong lúc phán ⇒ `409 HEAVY_ON_TURN` ([`AC-GRAPH-01-04`](../../06.analysis/03.acceptance-criteria/55.graph-roslyn.md)) |
| **Idempotent** | ✅ theo `(project, build_id)` — cùng khoá, cùng nội dung ⇒ `202` + `replayed: true`; khác nội dung ⇒ `409 CONFLICT` |
| **Bảng ghi** | `graph_node` · `graph_edge` · `source_claim` · `graph_index_run` ([`02.roundtrip`](02.roundtrip.md) §1) |

```json
POST /v1/graph/index
{
  "project": "baplatform",
  "build_id": "9f1c2a…",
  "source": { "kind": "roslyn", "solution_path": "src/App.sln" }
}
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | kiểm với credential; **không** đến từ client không xác thực ([`01.contracts`](01.contracts.md) §4) |
| `build_id` | **có** | khoá idempotency; chuỗi mờ, **không** đặt định dạng ở đây — `OPEN-API-GRAPH-01` |
| `source.kind` | **có** | tập đóng `roslyn` — ngôn ngữ khác là `OUT` ([`D-91`](../../03.inception/02.decision-log/06.architecture-va-data.md) · `US-GRAPH-01` §Ngoài phạm vi) |
| `source.solution_path` | **có** khi `kind=roslyn` | đường dẫn **tương đối** trong consumer root; ra ngoài root ⇒ `403 BLOCKED_SCOPE` |

```json
202 Accepted
{ "project": "baplatform", "build_id": "9f1c2a…", "status": "queued",
  "replayed": false, "accepted_at": "2026-11-05T09:00:00.000Z" }
```

| Mã | Khi nào | Ghi chú |
|---|---|---|
| **202** | đã nhận việc, C5 chạy off-path | `status: queued`; độ phủ **chưa** biết ⇒ không trả số |
| **202** + `PARSE_FAILED` | một file parse lỗi | kèm `failed_files: [{path, error:'PARSE_FAILED'}]`; coverage giảm, **không** node/edge giả ([`AC-GRAPH-01-02`](../../06.analysis/03.acceptance-criteria/55.graph-roslyn.md)) |
| **400** | thiếu `project`/`build_id`/`source` | `MISSING_INPUT` |
| **403** | project ngoài quyền **hoặc** không tồn tại | `OUT_OF_SCOPE` — **cùng** câu |
| **403** | `solution_path` ra ngoài consumer root | `BLOCKED_SCOPE` |
| **409** | gọi trong lúc phán một turn | `HEAVY_ON_TURN` |
| **409** | cùng `(project, build_id)`, khác nội dung nguồn | `CONFLICT` — không ghi đè |
| **503** | thiếu SDK/NuGet/`obj/` hoặc solution không build | `TOOLCHAIN_UNAVAILABLE` ⇒ `OUT`/`UNKNOWN`, **không** `coverage=0` ([`AC-GRAPH-01-05`](../../06.analysis/03.acceptance-criteria/55.graph-roslyn.md)) |

## `OPEN`

| ID | Câu hỏi | Chủ |
|---|---|---|
| `OPEN-API-GRAPH-01` | `build_id` lấy từ đâu (commit SHA? `solution_hash`?) — nguồn có thật nhưng chưa chốt định dạng | `arch` |
| `OPEN-API-GRAPH-05` | **ĐÓNG 2026-11-06 (Stage 5b)** — dùng bảng `graph_index_run (project, build_id, source_kind)` trong DB `graph` để lưu `source_hash` và `status`. Cùng `source_hash` trả về 202 `replayed: true`; khác `source_hash` trả về 409 `CONFLICT`. | `arch` · `data` |
| `OPEN-API-GRAPH-02` | index **tăng dần** hay **toàn phần** cho lần thứ hai — [`15` §5](../01.architecture/15.code-graph-baplatform.md) nêu "incremental" nhưng chưa có luật | `arch` |

## Luật sửa

hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
