# `API-21` — `GET /v1/turns/:id`

`GET /v1/turns/:id`

```json
GET /v1/turns/8f2c…?project=baplatform
```

| | |
|---|---|
| **200** | xem thân bên dưới — **đầy đủ**, không phân trang |
| **403** | `project` ngoài quyền **hoặc** không tồn tại ⇒ **cùng** câu `OUT_OF_SCOPE` ([`6.9`](../../09.wbs/01.packets/01.bip/37.visibility-rule.md)) |
| **404** | `turn_id` **thuộc** project nhưng **không** có record ⇒ `TURN_NOT_FOUND` — khác `403`, và khác **có thật** |
| **410** | record đã bị xoá theo chính sách lưu trữ ⇒ `TURN_GONE`, **không** phải "chưa từng có" |

```json
{
  "turn_id": "8f2c…",
  "at": "2026-10-27T14:02:11.000Z",
  "as_of": "2026-10-27T22:30:00.000Z",
  "level": "partial",
  "basis": "verified",
  "mode": "ask",
  "guarantee": "G-SCOPE",
  "elections": [
    { "id": "graph",    "version": "1.3", "from": "shared",  "overridden_by": ["pool"] },
    { "id": "docgraph", "version": "—",   "from": "none",    "overridden_by": [], "reason": "host không có MCP" }
  ],
  "files_used": [
    { "path": "src/a.ts", "content_hash": "sha256:…", "git_commit": "c1a…", "dirty": false, "gone": true }
  ],
  "cites": [
    { "target": "requirement", "where": { "project": "baplatform", "turn_id": "8f2c…", "seq": 2 },
      "key": "min_basis", "kind": "requirement", "dangling": false }
  ],
  "unknowns": [
    { "what": "artefact đã xoá — lấy lại được qua git, không đọc trực tiếp", "cause": "gone" }
  ]
}
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `level` · `basis` · `mode` | **có** | **ba** trường, **không** gộp một nhãn — gộp làm mất khác biệt `insufficient` vs `cannot-judge` |
| `as_of` | **có** | thời điểm **tính** `expired` — người đọc biết câu trả lời ở lúc nào |
| `guarantee` | **có** | `G-FULL` · `G-SCOPE` · `G-ADVISORY` — **lần chạy này** đáng tin tới đâu |
| `elections[]` | **có**, có thể `[]` | dựng lại **`ORDER BY seq`**; `reason` chỉ có khi `from='none'` |
| `files_used[].dirty` | **có** | **trường** — sự thật lúc ghi |
| `files_used[].gone` | **có** | **tính lúc đọc** — không lưu ([`09` §3.15](../../07.technical/01.architecture/09.evidence-plane.md)) |
| `cites[]` | **có**, có thể `[]` | **tính** mỗi lần đọc; `dangling` là **quan sát**, không phải lỗi |
| `unknowns[]` | **có**, **kể cả khi `[]`** | vắng mặt và rỗng là **cùng** một lời nói dối (`BR-05`) |

**Không có `payload` thô trong response.** `API-21` trả **bản dựng lại**, không trả `jsonb` nguyên bản — nếu không, client sẽ đọc một hình dạng khác với thứ
hàm `replay` đọc, và hai đường sẽ trôi (`BR-01`).

**Không phân trang.** Một turn là **một** đơn vị; cắt nó thành trang là cắt mất `seq_gaps` — thứ duy nhất phân biệt *"mất item 3"* với *"chỉ có 2 item"*.
Nếu record **lớn** (vượt giới hạn phản hồi), trả `413` + `TURN_TOO_LARGE`, **không** trả một phần.

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà file bảng không đổi · mã lỗi ở đây không còn trong
registry · hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.

## Truy vấn ticket **theo turn** — đi qua `API-21`, không qua `API-18`

`45.ticket-traceback` `OPEN-2`. `D-63` `DQ-05`.

`AC-TICKET-04-*` đòi *"truy vấn theo turn"*, mà `API-18` **không** mang `turn_id` (request chỉ có `project` · `source` · `key`).

**`API-21` là cửa duy nhất.** Pack ghi `turn_id` vào `evidence_item` khi tạo, nên `GET /v1/turns/:id` trả được *"turn này chạy trên
pack nào"*. Thêm `turn_id` vào `API-18` là đổi `API-18` thành hai endpoint: một để **tạo**, một để **tra**.

**Vì sao không thêm:** `API-18` là đường **ghi**; tra cứu là đường **đọc**. Trộn hai chiều vào một route làm quyền khó khai — và
`API-18` là đường **ghi** ticket pack, **không** nằm trên turn path; tra theo turn dùng `API-21`.
