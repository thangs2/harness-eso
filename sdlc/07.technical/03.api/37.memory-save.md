# `API-36` — `POST /v1/memory:save`

`POST /v1/memory:save`

Ghi **một version** của một fact memory. Memory **chỉ ghi thêm**: sửa = version mới, không `UPDATE`
([`24.memory-record`](../02.data-design/24.memory-record.md) §4 · [`AC-MEM-01`](../../06.analysis/03.acceptance-criteria/59.memory-contract.md)).

## Hợp đồng

| | |
|---|---|
| **Consumer** | C1 host adapter **sau** khi turn đã phán · CLI · **không** UI ([`08.ui-design/01.surfaces`](../../08.ui-design/01.surfaces.md) §7) |
| **Trên đường turn** | ❌ — off-path; gọi trong lúc phán ⇒ `409 HEAVY_ON_TURN` ([`D-46`](../../03.inception/02.decision-log/00.index.md)) |
| **Idempotent** | ✅ theo `(project, memory_id, version)` — trùng y hệt `content_hash` ⇒ `200` + `replayed: true`; **khác** nội dung ⇒ `409 CONFLICT` |
| **Bảng ghi** | `memory_record` · `memory_topology_ref` |

```json
POST /v1/memory:save
{
  "project": "baplatform",
  "memory_id": "8f2c1d4e-…",
  "version": 1,
  "memory_type": "fact",
  "title": "order.created đổi schema ở v2",
  "content": "…",
  "concepts": ["order.created", "schema"],
  "files": ["src/Orders/Order.cs"],
  "session_ids": ["turn-9f1c2a"],
  "strength": 0.7,
  "tier": "short",
  "scope_kind": "service",
  "scope_value": "orders",
  "provenance": "native",
  "topology": [ { "node_kind": "route", "node_id": "n-17", "path": "src/Orders/Order.cs", "symbol": "Create" } ]
}
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` · `memory_id` · `version` | **có** | khoá chính `(project, memory_id, version)`; `version ≥ 1` |
| `memory_type` | **có** | tập đóng 7 giá trị của [`24` §1](../02.data-design/24.memory-record.md): `workflow` · `architecture` · `fact` · `decision` · `pattern` · `preference` · `bug` |
| `title` · `content` | **có** | nội dung |
| `concepts[]` · `files[]` · `session_ids[]` | **có**, có thể `[]` | điều kiện lọc — mảng, không `jsonb` ([`24` §3](../02.data-design/24.memory-record.md)) |
| `strength` | **có** | `0..1`; decay **tính lúc đọc**, không lưu |
| `tier` | **có** | tập đóng `short` · `long`; promotion short→long là **version mới** ([`AC-MEM-02-02`](../../06.analysis/03.acceptance-criteria/60.memory-store.md)) |
| `scope_kind` · `scope_value` | **có** | tập đóng `repo` · `service` · `route` · `module` (`E-3`) |
| `provenance` | **có** | `native` — record `migrated` **chỉ** vào qua `API-39` (`E-7`) |
| `topology[]` | **có**, có thể `[]` | `{node_kind, node_id?, path, symbol?, commit_sha?}`; `node_kind` ∈ `service` · `route` · `event` · `module` · `file`; thứ tự mảng ⇒ `ref_seq` |
| `content_hash` | không | **server** tính (sha256 nội dung chuẩn hoá) — client không gửi |
| `created_at` · `updated_at` · `is_latest` | không | **server**; version N>1 giữ `created_at` của version 1, `updated_at = now`; `is_latest` là **view**, không phải cột |

```json
201 Created
{ "project": "baplatform", "memory_id": "8f2c1d4e-…", "version": 1,
  "memory_type": "fact", "title": "order.created đổi schema ở v2", "content": "…",
  "concepts": ["order.created", "schema"], "files": ["src/Orders/Order.cs"],
  "session_ids": ["turn-9f1c2a"], "strength": 0.7, "tier": "short",
  "scope_kind": "service", "scope_value": "orders", "provenance": "native",
  "migrated_from": null, "migrated_at": null,
  "content_hash": "sha256:…", "created_at": "2026-11-05T09:40:00.000Z",
  "updated_at": "2026-11-05T09:40:00.000Z", "is_latest": true,
  "replayed": false }
```

| Mã | Khi nào | HTTP |
|---|---|---|
| `INVALID_RECORD` | thiếu trường, `memory_type`/`tier`/`scope_kind` ngoài tập đóng, `version < 1`, `strength` ngoài `0..1` ([`AC-MEM-01-02`](../../06.analysis/03.acceptance-criteria/59.memory-contract.md)) | 400 |
| `MISSING_INPUT` | thiếu `project` | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại ([`AC-MEM-01-03`](../../06.analysis/03.acceptance-criteria/59.memory-contract.md)) | 403 |
| `CONFLICT` | cùng `(memory_id, version)` — `content_hash` **khác** ⇒ không ghi đè ([`AC-MEM-02-05`](../../06.analysis/03.acceptance-criteria/60.memory-store.md)) | 409 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |

**Sửa/xoá bị từ chối ở route.** `PUT` · `PATCH` · `DELETE /v1/memory/{id}` **không** phải endpoint: cả ba trả
`405 APPEND_ONLY`, record giữ nguyên ([`AC-MEM-01-05`](../../06.analysis/03.acceptance-criteria/59.memory-contract.md));
trigger `BEFORE UPDATE OR DELETE` ở tầng DB là chốt thứ hai ([`24` §4](../02.data-design/24.memory-record.md)).

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
