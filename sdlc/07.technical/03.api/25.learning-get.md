# `API-24` — `GET /v1/learning/{id}`

`GET /v1/learning/{id}`

| | |
|---|---|
| **200** | `{ "proposal": {…}, "events": [{seq, kind, actor, at, reason}] }` |
| **404** | `PROJECT_NOT_FOUND` — **cùng câu** với ngoài quyền (`BR-13`) |

## Bảng

| Bảng | Đọc/ghi | Cột |
|---|---|---|
| [`proposal`](../02.data-design/19.proposal.md) | **đọc** | toàn bộ |
| [`proposal_event`](../02.data-design/21.proposal-event.md) | **đọc** theo `seq` | `seq` · `kind` · `actor` · `at` · `reason` |

**Vì sao cần endpoint này:** `API-4` có `turns` · `risks` · `graph` · `audit` — **không** có `proposals`. Không có `API-24` thì màn
hình phải ghép từ `API-4` và tự suy trạng thái ⇒ bề mặt **tính**, mà `D-47` cấm.

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · `proposal_event` đổi cột · mã lỗi ở đây không còn trong registry · hình dạng
request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.
