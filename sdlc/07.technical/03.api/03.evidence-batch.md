# `API-1` — `POST /v1/evidence:batch`

`POST /v1/evidence:batch`

```json
{
  "project": "baplatform",
  "batch_id": "uuid",
  "items": [
    {
      "turn_id": "uuid", "seq": 1,
      "at": "2026-10-25T12:00:00Z",
      "actor": { "role": "lead", "status": "FULL" },
      "level": "partial", "mode": "ask", "basis": "retrieved",
      "payload": { "requirements": [], "answers": [], "elections": [], "files_used": [] }
    }
  ]
}
```

| | |
|---|---|
| **200** | `{ "accepted": n, "duplicates": m }` — trùng **không** phải lỗi ([`D-47`](../../03.inception/02.decision-log/00.index.md)) |
| **400** | thiếu `project` · thiếu `turn_id` |
| **403** | `project` không khớp phạm vi của credential |
| **409** | `turn_id` đã có với `payload` **khác** — cùng khoá, khác nội dung: **dừng**, không ghi đè |
| **503** | C2 chết ⇒ C1 **giữ** outbox, thử lại; **không** mất dữ liệu |

**`409` là chỗ đáng chú ý:** idempotent theo khoá, **nhưng** cùng khoá mà nội dung khác thì **không** được coi là trùng. Đó là
lỗi lập trình, và nuốt nó là nuốt bằng chứng.

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà file bảng không đổi · mã lỗi ở đây không còn trong
registry · hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.
