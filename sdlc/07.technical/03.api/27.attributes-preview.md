# `API-26` — `POST /v1/attributes:preview`

`POST /v1/attributes:preview`

```json
{ "project": "baplatform", "add": [{"name":"stage","closed_values":["a","b"]}] }
```

| | |
|---|---|
| **200** | `{ "impact": { "policies": 3, "subjects": 12 }, "invalid": [] }` |
| **409** | thuộc tính đang được policy dùng mà `closed_values` **bỏ** một giá trị đang có ⇒ `DIRTY_CONFIG` |
| **403** | không phải `operator` ⇒ `CONFIG_FORBIDDEN` |

## Bảng

| Bảng | Đọc/ghi | Cột |
|---|---|---|
| [`attribute_def`](../02.data-design/09.attribute-def.md) | **đọc** | `name` |
| [`policy`](../02.data-design/13.policy.md) | **đọc** đếm phụ thuộc | `attribute` |

**Preview trước, áp sau** — cùng luật với `API-12` → `API-13`. Thuộc tính là tập **đóng**; đổi nó đổi nghĩa mọi vị từ đang dùng nó.

## Luật sửa

Sai khi: route đổi · `impact` đổi hình dạng · mã lỗi không còn trong registry · `attribute_def` đổi cột.
