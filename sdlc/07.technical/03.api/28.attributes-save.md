# `API-27` — `POST /v1/attributes`

`POST /v1/attributes`

```json
{ "project": "baplatform", "name": "stage", "closed_values": ["a","b"] }
```

| | |
|---|---|
| **200** | `{ "name": "stage", "version": 4 }` |
| **400** | `closed_values` rỗng ⇒ `EMPTY_ROLE` — tập đóng mà rỗng thì mọi vị từ trên nó **luôn sai** |
| **409** | đã có `version` khác bytes mà không tăng ⇒ `VERSION_REQUIRED` |

## Bảng

| Bảng | Đọc/ghi | Cột |
|---|---|---|
| [`attribute_def`](../02.data-design/09.attribute-def.md) | **ghi** | `name` · `closed_values` |

**Áp là ghi một dòng mới, không sửa dòng cũ** — `policy` cũ trỏ `attribute` theo **tên**, nên sửa tại chỗ làm luật cũ đổi nghĩa
mà `policy` không đổi một byte (`Q-08` cùng lý do).

## Luật sửa

Sai khi: route đổi · `attribute_def` đổi cột · áp trở thành `UPDATE` tại chỗ.
