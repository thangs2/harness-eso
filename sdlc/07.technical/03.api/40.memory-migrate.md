# `API-39` — `POST /v1/memory:migrate`

`POST /v1/memory:migrate`

Nạp record từ **store cũ** (agentmemory) vào memory ESO, giữ **đủ 12 chiều** + provenance
([`US-MEM-03`](../../06.analysis/02.user-stories/61.memory-migrate.md) · [`AC-MEM-03`](../../06.analysis/03.acceptance-criteria/61.memory-migrate.md) ·
[`24.memory-record`](../02.data-design/24.memory-record.md) §7).

## Hợp đồng

| | |
|---|---|
| **Consumer** | operator · CLI · **không** UI |
| **Trên đường turn** | ❌ — off-path; migration nặng, gọi trong lúc phán ⇒ `409 HEAVY_ON_TURN` |
| **Idempotent** | ✅ theo `(project, source.kind, memory_id, version)` — nạp lại cùng nguồn ⇒ `skipped`, **không** nhân đôi |
| **Bảng ghi** | `memory_record` · `memory_topology_ref` |

```json
POST /v1/memory:migrate
{ "project": "baplatform",
  "source": { "kind": "agentmemory", "path": "/tmp/agentmemory-export.json" },
  "tier": "long", "limit": 500 }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | project **đích**; kiểm với credential |
| `source.kind` | **có** | tập đóng `agentmemory` — tên **host** (`cursor` · `agy` · `claude` · `dsh`) ⇒ `400 PER_HOST_COPY`: host chỉ là adapter, **không** phải nguồn ([`AC-MEM-03-03`](../../06.analysis/03.acceptance-criteria/61.memory-migrate.md)) |
| `source.path` | **có** | store/export **thật**; không mở được ⇒ `422 SOURCE_UNAVAILABLE` |
| `tier` | **có** | tập đóng `short` · `long`; nguồn agentmemory **không** có trường này nên người migrate chọn — `OPEN-API-MEM-03` |
| `limit` | không | trần số record mỗi lần; giá trị mặc định `OPEN-API-MEM-01` |

```json
200 OK
{ "project": "baplatform",
  "migrated": 38, "skipped": 1,
  "conflicts": [ { "memory_id": "0a1b…", "version": 3, "code": "CONFLICT",
                   "source_hash": "sha256:…", "local_hash": "sha256:…" } ],
  "failed": [ { "source_id": "77c0…", "code": "INVALID_RECORD" } ],
  "provenance": { "migrated_from": "agentmemory", "migrated_at": "2026-11-05T10:00:00.000Z" } }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `migrated` · `skipped` | **có** | `skipped` = đã có **đúng** version + `content_hash` |
| `conflicts[]` | **có**, có thể `[]` | hai nguồn khác nội dung: **giữ cả hai**, nêu `source_hash`/`local_hash`, **không** chọn bừa ([`AC-MEM-03-04`](../../06.analysis/03.acceptance-criteria/61.memory-migrate.md)) |
| `failed[]` | **có**, có thể `[]` | record nguồn không hợp lệ ⇒ `INVALID_RECORD`, không ghi |
| `provenance` | **có** | `migrated_from`/`migrated_at` trên **mọi** record đã nạp ([`E-7`](../../05.requirements/03.eso-memory.md)) — DB bắt buộc bằng `CHECK` ([`24`](../02.data-design/24.memory-record.md)) |

**12 chiều không được mất.** `id` · `version` · `type` · `title` · `content` · `concepts[]` · `files[]` · `sessionIds[]` ·
`strength` · `createdAt`/`updatedAt` **đều** nạp nguyên; `isLatest` **không** mang theo mà **tính** lại bằng view (`24` §2).
Toạ độ topology (`node_id` + `path`/`symbol`/`commit_sha`) nạp vào `memory_topology_ref`; `node_id` chết sau rebuild **không** làm mất fact.

| Mã | Khi nào | HTTP |
|---|---|---|
| `PER_HOST_COPY` | `source.kind` là **host**, không phải store | 400 |
| `INVALID_RECORD` | record nguồn thiếu trường / `type` ngoài tập đóng | 400 |
| `MISSING_INPUT` | thiếu `project`/`source`/`tier` | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại | 403 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |
| `SOURCE_UNAVAILABLE` | không mở được `source.path` | 422 |

## `OPEN`

| ID | Câu hỏi | Chủ |
|---|---|---|
| `OPEN-API-MEM-03` | Record migrate nhận `tier` gì khi nguồn không có trường này — một `tier` cho cả lô, hay suy theo `type`/tuổi? | `data` |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
