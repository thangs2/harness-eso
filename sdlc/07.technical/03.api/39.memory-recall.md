# `API-38` — `POST /v1/memory:recall`

`POST /v1/memory:recall`

Recall theo **từ khoá + concept**, và **traversal** theo topology — không chỉ top-k similarity
([`ESO-MEMORY` E-4/E-5](../../05.requirements/03.eso-memory.md) · [`AC-MEM-02-03`](../../06.analysis/03.acceptance-criteria/60.memory-store.md) ·
[`AC-MEM-02-04`](../../06.analysis/03.acceptance-criteria/60.memory-store.md)). Hình dạng trả về giữ đúng `{ snippets, trace }`
mà `fetch()` đang trả ([`ESO-MEMORY` §6](../../05.requirements/03.eso-memory.md)).

## Hợp đồng

| | |
|---|---|
| **Consumer** | C3 · CLI · host adapter **ngoài** lúc phán · **không** UI |
| **Trên đường turn** | ❌ — off-path; gọi trong lúc phán ⇒ `409 HEAVY_ON_TURN` |
| **Idempotent** | — (chỉ đọc) |
| **Bảng đọc** | `memory_record` (qua view `memory_latest`) · `memory_topology_ref` |

```json
POST /v1/memory:recall
{ "project": "baplatform", "concepts": ["order.created"], "files": ["src/Orders/Order.cs"],
  "scope": { "kind": "service", "value": "orders" }, "limit": 10 }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | cô lập project |
| `query` / `concepts[]` / `files[]` / `session_id` / `scope` / `node` | **ít nhất một** | không có bộ lọc nào ⇒ `400 MISSING_INPUT`; recall không giới hạn là quét cả store |
| `limit` | không | trần số snippet — **giá trị mặc định** là `OPEN-API-MEM-01`, không đặt số ở đây |

```json
200 OK
{ "project": "baplatform", "status": "hit", "as_of": "2026-11-05T09:50:00.000Z",
  "snippets": [ { "memory_id": "8f2c1d4e-…", "version": 2, "memory_type": "fact",
                  "title": "order.created đổi schema ở v2", "content": "…",
                  "strength_effective": 0.62, "files": ["src/Orders/Order.cs"],
                  "scope_kind": "service", "scope_value": "orders" } ],
  "trace": [ { "by": "concept", "value": "order.created", "hits": 1 },
             { "by": "file", "value": "src/Orders/Order.cs", "hits": 1 } ],
  "paths": [ [ "route:POST /api/orders", "event:order.created", "memory:8f2c1d4e-…" ] ] }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `status` | **có** | `hit` · `weak` · `miss` — **ba** trạng thái, không gộp ([`E-5`](../../05.requirements/03.eso-memory.md)); key chưa từng ghi **không** trả như hit yếu |
| `snippets[]` | **có**, có thể `[]` | `miss` ⇒ `[]`; `weak` ⇒ có snippet nhưng dưới ngưỡng strength |
| `trace[]` | **có** | bộ lọc **đã dùng** + số hit — để đọc lại được vì sao ra kết quả |
| `paths[]` | **có** khi traversal | đường đi node → memory theo topology ([`AC-MEM-02-04`](../../06.analysis/03.acceptance-criteria/60.memory-store.md)); `[]` khi không traversal |

| Mã | Khi nào | HTTP |
|---|---|---|
| `MISSING_INPUT` | thiếu `project` hoặc không có bộ lọc nào | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại | 403 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |

**Ngưỡng `hit`/`weak` là dữ liệu**, không phải hằng số trong route ([`D-11`](../../03.inception/02.decision-log/00.index.md)): `miss` = 0 snippet;
`weak` = có snippet nhưng `strength_effective` dưới sàn; `hit` = đạt sàn. Giá trị sàn thuộc `OPEN-API-MEM-02`.

## `OPEN`

| ID | Câu hỏi | Chủ |
|---|---|---|
| `OPEN-API-MEM-01` | `limit` mặc định bao nhiêu? | `data` |
| `OPEN-API-MEM-02` | Sàn `strength_effective` để phân biệt `hit`/`weak`? | `data` |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
