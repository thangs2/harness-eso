## 4. Mã lỗi — **một** bảng, không mỗi slice một bảng

Cây đang dùng `BLOCKED_SCOPE` · `DONE_FORBIDDEN` · `OUT_OF_SCOPE` · `DUPLICATE_ID` · `PREVIEW_FAILED` · `ALREADY_CLOSED` · `DANGLING_ARTEFACT` …
và **không mã nào được khai ở đâu**. Mỗi slice tự đặt tên ⇒ **cùng lỗi, hai tên** ⇒ client không xử lý được.

| `ERR` | HTTP | Sinh từ | Nghĩa |
|---|---|---|---|
| `OUT_OF_SCOPE` | 403 | `E7`–`E14` · `BR-12` | project ngoài quyền — **cùng câu** với project không tồn tại |
| `BLOCKED_SCOPE` | 403 | `W2-6` · `BR-03` | ghi ngoài `allowed_files` ⇒ **từ chối và ghi lại** |
| `DONE_FORBIDDEN` | 403 | `BR-08` | chỉ `A-01` được đặt *Done* |
| `DUPLICATE_ID` | 409 | `E7` | `id` trùng, **một** dòng sống |
| `ALREADY_CLOSED` | 409 | `E11` | đóng risk hai lần |
| `NOT_REVERTIBLE` | 409 | `E14` | không lùi được bước đó |
| `PREVIEW_FAILED` | 422 | `E12` | không tạo được ảnh hưởng ⇒ **không** có `[Lưu]` |
| `DANGLING_ARTEFACT` | 200 | `E21` | artefact đã xoá ⇒ **treo**, không sập |

| | | |
|---|---|
| `PREVIEW_REQUIRED` | 409 · `E13` — lưu mà chưa preview (hoặc `hash` lệch) |
| `ROOT_CHANGE_UNPLANNED` | 409 · `E13` — đổi `sdlc_root` mà chưa khai kế hoạch chuyển |
| `DIRTY_CONFIG` | 409 · `E17` — nâng preset khi còn thay đổi chưa lưu |
| `STALE_VERSION` | 409 · `E13` — version đã bị người khác nâng (hiện chỉ có trong `AC-UI-03-12`) |
| `CONFIG_FORBIDDEN` | 403 · `E13` — không phải `operator` |
| `REASON_REQUIRED` | 400 · `E11` — accept/close không kèm lý do |
| `ACCEPT_WITHOUT_DUE` | 400 · `E11` — accept không kèm `due` |
| `UNKNOWN_GROUP` | 400 · `E12` — nhóm cấu hình không thuộc bốn nhóm |
| `NO_REASON` | 400 · quyết định đề xuất không kèm lý do (`W5-7`) |
| `SCOPE_UNREADABLE` | 403 · `W2-6` — không đọc được khai báo phạm vi ⇒ vẫn `DENY` |

| `ACCEPT_FORBIDDEN` | 403 · `E11` — không được accept risk này |
| `APPLY_FORBIDDEN` | 403 · `E20` — không được áp đề xuất (agent không có quyền áp) |
| `APPROVAL_REQUIRED` | 403 · `E17` — nâng `shared` mà chưa có người duyệt |
| `CONFIG_INCOMPLETE` | 422 · `E16` — `check` thấy thiếu mục cấu hình bắt buộc |
| `DIRECT_WRITE_FORBIDDEN` | 403 · `DB`/`CLI` — ghi thẳng vào `evidence_*` ngoài hàm ingest |
| `HANDOFF_INCOMPLETE` | 400 · `E10` — bàn giao thiếu `carries` hoặc `bar_version` |
| `MUTATE_FORBIDDEN` | 403 · `E9`/`E9b` — sửa luật/thuộc tính ngoài đường append |
| `NO_TICKET_SOURCE` | 200 · `E18` — không có tool ticket ⇒ `missing[]`, **không** bịa `ticket_key` |
| `PACK_TAMPERED` | 409 · `E18` — `content_hash` của pack không khớp nội dung |
| `PIN_UNAVAILABLE` | 409 · chọn host — đích của ghim không còn; **giữ nguyên** lỗi trên mọi host |
| `POLICY_CHANGE_FORBIDDEN` | 403 · `E9` — đổi `policy` khi không phải `operator` |
| `POLICY_FORBIDDEN` | 403 · `E9` — không có quyền ghi `policy` |
| `PROJECT_NOT_FOUND` | 404 · mọi `E*` — **cùng** câu với `OUT_OF_SCOPE` khi cần giấu tồn tại |
| `REVERT_FORBIDDEN` | 403 · `E14` — không được revert cấu hình |
| `ROLE_CHANGE_FORBIDDEN` | 403 · `E8` — không được sửa vai |
| `RULE_CHANGE_FORBIDDEN` | 403 · `E9` — không được sửa luật |
| `SDLC_INCOMPLETE` | 422 · `E16` — `check` thấy thiếu mục SDLC bắt buộc |
| `SILENT_NONE` | 500 · adapter — năng lực **mất** mà không ghi `election` (lỗi của chính hệ) |
| `SYNC_CONFLICT` | 409 · sync — hai bản khác hash; **không** tự chọn bên nào |
| `TICKET_INCOMPLETE` | 200 · `E18` — ticket thiếu trường bắt buộc ⇒ `missing[]` kèm tên |
| `TURN_NOT_FOUND` | 404 · `E21` — `turn_id` thuộc project nhưng không có record |
| `UI_FETCH_FAILED` | 200 · UI — `ST3` `error`; **không** được hiện thành `empty` |
| `VERSION_REQUIRED` | 400 · `E13` — cùng version khác bytes; phải tăng version |
| `WRITE_NONE` | 200 · `E20`/`E11` — không có gì để ghi (đã ở trạng thái đích) |

| `TURN_GONE` | 410 · `E21` — record đã xoá theo chính sách lưu trữ; **khác** "chưa từng có" |
| `TURN_TOO_LARGE` | 413 · `E21` — record vượt giới hạn phản hồi ⇒ **không** trả một phần |

**Luật:** mã mới **phải** vào bảng này **trước** khi dùng. Mã không có ở đây là **chưa tồn tại**.
