# `API-32` — `POST /v1/graph/q3`

`POST /v1/graph/q3`

**Q3 — module nào phụ thuộc vòng.** Tìm **SCC** thật trên cạnh `depends_on`
([`18.graph-queries`](../01.architecture/18.graph-queries.md) §2 · [`AC-ARCH-04`](../../06.analysis/03.acceptance-criteria/33.arch-us-04-cycles.md)).

## Hợp đồng

| | |
|---|---|
| **Consumer** | A-02 · CLI / C3 **off-path** · **không** UI graph |
| **Trên đường turn** | ❌ — trong lúc phán ⇒ `409 HEAVY_ON_TURN` |
| **Idempotent** | — (chỉ đọc) |
| **Bảng đọc** | `graph_node` · `graph_edge` · `completeness` |

```json
POST /v1/graph/q3
{ "project": "baplatform", "build_id": "9f1c2a…" }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | cô lập project |
| `build_id` | không | như `API-30`. **Không** có tham số độ sâu — chu trình là phép đếm, không phải traversal |

```json
200 OK
{ "project": "baplatform", "question": "Q3", "status": "ready",
  "as_of": "2026-11-05T09:24:00.000Z",
  "completeness": { "question": "Q3", "value": 0.97,
                    "kinds": { "module": 0.97, "depends_on": 0.97 }, "floor": 0.7 },
  "answer": { "cycles": [ ["Orders", "Billing", "Orders"] ], "ignored_edges": [] },
  "unknowns": [] }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `answer.cycles` | **có**, có thể `[]` | mỗi phần tử là **một** chu trình (SCC); hai module cùng phụ thuộc một module chung **không** phải vòng ([`AC-ARCH-04-02`](../../06.analysis/03.acceptance-criteria/33.arch-us-04-cycles.md)) |
| `answer.ignored_edges` | **có**, có thể `[]` | cạnh `depends_on` trỏ module đã xoá: **bỏ** và **nêu**, không báo vòng giả ([`AC-ARCH-04-05`](../../06.analysis/03.acceptance-criteria/33.arch-us-04-cycles.md)) |
| `status` | **có** | graph **0 cạnh** `depends_on` vẫn phải trả "không có vòng" **kèm độ phủ**, không im lặng ([`AC-ARCH-04-04`](../../06.analysis/03.acceptance-criteria/33.arch-us-04-cycles.md)) |

| Mã | Khi nào | HTTP |
|---|---|---|
| `LOW_COVERAGE` | phủ `< 0,7` ⇒ `unknown`, **không** khẳng định "sạch" | 200 |
| `DANGLING_MODULE` | cạnh trỏ module mất ⇒ `ignored_edges[]` | 200 |
| `MISSING_INPUT` | thiếu `project` | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại | 403 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
