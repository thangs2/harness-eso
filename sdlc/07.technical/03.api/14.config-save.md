# `API-13` — `POST /v1/config:save`

`POST /v1/config:save`

```json
{ "project": "baplatform", "change": { … }, "hash": "sha256:…" }
```

| | |
|---|---|
| **200** | `{ "version": 12 }` — **nguyên tử**: bốn nhóm cùng một version |
| **409** | `hash` không khớp thay đổi ⇒ `PREVIEW_REQUIRED` ([`AC-IAM-06-02`](../../06.analysis/03.acceptance-criteria/10.iam-us-06-config.md)) |
| **409** | `sdlc_root` đổi mà **chưa** khai kế hoạch chuyển ⇒ `ROOT_CHANGE_UNPLANNED` ([`AC-CFG-01-02`](../../06.analysis/03.acceptance-criteria/11.cfg-us-01-config-page.md)) |
| **403** | không phải `operator` ⇒ `CONFIG_FORBIDDEN` ([`AC-CFG-01-04`](../../06.analysis/03.acceptance-criteria/11.cfg-us-01-config-page.md)) |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà file bảng không đổi · mã lỗi ở đây không còn trong
registry · hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.
