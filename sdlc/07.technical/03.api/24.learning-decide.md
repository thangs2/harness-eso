# `API-23` — `POST /v1/learning:decide`

`POST /v1/learning:decide`

```json
{ "project": "baplatform", "proposal_id": "uuid", "decision": "approve", "reason": "…" }
```

| | |
|---|---|
| **200** | `{ "status": "approved", "seq": 4 }` — ghi **một** sự kiện `decided` |
| **400** | `decision = "reject"` mà `reason` rỗng ⇒ `NO_REASON` |
| **409** | đã có `decided` ⇒ `ALREADY_DECIDED`; **không** `200` im lặng |
| **409** | đề xuất không ở trạng thái `proposed` ⇒ `VERSION_REQUIRED` |

## Bảng

| Bảng | Đọc/ghi | Cột |
|---|---|---|
| [`proposal`](../02.data-design/19.proposal.md) | **đọc** | `proposal_id` · `status` (tính) |
| [`proposal_event`](../02.data-design/21.proposal-event.md) | **ghi** một `decided` | `seq` · `kind` · `actor` · `at` · `reason` |

**Quyết định một lần** (`D-63` `DQ-02`): `decided` thứ hai bị **từ chối**, không ghi đè. Ghi đè làm lịch sử duyệt thành thứ
sửa được — và khi đó *"ai đã duyệt"* không còn trả lời được.

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · `proposal_event` đổi cột · mã lỗi ở đây không còn trong registry · hình dạng
request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.
