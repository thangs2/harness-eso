# `API-9` — `POST /v1/policies`

`POST /v1/policies`

```json
{ "project": "baplatform", "policy_id": "uuid?",
  "attribute": "path", "operator": "starts_with", "value": "packages/",
  "effect": "deny", "subjects": ["build"] }
```

| | |
|---|---|
| **200** | `{ "policy_id": "…", "version": 3 }` |
| **400** | `attribute` **ngoài tập đóng** ⇒ `UNKNOWN_ATTRIBUTE` — **từ chối khi lưu**, không phải khi chạy ([`AC-IAM-03-03`](../../06.analysis/03.acceptance-criteria/07.iam-us-03-policies.md)) |
| **403** | không phải `operator` ⇒ `POLICY_CHANGE_FORBIDDEN` |

**Không có đường nào cho agent** — kể cả gián tiếp, vì hành động này **chỉ** role `operator` gọi được ([`D-48`](../../03.inception/02.decision-log/00.index.md) §"chặn ở hành động").

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà file bảng không đổi · mã lỗi ở đây không còn trong
registry · hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ.
