# `API-31` — `POST /v1/graph/q2`

`POST /v1/graph/q2`

**Q2 — đổi cột bảng thì cái gì gãy.** Traversal **ngược** chiều phụ thuộc: `table → entity → dto → app_service`
([`18.graph-queries`](../01.architecture/18.graph-queries.md) §2 · [`AC-ARCH-03`](../../06.analysis/03.acceptance-criteria/32.arch-us-03-impact.md)).
`K(Q2) = [table, entity, column]`.

## Hợp đồng

| | |
|---|---|
| **Consumer** | A-02 · CLI / C3 **off-path** · **không** UI graph |
| **Trên đường turn** | ❌ — trong lúc phán ⇒ `409 HEAVY_ON_TURN` |
| **Idempotent** | — (chỉ đọc) |
| **Bảng đọc** | `graph_node` · `graph_edge` · `completeness` |

```json
POST /v1/graph/q2
{ "project": "baplatform", "table": "orders", "column": "tenant_id", "build_id": "9f1c2a…" }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | cô lập project |
| `table` | **có** | thiếu ⇒ `400 MISSING_INPUT` |
| `column` | không | có thì phạm vi hẹp hơn; **không** đổi chiều traversal |
| `build_id` | không | như `API-30` |

```json
200 OK
{ "project": "baplatform", "question": "Q2", "status": "ready",
  "as_of": "2026-11-05T09:22:00.000Z",
  "completeness": { "question": "Q2", "value": 0.91,
                    "kinds": { "table": 1.0, "entity": 0.93, "column": 0.91 }, "floor": 0.7 },
  "answer": { "direction": "reverse",
              "impact": [ { "kind": "app_service", "path": "src/Orders/OrderAppService.cs",
                            "via": ["entity", "dto"] } ] },
  "unknowns": [] }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `answer.direction` | **có** | luôn `reverse` — chiều xuôi là **sai** ([`AC-ARCH-03-01`](../../06.analysis/03.acceptance-criteria/32.arch-us-03-impact.md)) |
| `answer.impact` | **có**, có thể `[]` | `[]` khi bảng **không ai đọc** — rỗng thật, **không** `OVERREACH` ([`AC-ARCH-03-04`](../../06.analysis/03.acceptance-criteria/32.arch-us-03-impact.md)) |
| `unknowns[]` | **có** | nhánh `unknown` nêu **bảng đã xoá** khi entity trỏ vào bảng mất ([`AC-ARCH-03-05`](../../06.analysis/03.acceptance-criteria/32.arch-us-03-impact.md)) |

| Mã | Khi nào | HTTP |
|---|---|---|
| `LOW_COVERAGE` | phủ dưới `floor` ⇒ `status: unknown`, **không** "không gãy gì" | 200 |
| `DANGLING_TABLE` | entity trỏ bảng đã xoá ⇒ nhánh đó `unknown` + nêu bảng | 200 |
| `OVERREACH` | câu trả lời liệt kê file **không** dùng bảng đó ⇒ **từ chối** | 422 |
| `MISSING_INPUT` | thiếu `project`/`table` | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại | 403 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
