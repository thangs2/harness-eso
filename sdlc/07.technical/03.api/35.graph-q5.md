# `API-34` — `POST /v1/graph/q5`

`POST /v1/graph/q5`

**Q5 — slice có chạm ranh giới tenant không.** Đếm dấu `tenant` trên tập con entity/app_service
([`18.graph-queries`](../01.architecture/18.graph-queries.md) §2 · [`AC-ARCH-06`](../../06.analysis/03.acceptance-criteria/35.arch-us-06-tenant.md)).

## Hợp đồng

| | |
|---|---|
| **Consumer** | A-04/A-02 · CLI / C3 **off-path** · **không** UI graph |
| **Trên đường turn** | ❌ — trong lúc phán ⇒ `409 HEAVY_ON_TURN` |
| **Idempotent** | — (chỉ đọc) |
| **Bảng đọc** | `graph_node` · `graph_edge` · `completeness` |

```json
POST /v1/graph/q5
{ "project": "baplatform", "slice": "orders", "build_id": "9f1c2a…" }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `project` | **có** | cô lập project |
| `slice` | **có** | tên slice trong graph; thiếu ⇒ `400 MISSING_INPUT` |
| `build_id` | không | như `API-30` |

```json
200 OK
{ "project": "baplatform", "question": "Q5", "status": "ready",
  "as_of": "2026-11-05T09:28:00.000Z",
  "completeness": { "question": "Q5", "value": 0.7,
                    "kinds": { "entity": 0.7, "app_service": 0.72, "tenant_marker": 0.7 }, "floor": 0.7 },
  "answer": { "slice": "orders", "touches_tenant": true,
              "evidence": [ { "kind": "entity", "path": "src/Orders/Order.cs", "marker": "tenant_id" } ] },
  "unknowns": [] }
```

| Trường | Bắt buộc | Ghi chú |
|---|---|---|
| `answer.touches_tenant` | **có** | `true` · `false` · **`null`** khi `unknown` — `false` **chỉ** được nói khi phủ đạt ngưỡng ([`AC-ARCH-06-02`](../../06.analysis/03.acceptance-criteria/35.arch-us-06-tenant.md)) |
| `answer.evidence[]` | **có** khi `touches_tenant=true` | dấu `tenant` **cụ thể**, không phải "có thể" |
| Ngưỡng | — | **đóng tại `0,7`**: đúng `0,7` còn trả lời; **chỉ** `< 0,7` mới `unknown` ([`AC-ARCH-06-04`](../../06.analysis/03.acceptance-criteria/35.arch-us-06-tenant.md)) |

| Mã | Khi nào | HTTP |
|---|---|---|
| `LOW_COVERAGE` | phủ `< 0,7` ⇒ `unknown`, `touches_tenant: null`, **không** "không chạm" | 200 |
| `EMPTY_SLICE` | slice **0 bảng** ⇒ `unknown` + nêu "slice rỗng" ([`AC-ARCH-06-05`](../../06.analysis/03.acceptance-criteria/35.arch-us-06-tenant.md)) | 200 |
| `MISSING_INPUT` | thiếu `project`/`slice` | 400 |
| `OUT_OF_SCOPE` | project ngoài quyền **hoặc** không tồn tại | 403 |
| `HEAVY_ON_TURN` | gọi trong lúc phán | 409 |

## Luật sửa

Sai khi: route hoặc mã trạng thái đổi · một bảng đọc/ghi đổi mà `02.roundtrip` không đổi · mã lỗi ở đây không còn trong registry ·
hình dạng request/response đổi mà `02.roundtrip` vẫn khai bảng cũ · endpoint này bị gọi trên đường turn.
