# IAM — capability spec

## Vai MỞ, động từ ĐÓNG
- verbs (bảng `verb`, cưỡng chế): `read` `write` `append` `approve` `configure` `handoff`
- capability (mở, người đặt tên): `be` `fe` `qc` `design` `pm` `review` `lead` `p` …
- role = `capabilities[]` + `scope[(verb,kind,value)]` + `bar[]`; **1 hoặc N**, không catalog đóng
- `bar` = **nghĩa vụ**, không phải quyền; rỗng trên vai agent = không hợp lệ
- `role_presets[0]` = 7 vai baplatform (preset, **không** phải cơ chế)

## 6 chức năng
`US-IAM-01` workers (nghỉ khi đang dở ⇒ risk `OPEN`) `02` roles `03` policies `04` flows
`05` accept (**cần `due`**) `06` config (preview hash → save → revert)

## Luật
- **deny-overrides** · quyền = `role ∩ grant ∩ slice` (**giao, không hợp**)
- chỉ `operator` đổi vai/luật; agent chặn ở **HÀNH ĐỘNG** (phủ cả đường gián tiếp)
- bàn giao **chặn** nếu thiếu `bar` vai nhận · `accept` không `due` ⇒ từ chối
- lưu config chỉ khi `hash` khớp preview · revert **dời con trỏ** + đánh dấu artefact
- uỷ quyền = `evidence_item` `kind=authz`, **không** bảng thứ hai
- **0 endpoint trên đường turn**; E7–E12 là admin
