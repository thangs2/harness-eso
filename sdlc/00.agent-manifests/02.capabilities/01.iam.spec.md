# IAM — capability spec

## Roles are OPEN. Verbs are CLOSED.
- **verbs** (enforced): `read` `write` `append` `approve` `configure` `handoff`
- **capability** (open, user-named): `be` `fe` `qc` `design` `pm` `review` `lead` `p` …
- **role** = `capabilities[]` + `scope` + `bar[]` — create 1 or N, no closed catalog
- `bar` = **obligation**, not permission. Empty `bar` on agent role = invalid.
- preset `role_presets[0]` = baplatform 7-role template (content, not mechanism).

## 6 functions
| id | function |
|---|---|
| US-IAM-01 | workers — add/pause/retire; retiring with in-flight work ⇒ OPEN risk |
| US-IAM-02 | roles — scope + bar |
| US-IAM-03 | policies — attribute predicates |
| US-IAM-04 | flows — handoff A→B |
| US-IAM-05 | accept — debt needs owner + due |
| US-IAM-06 | config — preview → save → revert |

## Laws
deny-overrides · authority = `role ∩ grant ∩ slice` (**never union**) ·
only `operator` changes role/policy · agent never changes policy — blocked at **ACTION**, covers indirect path ·
handoff **blocked** if receiver `bar` unmet · `accept` without `due` refused ·
config save refused unless preview `hash` matches · revert moves pointer, marks artefacts, never rewrites
