# Knowledge — capability spec

## A declaration = **one** markdown file in git
`{zone}/{kind}/{name}.md` · `zone` ∈ `pool` `shared` `project` · `kind` ∈ `skills` `rules`
Required: `id` · `version` · `kind` · **`applies_when`** · `declared_by`

Missing `applies_when` = applies **everywhere** ⇒ must write `always: true` explicitly.

## `applies_when` — 10 **closed** attributes
`always` `paths` `service_count` `team_count` `consistency_need` `coupling`
`tenant_model` `read_write_ratio` `deploy_independence` `observability_need` `latency_budget` `failure_domain`

**3 must be human-declared** (not inferable): `consistency_need` · `tenant_model` · `failure_domain`
Undeclared ⇒ a declaration using it **does not match**, and the system says **"not declared"** — never a default.
Unknown attribute ⇒ **refused at save** (not at run).

## Precedence
`project override` > `project use` > `shared` > `pool`
Result = `Resolved{id, version, from, overridden_by?}` — evidence records the **version**, nothing pins.

## Three rules
- **upgrading `shared` upgrades everyone**; opt out by **override**, and overrides **must be visible**
- upgrading needs **approval** + an **impact list** + **one-action revert**
- `status` ∈ `current` · `superseded` · `revoked` — all three readable, only `current` selectable

## Wire
`E2 declarations:sync` (in then out; **conflict ⇒ stop**). Tables `declaration` · `sync_state`.
**0 endpoints on the turn path** — selection runs **locally** from files.
