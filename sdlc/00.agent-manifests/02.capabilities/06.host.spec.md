# Host capability — capability spec

## Bốn nhánh, thứ tự **cố định**
`host-native` → `eso-native` → `external` → **`none`**
Dừng ở nhánh **đầu tiên có**. Kiểm **đúng thứ tự** — không nhảy.

## `none` là trạng thái **hợp lệ**
Không nhánh nào có ⇒ **vẫn chạy**, **hạ mức bảo đảm**, và **nói ra**.
`none` **không** phải lỗi: giấu nó là để agent **đoán**.

## Hai luật
- **ghi nhánh đã chọn** + lý do, mỗi lần — `elections{kind, provider, reason}`
- đổi nhánh (kể cả khi nhánh cũ hỏng) **phải được ghi**; đổi ngầm ⇒ `SILENT_SWITCH`

## Năng lực nào được chọn
Đọc/ghi file · chạy lệnh · session memory · skills · pre-step hook · graph · search
Host **thiếu** ⇒ nhánh rơi xuống; **không** giả vờ có.

## Phủ RBAC
**N/A** — chọn nguồn chạy **cục bộ trong turn**, không có bề mặt người dùng.
Quyền **đổi cấu hình** năng lực là config: `AC-CFG-01-04` (#2).

## Wire
**0 endpoint trên đường turn** — chọn nguồn là việc **cục bộ**. Kết quả vào `payload` của evidence.
Tenant: cấu hình A **không** áp cho B.
