# Evidence — capability spec

## What each turn records
`level` · `mode` · `basis` · `Resolved[]` (which skill version) · `FileUse{path, content_hash, git_commit, dirty}` · `elections`

**`dirty: true`** ⇒ the content **cannot be recovered** from git ⇒ must be **stated** (a limit of the evidence).

## Three rules
- **append-only**: no `UPDATE`, no `DELETE`; changing = appending ([`BR-06`](../../03.analysis/01.business-analysis/03.business-rules.md))
- **only the runtime writes**; humans write via `risk:event` (E11) — a direct write ⇒ `DIRECT_WRITE_FORBIDDEN`
- **isolation**: `project` is the leading key part; missing `SET LOCAL` ⇒ **empty**, never everything

## Revert — mark, do not mutate
a revert event **closes a window** `[publish, revert]`; artefacts that used that version are **computed** into a
`ran_on_reverted_skill` flag. **Never** mutate the artefact; **never** delete the old version
([`D-32`](../../01.inception/02.decision-log/00.index.md) · [`D-33`](../../01.inception/02.decision-log/00.index.md)).

## Wire
`E1 evidence:batch` (idempotent on `(project, turn_id, seq)`) · `E5 graph:batch` · `E11 risk:event` (the human's only write path)
