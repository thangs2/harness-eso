# Luật đặt tên delivery

## 1. Folder đợt

```text
sdlc/delivery/demo/{YYYY-MM-DD}-{batch}/
sdlc/delivery/release/{YYYY-MM-DD}-{batch}/
```

- `YYYY-MM-DD`: ngày đợt (local, `Asia/Saigon`).
- `batch`: `eso-<from>-<to>` — ví dụ `eso-368-389`; toàn bộ dùng `eso-all`.

Ví dụ: `sdlc/delivery/demo/2026-11-05-eso-368-389/`.

## 2. Script `.sh`

```text
{plane}-{action}-{YYYY-MM-DD}-{batch}.sh
```

| Phần | Giá trị | Nghĩa |
|---|---|---|
| `plane` | `be` \| `fe` | `be` = `eso/control-plane` (NestJS/Fastify); `fe` = `eso/ui` (Angular) |
| `action` | `demo` \| `release` | demo = chạy thử; release = gate phát hành |
| `YYYY-MM-DD` | ngày | phải trùng folder đợt |
| `batch` | `eso-<from>-<to>` | phải trùng folder đợt |

Ví dụ:

```text
be-demo-2026-11-05-eso-368-389.sh
fe-demo-2026-11-05-eso-368-389.sh
be-release-2026-11-05-eso-368-389.sh
```

## 3. Luật viết script

1. `.sh` là **entrypoint duy nhất** cho người chạy; không yêu cầu nhớ `node`/`bun`/`npm` lẻ.
2. `set -euo pipefail`; in từng bước; exit non-zero khi fail.
3. `ROOT` tính từ `BASH_SOURCE`, không phụ thuộc cwd.
4. Demo mặc định `--check`; `--serve` chỉ khi được truyền.
5. Không hard-code token/secret; token demo in ra từ script.
6. Không ghi file tracked; mọi output vào `/tmp`.
7. Không đặt alias `demo:*` trong `package.json` — sẽ bị xoá.

## 4. Phân biệt BE / FE

| | BE | FE |
|---|---|---|
| Code | `eso/control-plane` | `eso/ui` |
| Runtime | NestJS + Fastify | Angular 22 (tsc build) |
| Demo | HTTP: health, auth, config, S1 HTML, Q4/Q5 | build + structure + 14 file test AC UI |
| Script | `be-demo-...sh` | `fe-demo-...sh` |
