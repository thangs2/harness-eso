# Luật đặt tên delivery

## 1. Folder đợt

```text
sdlc/delivery/demo/{YYYY-MM-DD}-{batch}/
sdlc/delivery/release/{YYYY-MM-DD}-{batch}/
```

- `YYYY-MM-DD`: ngày đợt (local, `Asia/Saigon`).
- `batch`: `eso-<from>-<to>` — ví dụ `eso-368-389`; toàn bộ dùng `eso-all`.
- Mỗi folder có **`00.index.md`**; đây là index của đợt, không đọc file rời.

Ví dụ: `sdlc/delivery/demo/2026-11-05-eso-368-389/`.

## 2. Script `.sh` — stable, không theo đợt

```text
{plane}-{action}.sh
```

| Phần | Giá trị | Nghĩa |
|---|---|---|
| `plane` | `be` \| `fe` | `be` = `eso/control-plane` (NestJS/Fastify); `fe` = `eso/ui` (Angular) |
| `action` | `demo` \| `release` | demo = chạy thử; release = gate phát hành |

Script nằm cố định ở `sdlc/delivery/`:

```text
sdlc/delivery/be-demo.sh
sdlc/delivery/fe-demo.sh
sdlc/delivery/be-release.sh
```

**Đợt là tham số**, không phải tên file:

```bash
sdlc/delivery/be-demo.sh --batch=2026-11-05-eso-368-389 --check
sdlc/delivery/fe-demo.sh --batch=2026-11-05-eso-368-389
sdlc/delivery/be-release.sh --batch=2026-11-05-eso-368-389
```

Không truyền `--batch` ⇒ lấy folder đợt mới nhất.

## 3. Thêm đợt mới

1. Tạo `sdlc/delivery/demo/{date}-{batch}/00.index.md` (và/hoặc `release/.../00.index.md`).
2. **Không** tạo `.sh` mới, không copy script, không sửa `package.json`.
3. Chạy lại script stable với `--batch` mới.

## 4. Luật viết script

1. `.sh` là entrypoint duy nhất; không bắt người chạy nhớ `node`/`bun`/`npm` lẻ.
2. `set -euo pipefail`; in batch + từng bước; exit non-zero khi fail.
3. `ROOT` tính từ `BASH_SOURCE`, không phụ thuộc cwd.
4. Demo mặc định `--check`; `--serve` chỉ khi được truyền.
5. Không hard-code token/secret; token demo in ra từ script.
6. Không ghi file tracked; output vào `/tmp`.
7. Không alias `demo:*` trong `package.json`.

## 5. Phân biệt BE / FE

| | BE | FE |
|---|---|---|
| Code | `eso/control-plane` | `eso/ui` |
| Runtime | NestJS + Fastify | Angular 22 (tsc build) |
| Demo | HTTP: health, auth, config, S1 HTML, Q4/Q5 | build + structure + 14 file test AC UI |
| Script | `be-demo.sh` | `fe-demo.sh` |

## 6. Anti-pattern

```text
fe-demo-2026-11-05-eso-368-389.sh   # ❌ mỗi đợt một file = repeat
be-demo-2026-11-05.sh               # ❌ ngày nằm trong tên file
demo:eso                            # ❌ alias rời rạc trong package.json
```
