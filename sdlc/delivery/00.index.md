## Luật cứng

1. Mỗi đợt có **một folder** `{YYYY-MM-DD}-{batch}`; batch = `eso-<from>-<to>`.
2. Mỗi folder có **`00.index.md`** làm cửa vào; không đọc file rời.
3. Lệnh chạy là **script stable** `be-demo.sh` / `fe-demo.sh` / `be-release.sh`; đợt truyền bằng `--batch`, không tạo script mới.
4. `.sh` phải phân biệt **BE** (`eso/control-plane`, NestJS/Fastify) và **FE** (`eso/ui`, Angular).
5. Script chỉ ghi `/tmp`; không chạm consumer thật, `x79`, hay `comments/artifacts`.
